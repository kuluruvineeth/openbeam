# Slack Setup

## Prerequisites

- A Slack workspace where you have admin permissions
- OpenBeam bot running locally or deployed (see [Quickstart](/docs/bot/quickstart))

## Step 1: Create a Slack App

1. Go to [api.slack.com/apps](https://api.slack.com/apps) and click **Create New App**
2. Choose **From an app manifest**
3. Select the workspace you want to install to
4. Paste the manifest below (replace `your-domain.com` with your webhook URL)
5. Click **Create**

## Step 2: App Manifest

```yaml
display_information:
  name: OpenBeam
  description: Enterprise search and AI assistant
  background_color: "#1a1a2e"

features:
  bot_user:
    display_name: OpenBeam
    always_online: true

oauth_config:
  scopes:
    bot:
      - app_mentions:read
      - channels:history
      - chat:write
      - commands
      - groups:history
      - im:history
      - im:read
      - im:write
      - reactions:write
      - users:read
      - users:read.email

settings:
  event_subscriptions:
    bot_events:
      - app_mention
      - message.im
    request_url: https://your-domain.com/webhooks/slack
  interactivity:
    is_enabled: true
    request_url: https://your-domain.com/webhooks/slack
  org_deploy_enabled: false
  socket_mode_enabled: false
```

<Callout type="info">
If you prefer manual configuration instead of the manifest, create a new app "From scratch" and configure each section individually. The manifest method is faster and less error-prone.
</Callout>

## Step 3: Install to Workspace

1. Navigate to **OAuth & Permissions** in your Slack App settings
2. Click **Install to Workspace**
3. Review the permissions and click **Allow**
4. Copy the **Bot User OAuth Token** (`xoxb-...`)

## Step 4: Get Your Credentials

You need three values from the Slack App dashboard:

| Credential | Where to Find |
|------------|--------------|
| **Bot Token** | OAuth & Permissions > Bot User OAuth Token (`xoxb-...`) |
| **Signing Secret** | Basic Information > App Credentials > Signing Secret |
| **App ID** | Basic Information > App Credentials > App ID |

## Step 5: Configure Environment

```bash
SLACK_BOT_TOKEN=xoxb-your-bot-token
SLACK_SIGNING_SECRET=your-signing-secret
SLACK_APP_ID=your-app-id
```

## Step 6: Verify Webhook

In **Event Subscriptions**, the Request URL should show a green checkmark. If it doesn't:

1. Ensure the bot is running and accessible at `https://your-domain.com/webhooks/slack`
2. Slack sends a challenge request — the bot handles this automatically
3. The response must arrive within 3 seconds

## Step 7: Test

Mention the bot in any channel:

```
@OpenBeam search deployment runbook
```

Or send a direct message:

```
What is our deploy process?
```

The bot responds with Block Kit formatted messages — headers, sections, citation blocks, and follow-up action buttons.

## Scopes Explained

| Scope | Why It's Needed |
|-------|----------------|
| `app_mentions:read` | Receive events when users mention @OpenBeam |
| `channels:history` | Read messages in public channels (for context) |
| `chat:write` | Send messages and Block Kit responses |
| `commands` | Register and handle slash commands |
| `groups:history` | Read messages in private channels |
| `im:history` | Read direct message history |
| `im:read` | Access DM channels |
| `im:write` | Send DMs to users |
| `reactions:write` | Add emoji reactions (for acknowledgments) |
| `users:read` | Look up user profiles for identity resolution |
| `users:read.email` | Match Slack users to OpenBeam accounts by email |

## Response Format

The Slack adapter produces Block Kit payloads:

- **Search results**: Header block + Section per result (with clickable links) + Follow-up action buttons
- **AI answers**: Section block with answer text + Context block with numbered citations + Action buttons
- **Expert list**: Header + Section per expert with name, email, expertise
- **Errors**: Section with warning emoji prefix

## How It Works

The Slack adapter delegates to existing `@openbeam/services` infrastructure:

- **Signature verification**: `verifySlackSignature()` — HMAC-SHA256 with timing-safe comparison
- **Event parsing**: `parseSlackEvent()` — Zod-validated event envelope with typed event schemas
- **Response rendering**: `renderSlack()` — produces Block Kit JSON (headers, sections, context, actions, dividers)
- **Message sending**: `createSlackClient()` → `client.call("chat.postMessage", { blocks, text })`
