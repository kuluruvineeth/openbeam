# Quickstart

This guide gets the bot running on your machine with one platform configured. WhatsApp and Telegram are the easiest to start with.

## Prerequisites

| Requirement | Version | Check |
|-------------|---------|-------|
| Bun | 1.3.3+ | `bun --version` |
| PostgreSQL | 14+ | `psql --version` |
| Redis | 7+ | `redis-cli ping` |
| ngrok or cloudflared | Latest | `ngrok version` |

Don't have PostgreSQL/Redis? Start them with Docker:

```bash
docker run -d --name pg -e POSTGRES_PASSWORD=postgres -p 5432:5432 postgres:16
docker run -d --name redis -p 6379:6379 redis:7
```

## Step 1: Install Dependencies

```bash
bun install
```

## Step 2: Set Up the Database

```bash
DATABASE_URL=postgresql://postgres:postgres@localhost:5432/openbeam bun run db:migrate
```

## Step 3: Create Environment File

```bash
cp apps/bot/.env.example apps/bot/.env
```

Edit `apps/bot/.env` with your values:

```bash
BOT_PORT=3005
DATABASE_URL=postgresql://postgres:postgres@localhost:5432/openbeam
REDIS_URL=redis://localhost:6379
BOT_LINK_BASE_URL=http://localhost:3001
```

Then add the credentials for your chosen platform. See the platform-specific guides for how to get these:

- [Slack](/docs/bot/slack) — fastest for teams already on Slack
- [Telegram](/docs/bot/telegram) — easiest setup (BotFather, no business verification)
- [WhatsApp](/docs/bot/whatsapp) — richest consumer experience
- [Discord](/docs/bot/discord) — best for developer communities
- [Teams](/docs/bot/teams) — required for Microsoft-centric orgs

## Step 4: Expose Your Local Server

Platforms send webhooks to a public URL. Start a tunnel:

```bash
ngrok http 3005
```

Copy the HTTPS URL (e.g., `https://abc123.ngrok-free.app`) — you'll need this for webhook configuration.

<Callout type="info">
With a paid ngrok plan, you get a stable domain that doesn't change between restarts. For free ngrok, you'll need to reconfigure the webhook URL each time.

Alternative: `cloudflared tunnel --url http://localhost:3005`
</Callout>

## Step 5: Start the Bot

```bash
bun run --hot apps/bot/src/index.ts
```

Verify it's running:

```bash
curl http://localhost:3005/health
# {"status":"ok","service":"bot"}
```

## Step 6: Configure Your Platform

Follow the platform-specific guide to register webhooks and get credentials:

| Platform | Webhook URL | Guide |
|----------|------------|-------|
| Slack | `https://{ngrok}/webhooks/slack` | [Slack Setup](/docs/bot/slack) |
| Teams | `https://{ngrok}/webhooks/teams` | [Teams Setup](/docs/bot/teams) |
| Discord | `https://{ngrok}/webhooks/discord` | [Discord Setup](/docs/bot/discord) |
| Telegram | `https://{ngrok}/webhooks/telegram` | [Telegram Setup](/docs/bot/telegram) |
| WhatsApp | `https://{ngrok}/webhooks/whatsapp` | [WhatsApp Setup](/docs/bot/whatsapp) |

## Step 7: Send a Test Message

On your configured platform, send:

```
hello
```

You should see a welcome message with available commands. Then try:

```
search deployment docs
```

If you get a response with search results, the bot is working end-to-end.

## Step 8: Run Tests

```bash
bun test apps/bot/__tests__/
```

All 75 tests should pass.

## Troubleshooting

| Problem | Solution |
|---------|----------|
| Bot doesn't respond | Check that the webhook URL is correct and the tunnel is running |
| "invalid signature" errors | Verify your signing secret / app secret matches the platform config |
| "Account not linked" prompt | Click the magic link to connect your platform account to OpenBeam |
| Rate limit error | Wait the indicated number of seconds and try again |
| Health check fails | Ensure `DATABASE_URL` and `REDIS_URL` are correct |

See [Troubleshooting](/docs/bot/troubleshooting) for detailed platform-specific fixes.
