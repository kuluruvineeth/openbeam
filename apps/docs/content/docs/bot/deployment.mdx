# Deployment

## Docker

```dockerfile
FROM oven/bun:1.3.3-slim AS base
WORKDIR /app

COPY package.json bun.lock turbo.json ./
COPY apps/bot/package.json ./apps/bot/
COPY packages/types/package.json ./packages/types/
COPY packages/db/package.json ./packages/db/
COPY packages/ai/package.json ./packages/ai/
COPY packages/services/package.json ./packages/services/
COPY packages/redis/package.json ./packages/redis/

RUN bun install --frozen-lockfile

COPY . .
RUN bun run build --filter=bot

FROM oven/bun:1.3.3-slim
WORKDIR /app
COPY --from=base /app .

EXPOSE 3005
HEALTHCHECK CMD curl -f http://localhost:3005/health || exit 1
CMD ["bun", "run", "apps/bot/dist/index.js"]
```

## Environment Variables

All variables are validated at startup via Zod. Missing required variables cause immediate failure with a clear error message.

| Variable | Required | Platform |
|----------|----------|----------|
| `BOT_PORT` | No (default: 3005) | All |
| `DATABASE_URL` | Yes | All |
| `REDIS_URL` | No (default: redis://localhost:6379) | All |
| `SLACK_BOT_TOKEN` | For Slack | Slack |
| `SLACK_SIGNING_SECRET` | For Slack | Slack |
| `SLACK_APP_ID` | For Slack | Slack |
| `TEAMS_APP_ID` | For Teams | Teams |
| `TEAMS_APP_PASSWORD` | For Teams | Teams |
| `DISCORD_APPLICATION_ID` | For Discord | Discord |
| `DISCORD_PUBLIC_KEY` | For Discord | Discord |
| `DISCORD_BOT_TOKEN` | For Discord | Discord |
| `TELEGRAM_BOT_TOKEN` | For Telegram | Telegram |
| `TELEGRAM_WEBHOOK_SECRET` | For Telegram | Telegram |
| `WHATSAPP_PHONE_NUMBER_ID` | For WhatsApp | WhatsApp |
| `WHATSAPP_ACCESS_TOKEN` | For WhatsApp | WhatsApp |
| `WHATSAPP_VERIFY_TOKEN` | For WhatsApp | WhatsApp |
| `WHATSAPP_APP_SECRET` | For WhatsApp | WhatsApp |

## Rate Limits

| Scope | Limit | Window |
|-------|-------|--------|
| Per user per platform | 30 requests | 1 minute |
| Per team total | 500 requests | 1 minute |
