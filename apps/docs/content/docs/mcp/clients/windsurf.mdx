Windsurf (by Codeium) is an AI-native IDE with built-in Cascade AI. By connecting OpenBeam via MCP, you augment Cascade with your enterprise knowledge -- internal documentation, code standards, team decisions, and data from 100+ connected sources. Cascade handles code generation while OpenBeam provides the organizational context it lacks.

## Prerequisites

- **Windsurf** installed ([windsurf.com](https://windsurf.com))
- An **OpenBeam account** with at least one connected data source
- An **OpenBeam API key** (generate one at **Settings > API Keys** in the OpenBeam dashboard)

<Callout type="info">
API keys start with `op_live_`. Keep this value secret -- it grants access to all data sources visible to your team.
</Callout>

## Configuration

<Steps>
<Step>

### Open MCP settings

In Windsurf, open the MCP configuration. You can do this in one of three ways:

- Click the **MCPs icon** in the top-right of the Cascade panel
- Open **Settings > Cascade > MCP Servers** and click **View raw config**
- Manually edit the config file at `~/.codeium/windsurf/mcp_config.json`

If the file does not exist, create it.

</Step>
<Step>

### Add the OpenBeam server

Add the following to the config file. If the file already contains other MCP servers, merge the `openbeam` key into the existing `mcpServers` object.

```json
{
  "mcpServers": {
    "openbeam": {
      "url": "https://api.openbeam.work/mcp",
      "headers": {
        "Authorization": "Bearer op_live_your_key_here"
      }
    }
  }
}
```

Replace `op_live_your_key_here` with your actual API key.

<Callout type="warn">
If you self-host OpenBeam, replace `https://api.openbeam.dev` with your server's base URL.
</Callout>

</Step>
<Step>

### Restart Windsurf

Restart the IDE for the MCP server to connect. Windsurf loads MCP configurations on startup.

</Step>
</Steps>

## Verification

After restarting, open Cascade (Windsurf's AI panel) and type:

```text
List my connectors
```

Cascade should invoke the `connector_list` tool and return a summary of your connected data sources. If you see connector names, statuses, and document counts, the integration is working.

You can also check the MCP status indicator in the Windsurf status bar to confirm the OpenBeam server is connected.

## Use Cases

Windsurf's strength is AI-assisted coding. OpenBeam fills the gap between your codebase and your organization's broader knowledge.

### Search internal documentation while coding

```text
Search my docs for authentication flow design document
```

When implementing a feature, pull up the relevant design doc or RFC without leaving your editor.

### Find internal API references

```text
Search for API endpoint documentation for the billing service
```

Locate internal API specs, Swagger docs, or Confluence pages describing service contracts.

### Look up team decisions and standards

```text
Search for coding standards for error handling
```

Find team-agreed patterns, ADRs (Architecture Decision Records), and style guides indexed from Notion, Confluence, or Google Docs.

### Check connector health during debugging

```text
What's the health status of my GitHub connector?
```

When debugging sync issues or stale data, verify connector status without switching to the OpenBeam dashboard.

### Find the right person to ask

```text
Find who on my team is an expert in GraphQL
```

Identify subject-matter experts when you need a code review or have questions about an unfamiliar part of the codebase.

## Troubleshooting

### MCP server not appearing in Cascade

<Steps>
<Step>
Confirm the config file is valid JSON. A trailing comma or missing bracket will silently prevent loading. Paste the file contents into a JSON validator if unsure.
</Step>
<Step>
Verify the file is at `~/.codeium/windsurf/mcp_config.json`. Windsurf does not read the Claude Desktop config path.
</Step>
<Step>
Restart Windsurf completely -- closing and reopening a window is not sufficient. Quit the application and relaunch it.
</Step>
</Steps>

### Authentication failed

- Double-check that your API key starts with `op_live_` and has not been revoked.
- Ensure there are no extra spaces or line breaks inside the key value.
- If you self-host, confirm your server is reachable: `curl -s https://your-server/mcp` should return a response (not a connection error).

### Tools not loading

- Some tools are gated by scopes assigned to your API key. If you only see a subset of tools, check the key's scope configuration in **Settings > API Keys**.
- If no tools appear at all, the server connection likely failed. Check the Windsurf output panel (**View > Output**, select MCP from the dropdown) for error messages.

### Cascade ignores OpenBeam tools

Cascade uses its own judgment to decide when to invoke MCP tools. If it does not use OpenBeam for a query, try being explicit: "Use the OpenBeam search tool to find docs about X." Over time, Cascade learns which tools are useful for which queries.
