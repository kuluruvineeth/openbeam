# Quickstart

Three steps to give your AI assistant access to every document, message, and file across your team's tools.

## Prerequisites

- An OpenBeam account with at least one connected data source
- An AI tool that supports MCP (Claude Desktop, Cursor, Windsurf, Claude Code, etc.)

## Step 1: Get your credentials

<Tabs items={["Hosted (OAuth)", "Self-Hosted (API Key)"]}>
  <Tab value="Hosted (OAuth)">
    No API key needed. OpenBeam's hosted MCP server uses OAuth -- your AI tool will prompt you to sign in with your OpenBeam account when you first connect.

    The MCP URL is:

    ```
    https://api.openbeam.work/mcp
    ```
  </Tab>
  <Tab value="Self-Hosted (API Key)">
    Generate an API key from your OpenBeam dashboard:

    1. Go to **Settings > API Keys**
    2. Click **Create API Key**
    3. Copy the key (starts with `op_live_`)

    Or via the CLI:

    ```bash
    openbeam auth login
    openbeam api-key create --name "mcp-server"
    ```
  </Tab>
</Tabs>

## Step 2: Add to your AI tool

<Tabs items={["Claude Desktop", "Claude Code", "Cursor", "Other Clients"]}>
  <Tab value="Claude Desktop">
    Click the **+** button in any chat, then **Connectors > Manage Connectors > Add custom server**:

    ```
    URL: https://api.openbeam.work/mcp
    ```

    Claude will prompt you to sign in via OAuth. Or add to `claude_desktop_config.json`:

    ```json
    {
      "mcpServers": {
        "openbeam": {
          "url": "https://api.openbeam.work/mcp",
          "headers": {
            "Authorization": "Bearer op_live_your_key_here"
          }
        }
      }
    }
    ```
  </Tab>
  <Tab value="Claude Code">
    ```bash
    claude mcp add --transport http openbeam https://api.openbeam.work/mcp
    ```

    Then run `/mcp` in a Claude Code session to authenticate.
  </Tab>
  <Tab value="Cursor">
    Open **Settings > Tools & MCP > Add new MCP server**, or add to `.cursor/mcp.json`:

    ```json
    {
      "mcpServers": {
        "openbeam": {
          "url": "https://api.openbeam.work/mcp",
          "headers": {
            "Authorization": "Bearer op_live_your_key_here"
          }
        }
      }
    }
    ```
  </Tab>
  <Tab value="Other Clients">
    For any MCP client that supports Streamable HTTP, use the URL directly:

    ```
    https://api.openbeam.work/mcp
    ```

    Most modern MCP clients (Windsurf, Codex, VS Code, OpenCode) support native HTTP transport. See the [client setup guides](/docs/mcp/clients) for exact configuration per client.

    For self-hosted instances:

    ```json
    {
      "mcpServers": {
        "openbeam": {
          "url": "https://your-instance.example.com/mcp",
          "headers": {
            "Authorization": "Bearer op_live_your_key_here"
          }
        }
      }
    }
    ```
  </Tab>
</Tabs>

## Step 3: Try it

Once connected, ask your AI assistant any of these:

| Prompt | What happens |
|--------|-------------|
| "What connectors are connected to OpenBeam?" | Calls `connector_list` to show your data sources |
| "Search for our Q4 planning docs" | Calls `search_documents` with hybrid semantic + keyword search |
| "Who knows the most about authentication?" | Calls `search_people` to find subject matter experts |
| "Create a Linear issue for the login bug" | Calls `connector_action_execute` to create the issue |
| "What's the sync status of my Slack connector?" | Calls `sync_status` to show sync health |
| "Summarize what we know about Project Atlas" | Calls `ask_question` for RAG-powered answer with citations |

<Callout type="info">
  The AI assistant automatically discovers available tools. You do not need to tell it which tool to use -- just describe what you want in natural language.
</Callout>

## Verify the connection

The simplest test:

> "List my connected data sources and their sync status."

If you see your connectors listed with document counts and last sync times, everything is working.

## Troubleshooting

| Issue | Fix |
|-------|-----|
| "Server not found" | Ensure `https://api.openbeam.work` is reachable from your network |
| "Authentication failed" | Re-authenticate via OAuth, or check your API key is valid |
| "No results" | Verify at least one connector is synced in the OpenBeam dashboard |
| Connection timeout | Check firewall rules; the MCP endpoint requires HTTPS on port 443 |
| Tools not appearing | Restart your AI tool after adding the MCP configuration |
