# OpenPlane

Open source enterprise search and AI assistant. Self-hosted alternative to Glean.

## Architecture

```mermaid
flowchart TB
    subgraph Clients
        Web[Web UI]
        CLI[Go CLI]
        Daemon[Local Daemon]
    end

    subgraph API["API Layer"]
        Server[Hono + tRPC]
    end

    subgraph Processing
        Worker[Temporal Worker]
        Engine[Python Engine]
    end

    subgraph Storage
        DB[(PostgreSQL)]
        Redis[(Redis)]
        Vespa[(Vespa)]
        S3[(S3/R2)]
    end

    subgraph Edge["Edge Runtime"]
        EdgeCore[SQLite + Sync]
        EdgeSearch[FTS5 + Vector]
        EdgeAI[Local RAG]
    end

    subgraph Connectors
        SaaS[Slack, Gmail, Notion, Linear, GitHub]
        IoT[Samsara, AWS IoT, Azure IoT]
        Industrial[MQTT, OPC-UA, BACnet]
        Physical[FHIR, Matterport, Viam]
    end

    Web --> Server
    CLI --> Server
    Daemon --> Server
    Server --> DB & Redis & Vespa & Worker
    Worker --> Engine & Connectors & Vespa & S3
    EdgeCore --> EdgeSearch --> EdgeAI
```

## Stack

| Layer | Technology |
|-------|------------|
| Language | TypeScript 5.8+, Zod 4 |
| Frontend | Next.js 16, React 19, TailwindCSS 4 |
| API | Hono, tRPC 11, SuperJSON |
| Workers | Temporal |
| ML Engine | FastAPI, Unstructured |
| Search | Vespa (BM25 + semantic) |
| AI | Vercel AI SDK (Claude, GPT, Gemini) |
| Database | PostgreSQL, Prisma |
| Cache/Queue | Redis |
| Storage | S3/R2 |
| CLI | Go 1.24, Cobra |
| Edge | SQLite (bun:sqlite), FTS5 |
| Linter | Biome (via Ultracite) |

## Project Structure

```
apps/
├── web         # Next.js frontend (:3001)
├── server      # Hono API + tRPC (:3000)
├── worker      # Temporal worker
├── engine      # Python ML service (:8000)
├── cli         # Go CLI (openplane command)
├── daemon      # Local headless agent daemon
├── gateway     # IoT protocol gateway
└── docs        # Documentation (:4000)

packages/
├── types       # Shared type definitions (single source of truth)
├── ai          # Agents, tools, RAG pipeline
├── api         # tRPC routers
├── auth        # Authentication
├── db          # Prisma schema, queries
├── services    # Connector business logic
├── temporal    # Workflows & activities
├── redis       # Cache & rate limiting
├── vespa       # Search client & schemas
├── media       # Video processing
├── storage     # S3/R2 client
├── integrations # OAuth configs, app definitions
├── mcp         # Model Context Protocol
├── edge-core   # Edge SQLite storage & sync
├── edge-search # Edge hybrid search (FTS5 + vector)
└── edge-ai     # Edge RAG, NER, query rewriting
```

## Data Flow

```mermaid
sequenceDiagram
    participant U as User
    participant W as Web
    participant S as Server
    participant T as Temporal
    participant P as Worker
    participant E as Engine
    participant V as Vespa

    U->>W: Search query
    W->>S: tRPC request
    S->>V: Hybrid search (BM25 + semantic)
    V-->>S: Permission-filtered results
    S-->>W: Response
    W-->>U: Display

    Note over T,E: Background Sync
    S->>T: Trigger sync workflow
    T->>P: Execute activities
    P->>E: Parse documents
    E-->>P: Chunks + embeddings
    P->>V: Index
```
