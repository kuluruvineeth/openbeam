# OpenPlane

Open source enterprise search and AI assistant. Alternative to Glean.

## Architecture

```mermaid
flowchart TB
    subgraph Client
        Web[Web UI]
    end

    subgraph API["API Layer"]
        Server[Hono + tRPC]
    end

    subgraph Processing
        Worker[BullMQ Workers]
        Engine[Python Engine]
    end

    subgraph Storage
        DB[(PostgreSQL)]
        Redis[(Redis)]
        Vespa[(Vespa)]
        S3[(S3/R2)]
    end

    subgraph Connectors
        Slack & Gmail & Drive & More[...]
    end

    Web --> Server
    Server --> DB
    Server --> Redis
    Server --> Vespa
    Redis --> Worker
    Worker --> Engine
    Worker --> Connectors
    Worker --> Vespa
    Worker --> S3
    Engine --> Worker
```

## Stack

| Layer | Technology |
|-------|------------|
| Frontend | Next.js 16, React 19, TailwindCSS 4 |
| API | Hono, tRPC 11 |
| Workers | BullMQ |
| ML Engine | FastAPI, Unstructured |
| Search | Vespa |
| AI | Vercel AI SDK (Claude, GPT, Gemini) |
| Database | PostgreSQL, Prisma |
| Cache/Queue | Redis |
| Storage | S3/R2 |
| Video | TwelveLabs |

## Project Structure

```
apps/
├── web         # Next.js frontend
├── server      # Hono API + tRPC
├── worker      # BullMQ job processors
├── engine      # Python ML/parsing service
└── docs        # Documentation (Fumadocs)

packages/
├── ai          # LLM providers, embeddings, agents
├── api         # tRPC routers
├── auth        # Better Auth
├── db          # Prisma schema, queries, mutations
├── services    # Connector logic (Slack, Gmail, etc.)
├── redis       # BullMQ queues
├── vespa       # Search client
├── media       # TwelveLabs video processing
├── storage     # S3/R2 client
└── integrations # OAuth configs
```

## Data Flow

```mermaid
sequenceDiagram
    participant U as User
    participant W as Web
    participant S as Server
    participant Q as Queue
    participant P as Worker
    participant E as Engine
    participant V as Vespa

    U->>W: Search query
    W->>S: tRPC request
    S->>V: Hybrid search
    V-->>S: Results
    S-->>W: Response
    W-->>U: Display

    Note over Q,E: Background Sync
    S->>Q: Trigger sync
    Q->>P: Process job
    P->>E: Parse documents
    E-->>P: Chunks
    P->>V: Index
```
