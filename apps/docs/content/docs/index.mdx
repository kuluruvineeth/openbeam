# Search everything your team knows

OpenBeam connects to your SaaS tools, indexes every document, message, and file, and gives your team instant AI-powered answers with citations. Open source alternative to Glean.

## What you can do

| Capability | How it works |
|------------|-------------|
| **Unified search** | Hybrid BM25 + semantic search across all connected sources in under 200ms |
| **AI answers** | Grounded responses with citations from your actual documents |
| **20 connectors** | Slack, Gmail, Google Drive, Notion, Linear, GitHub, Samsara, MQTT, OPC-UA, and more |
| **Permission-aware** | Results respect source permissions. Users only see what they have access to |
| **Agent canvas** | Visual builder for multi-step AI workflows with human-in-the-loop approvals |
| **Edge runtime** | Offline-capable search and AI on SQLite for air-gapped environments |

## Tech stack

| Layer | Technology |
|-------|------------|
| Language | TypeScript 5.8+, Zod 4 |
| Frontend | Next.js 16, React 19, TailwindCSS 4, shadcn/ui |
| API | Hono, tRPC 11, SuperJSON |
| Orchestration | Temporal (durable workflows) |
| Search | Vespa (hybrid BM25 + semantic vectors) |
| Database | PostgreSQL 16 + Prisma |
| Cache | Redis 8 |
| AI | Vercel AI SDK (Claude, GPT, Gemini) |
| Storage | S3/R2/MinIO |
| ML Engine | Python, FastAPI, Unstructured |
| CLI | Go 1.24, Cobra |
| Edge | SQLite (bun:sqlite), FTS5, vector search |
| Monorepo | Turborepo + bun workspaces |
| Linter | Biome (via Ultracite) |
