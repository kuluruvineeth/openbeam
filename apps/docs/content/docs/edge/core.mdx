# Core Infrastructure

`@openplane/edge-core` provides the foundational infrastructure every edge node needs. SQLite for storage, config management for tier-aware behavior, a task scheduler with cron and retry, Merkle tree sync for cloud reconciliation, and health aggregation for fleet monitoring.

```typescript
import {
  openEdgeDatabase,
  EdgeConfigManager,
  getFeatureFlags,
  EdgeTaskScheduler,
  MerkleTree,
  CursorManager,
  StoreAndForwardQueue,
  detectBandwidthPolicy,
  HealthAggregator,
  SQLiteCache,
  SQLiteKVStore,
  SQLitePubSub,
  SQLiteLock,
} from "@openplane/edge-core";
```

## SQLite Foundation

All edge data lives in a single SQLite database running in WAL (Write-Ahead Logging) mode for concurrent read access.

```typescript
import { openEdgeDatabase } from "@openplane/edge-core";

const db = openEdgeDatabase("./data/edge.db");
```

`openEdgeDatabase` configures the database with production-ready pragmas:

| Pragma | Value | Purpose |
|--------|-------|---------|
| `journal_mode` | `WAL` | Concurrent readers, single writer |
| `foreign_keys` | `ON` | Referential integrity |
| `busy_timeout` | `5000` | Wait 5s on lock contention |
| `synchronous` | `NORMAL` | Balance durability and speed |

For tests, use an in-memory database:

```typescript
import { Database } from "bun:sqlite";

const db = new Database(":memory:");
db.exec("PRAGMA journal_mode = WAL");
```

## Config Manager

`EdgeConfigManager` persists node configuration to SQLite and notifies listeners on changes.

```typescript
import { EdgeConfigManager } from "@openplane/edge-core";

const config = new EdgeConfigManager(db);
```

### EdgeConfig Schema

The full config shape, defined in `@openplane/types/edge/config`:

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `nodeId` | `string` | required | Unique node identifier |
| `tier` | `EdgeTier` | required | Hardware tier |
| `syncPolicy` | `SyncPolicy` | incremental, 5min, batch 100 | Sync behavior |
| `searchConfig` | `SearchConfig` | FTS on, vector off, alpha 0.5 | Search settings |
| `slmConfig` | `SlmConfig` | disabled, phi-3-mini, mock runtime | SLM settings |
| `flConfig` | `FlConfig` | disabled, fedavg | Federated learning settings |
| `dataDir` | `string` | `"./data"` | Data directory |
| `logLevel` | `string` | `"info"` | Log level |
| `maxDbSizeMb` | `number` | `1024` | Max database size |

## Task Scheduler

SQLite-backed task queue with priority ordering, cron scheduling, exponential backoff retry, and dead letter queue.

```typescript
import { EdgeTaskScheduler } from "@openplane/edge-core";

const scheduler = new EdgeTaskScheduler(db);
```

### Enqueue and Process

```typescript
scheduler.registerHandler("sync-connector", async (payload) => {
  const connectorId = payload.connectorId as string;
  await runIncrementalSync(connectorId);
});

const taskId = scheduler.enqueue("sync-connector", { connectorId: "slack-001" }, {
  priority: 1,       // 0=critical, 1=high, 2=normal, 3=low
  maxAttempts: 5,
});

scheduler.start(1000); // Poll every 1s

// Manual processing
const task = scheduler.dequeue();
if (task) {
  try {
    await processTask(task);
    scheduler.complete(task.id);
  } catch (err) {
    scheduler.fail(task.id, err.message);
  }
}
```

### Cron Scheduling

```typescript
scheduler.schedule("daily-reindex", "0 2 * * *", { scope: "all" });

scheduler.schedule("hourly-health", "0 * * * *", {});

scheduler.schedule("weekday-sync", "30 9 * * 1-5", { connectorId: "jira-001" });
```

Cron expressions use standard 5-field format: `minute hour day-of-month month day-of-week`. When a cron task completes, the next occurrence is automatically enqueued.

### Retry with Exponential Backoff

Failed tasks retry with configurable backoff:

```typescript
scheduler.enqueue("fragile-task", { url: "https://api.example.com" }, {
  maxAttempts: 5,
  retryPolicy: {
    baseDelayMs: 1000,
    maxDelayMs: 60_000,
    backoffMultiplier: 2,
    jitterFactor: 0.1,
  },
});
```

After `maxAttempts` failures, tasks move to the dead letter queue:

```typescript
const deadLetters = scheduler.getDeadLetterQueue();
for (const item of deadLetters) {
  console.log(`${item.name} failed ${item.attempts}x: ${item.error}`);
}
```

### Task Management

```typescript
const task = scheduler.getTask(taskId);

const pendingTasks = scheduler.listTasks("pending");
const allTasks = scheduler.listTasks();

scheduler.stop();
```

## Merkle Tree

BLAKE3-based Merkle tree for efficient sync reconciliation. Compare two trees to find exactly which documents differ.

```typescript
import { MerkleTree } from "@openplane/edge-core";

const local = new MerkleTree();
local.insert("doc-1", "checksum-abc");
local.insert("doc-2", "checksum-def");
local.insert("doc-3", "checksum-ghi");

const root = await local.getRoot();
```

### Diff Two Trees

```typescript
const remote = new MerkleTree();
remote.insert("doc-1", "checksum-abc");  // same
remote.insert("doc-2", "checksum-xyz");  // different checksum
remote.insert("doc-4", "checksum-jkl");  // new on remote

const differences = local.diff(remote);
// ["doc-2", "doc-3", "doc-4"]
// doc-2: checksum changed, doc-3: missing on remote, doc-4: missing on local
```

### Proof and Verification

Generate inclusion proofs for individual keys and verify against a known root:

```typescript
const proof = await local.getProof("doc-1");
const isValid = await MerkleTree.verify("doc-1", "checksum-abc", proof, root);
// true
```

### Serialize and Deserialize

```typescript
const serialized = await local.serialize();
// { entries: [["doc-1", "checksum-abc"], ...], root: "a1b2c3..." }

const restored = MerkleTree.deserialize(serialized);
```

## Cursor Manager

Track per-connector sync progress. Persisted to SQLite so sync resumes after restarts.

```typescript
import { CursorManager } from "@openplane/edge-core";

const cursors = new CursorManager(db);

cursors.saveCursor({
  connectorId: "slack-001",
  lastEventId: "evt-12345",
  lastTimestamp: Date.now(),
  merkleRoot: await tree.getRoot(),
  fullSyncCompleted: true,
  version: 3,
});

const cursor = cursors.getCursor("slack-001");

const isStale = cursors.isStale("slack-001", 3_600_000); // stale after 1 hour

const allCursors = cursors.listCursors();

cursors.deleteCursor("slack-001");
```

## Store-and-Forward Queue

Priority queue for outbound events. Events queue locally when offline and drain when connectivity returns.

```typescript
import { StoreAndForwardQueue } from "@openplane/edge-core";

const queue = new StoreAndForwardQueue(db, 100); // 100 MB max
```

  <Tab value="Enqueue">
    ```typescript
    const eventId = queue.enqueue(
      "document_indexed",
      { documentId: "doc-1", connectorId: "confluence" },
      "high"  // priority: "critical" | "high" | "normal" | "low"
    ```

  <Tab value="Dequeue">

    ```typescript
        queue.markSent(event.id);
      } catch (err) {
        queue.markFailed(event.id, err.message);
    ```

## Bandwidth Detection

Automatically determine sync strategy based on measured network bandwidth.

```typescript
import { detectBandwidthPolicy } from "@openplane/edge-core";

const policy = detectBandwidthPolicy(estimatedKbps);

console.log(policy.syncMode);          // "full" | "incremental" | "metadata_only" | "manual"
console.log(policy.maxBatchSizeKb);    // batch size limit
console.log(policy.compressionEnabled); // whether to compress payloads
```

| Bandwidth | Sync Mode | Max Batch | Compression |
|-----------|-----------|-----------|:-----------:|
| >= 10,000 Kbps | `full` | 10 MB | No |
| >= 1,000 Kbps | `incremental` | 2 MB | Yes |
| >= 100 Kbps | `metadata_only` | 512 KB | Yes |
| < 100 Kbps | `manual` | 128 KB | Yes |

## SQLite Utilities

### Cache

LRU cache with TTL, max entries, and max size enforcement.

```typescript
import { SQLiteCache } from "@openplane/edge-core";

const cache = new SQLiteCache(db, {
  tableName: "search_cache",
  maxEntries: 10_000,
  maxSizeMb: 50,
  defaultTtlMs: 300_000, // 5 minutes
});

cache.set("query:deployment", JSON.stringify(results), 60_000);
const cached = cache.get("query:deployment");
cache.delete("query:deployment");

const stats = cache.stats(); // { entries: number, sizeMb: number }
```

### KV Store

Key-value store with optional TTL per key.

```typescript
import { SQLiteKVStore } from "@openplane/edge-core";

const kv = new SQLiteKVStore(db, "app_state");

kv.set("last_sync", Date.now().toString());
kv.set("temp_token", "abc123", 3_600_000); // 1 hour TTL

const value = kv.get("last_sync");
const exists = kv.has("last_sync");
const keys = kv.keys("sync_"); // prefix search

kv.delete("temp_token");
kv.evictExpired();
kv.clear();
```

### PubSub

In-process publish/subscribe for decoupled component communication.

```typescript
import { SQLitePubSub } from "@openplane/edge-core";

const pubsub = new SQLitePubSub();

pubsub.subscribe("document:indexed", (message) => {
  const { documentId } = message as { documentId: string };
  updateSearchIndex(documentId);
});

const delivered = pubsub.publish("document:indexed", { documentId: "doc-1" });
// delivered === 1 (number of subscribers notified)

pubsub.unsubscribe("document:indexed"); // remove all handlers
pubsub.channels(); // list active channels
```

### Distributed Lock

SQLite-backed advisory locks with TTL. Prevents concurrent operations on the same resource.

```typescript
import { SQLiteLock } from "@openplane/edge-core";

const locks = new SQLiteLock(db);

const acquired = locks.acquire("sync:slack-001", "worker-1", 30_000); // 30s TTL
if (acquired) {
  try {
    await performSync();
  } finally {
    locks.release("sync:slack-001", "worker-1");
  }
}

locks.isLocked("sync:slack-001"); // true/false
locks.forceRelease("sync:slack-001"); // override holder check
```
