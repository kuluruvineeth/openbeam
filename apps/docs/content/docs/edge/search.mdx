# Search Engine

`@openbeam/edge-search` provides a complete search stack running on a single edge node. SQLite FTS5 for keyword matching, in-memory cosine similarity for vector search, and hybrid ranking that fuses both signals. No external search engine required.

```typescript
import {
  EdgeSearchEngine,
  SQLiteFTS5Provider,
  InMemoryVectorProvider,
  SQLiteDocumentStore,
  hybridRank,
  rrfRank,
} from "@openbeam/edge-search";
```

## EdgeSearchEngine

The main orchestrator. Wires together FTS, vector, and document store providers.

```typescript
import { openEdgeDatabase } from "@openbeam/edge-core";
import { EdgeSearchEngine, SQLiteFTS5Provider, InMemoryVectorProvider, SQLiteDocumentStore } from "@openbeam/edge-search";

const db = openEdgeDatabase("./edge.db");

const engine = new EdgeSearchEngine({
  fts: new SQLiteFTS5Provider(db),
  vector: new InMemoryVectorProvider(),  // optional: omit for FTS-only
  store: new SQLiteDocumentStore(db),
  defaultAlpha: 0.5,  // vector weight in hybrid ranking (0 = FTS only, 1 = vector only)
});
```

### Indexing Documents

```typescript
await engine.indexDocument({
  documentId: "doc-001",
  connectorId: "confluence",
  title: "Production Deployment Guide",
  content: "This guide covers the steps for deploying to production including health checks, rollback procedures, and monitoring setup.",
  documentType: "page",
  checksum: "sha256:abc123",
  embedding: embeddingVector,  // Float32Array from embedding model
  metadata: { space: "Engineering", author: "jane@company.com" },
  createdAt: Date.now(),
  updatedAt: Date.now(),
});

await engine.removeDocument("doc-001");
```

### Searching

<Tabs items={["FTS Only", "Hybrid", "With Filters"]}>
  <Tab value="FTS Only">
    When no embedding is provided, the engine uses FTS-only mode.

    ```typescript
    const results = await engine.search({
      query: "deployment health checks",
      limit: 10,
    });

    console.log(results.searchMode);  // "fts_only"
    console.log(results.queryTimeMs); // < 50ms typical

    for (const hit of results.results) {
      console.log(`${hit.title} (score: ${hit.score.toFixed(3)})`);
      console.log(`  ${hit.snippet}`);
      console.log(`  connector: ${hit.connectorId}, type: ${hit.documentType}`);
    }
    ```
  </Tab>
  <Tab value="Hybrid">
    Pass a query embedding to enable hybrid search. FTS and vector scores are normalized and fused using the `hybridAlpha` weight.

    ```typescript
    import { MockEmbeddingModel } from "@openbeam/edge-ai";

    const embedding = new MockEmbeddingModel();
    const queryVector = await embedding.embed("deployment health checks");

    const results = await engine.search(
      { query: "deployment health checks", limit: 10, hybridAlpha: 0.6 },
      queryVector
    );

    console.log(results.searchMode);  // "hybrid"

    for (const hit of results.results) {
      console.log(`${hit.title} — fts: ${hit.ftsScore?.toFixed(3)}, vec: ${hit.vectorScore?.toFixed(3)}, combined: ${hit.score.toFixed(3)}`);
    }
    ```
  </Tab>
  <Tab value="With Filters">
    Filter by connector, document type, or date range.

    ```typescript
    const results = await engine.search({
      query: "quarterly revenue",
      limit: 20,
      connectorIds: ["google-drive", "notion"],
      documentTypes: ["spreadsheet", "page"],
      dateRange: {
        from: new Date("2025-01-01").getTime(),
        to: Date.now(),
      },
    });
    ```

## Search Response Shape

Every search returns an `EdgeSearchResponse`:

```typescript
interface EdgeSearchResponse {
  results: EdgeSearchResult[];
  totalHits: number;
  queryTimeMs: number;
  searchMode: "fts_only" | "vector_only" | "hybrid";
}

interface EdgeSearchResult {
  documentId: string;
  title: string;
  snippet: string;            // first 200 chars of content
  score: number;              // combined score
  ftsScore?: number;          // BM25 score (normalized)
  vectorScore?: number;       // cosine similarity (normalized)
  connectorId: string;
  documentType?: string;
  updatedAt?: number;
  metadata?: Record<string, unknown>;
}
```

## SQLiteFTS5Provider

BM25-ranked full-text search using SQLite's FTS5 extension.

```typescript
import { SQLiteFTS5Provider } from "@openbeam/edge-search";

const fts = new SQLiteFTS5Provider(db, "fts_documents");

await fts.index("doc-1", "Deployment Guide", "Step-by-step production deployment...");
await fts.index("doc-2", "Monitoring Setup", "Configure Prometheus and Grafana...");

const results = await fts.search("deployment monitoring", 10);
// [{ documentId: "doc-1", score: 2.45 }, { documentId: "doc-2", score: 1.82 }]

await fts.remove("doc-1");
const count = await fts.documentCount();
await fts.clear();
```

### FTS5 Query Syntax

FTS5 supports standard search operators:

| Syntax | Example | Behavior |
|--------|---------|----------|
| Space-separated terms | `deployment guide` | Match documents containing both terms (implicit AND) |
| `OR` operator | `deployment OR monitoring` | Match documents containing either term |
| `NOT` operator | `deployment NOT staging` | Exclude documents with term |
| Phrase search | `"health check"` | Match exact phrase |
| Prefix wildcard | `deploy*` | Match terms starting with prefix |

<Callout type="warn">
Quotes in user queries are sanitized to prevent FTS5 syntax errors. Raw single and double quotes are replaced with spaces before querying.
</Callout>

## InMemoryVectorProvider

Cosine similarity search over L2-normalized vectors. All vectors are held in memory for sub-millisecond search at edge scale.

```typescript
import { InMemoryVectorProvider } from "@openbeam/edge-search";

const vector = new InMemoryVectorProvider();

await vector.upsert("doc-1", embedding1); // Float32Array
await vector.upsert("doc-2", embedding2);

const results = await vector.search(queryVector, 10);
// [{ documentId: "doc-1", score: 0.92 }, { documentId: "doc-2", score: 0.87 }]

await vector.remove("doc-1");
const count = await vector.documentCount();
await vector.clear();
```

Vectors must have matching dimensions. Mismatched vectors are skipped during search.

### Performance Characteristics

| Metric | Typical | Notes |
|--------|---------|-------|
| Search latency | < 10ms | 10K vectors, 384 dimensions |
| Memory per vector | ~1.5 KB | 384 * 4 bytes + overhead |
| 10K documents | ~15 MB | RAM for vector index |
| 100K documents | ~150 MB | Upper bound for edge nodes |

## Hybrid Ranking

Two ranking strategies for fusing FTS and vector results.

### hybridRank

Weighted linear combination with min-max normalization. The `alpha` parameter controls the balance.

```typescript
import { hybridRank } from "@openbeam/edge-search";

const ftsResults = [
  { documentId: "doc-1", score: 3.2 },
  { documentId: "doc-2", score: 1.8 },
];
const vectorResults = [
  { documentId: "doc-1", score: 0.95 },
  { documentId: "doc-3", score: 0.88 },
];

const ranked = hybridRank(ftsResults, vectorResults, 0.5);
// alpha=0.5: equal weight to FTS and vector
// alpha=0.0: FTS only
// alpha=1.0: vector only
```

Each result in the output includes both component scores:

```typescript
interface RankedResult {
  documentId: string;
  score: number;       // alpha * vectorScore + (1 - alpha) * ftsScore
  ftsScore?: number;   // normalized 0-1
  vectorScore?: number; // normalized 0-1
}
```

### rrfRank

Reciprocal Rank Fusion. Position-based scoring that is robust to score scale differences. Use when combining more than two result sets.

```typescript
import { rrfRank } from "@openbeam/edge-search";

const fused = rrfRank([ftsResults, vectorResults, rerankerResults], 60);
// k=60 (default): standard smoothing constant
// score = sum(1 / (k + rank + 1)) across all result sets
```

## SQLiteDocumentStore

CRUD storage for document records with metadata. Used by the search engine to hydrate results with titles, content, and metadata.

```typescript
import { SQLiteDocumentStore } from "@openbeam/edge-search";

const store = new SQLiteDocumentStore(db, "edge_documents");

await store.put("doc-1", {
  documentId: "doc-1",
  connectorId: "confluence",
  title: "Deployment Guide",
  content: "Full content here...",
  documentType: "page",
  checksum: "sha256:abc",
  metadata: { space: "Engineering" },
  createdAt: Date.now(),
  updatedAt: Date.now(),
});

const doc = await store.get("doc-1");
const exists = await store.has("doc-1");
await store.delete("doc-1");
```

### Listing and Filtering

```typescript
const docs = await store.list({
  connectorId: "confluence",
  documentType: "page",
  limit: 50,
  offset: 0,
});

const totalDocs = await store.count();
await store.clear();
```

## Search Modes

The engine automatically selects the search mode based on available providers and input.

| Condition | Mode | Behavior |
|-----------|------|----------|
| No vector provider or no embedding | `fts_only` | BM25 keyword matching only |
| Vector provider + embedding, no FTS results | `vector_only` | Cosine similarity only |
| Vector provider + embedding + FTS results | `hybrid` | Fused ranking via `hybridRank` |

## Performance Targets

| Operation | Target | Actual (10K docs) |
|-----------|--------|-------------------|
| FTS search | < 50ms | ~5-15ms |
| Vector search | < 10ms | ~2-5ms |
| Hybrid search | < 100ms | ~10-25ms |
| Document index | < 5ms | ~1-3ms |
| Document retrieve | < 1ms | ~0.5ms |
