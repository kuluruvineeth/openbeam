## Applications

|-----|-----------|------|---------------|
| **web** | Next.js 16, React 19 | `:3001` | Frontend SPA — search, chat, agents, mission control |

### Dependency Direction

Dependencies flow strictly downward:

```
apps/* → packages/api → packages/services → packages/db
                ↓               ↓
         packages/temporal  packages/vespa
                ↓               ↓
         packages/redis    packages/storage
                ↓
         packages/types  ← SINGLE SOURCE OF TRUTH
```

### Package Clusters

| Cluster | Packages |
|---------|----------|
| **Platform** | types, config, ui, auth, api |
| **Data Plane** | db, storage, redis, vespa |
| **Workflows** | temporal |
| **AI + Connectors** | ai, services, integrations, media |
