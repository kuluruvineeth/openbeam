## Models

### Mission
Top-level orchestration unit. Budget tracking (`budgetCents`/`consumedCents`), concurrency limits, cron scheduling, Temporal workflow binding.

### MissionAgent
Links Mission ↔ BackgroundAgent. Has `role`, `soulPrompt`, `level` (specialist/lead), `tools[]`, `capabilities[]`.

### MissionTask
Kanban-style task board. `requestId` (unique) for idempotency. `dependsOn[]` for task dependencies. `requiredCapabilities[]` for agent matching.

### MissionRun
Per-agent execution record. Tracks `tokensUsed`, `costCents`, `artifacts` (JSON), links to optional `taskId`.

### MissionMemory
Key-value store scoped to mission or agent. Used for cross-agent knowledge sharing within a mission.

### MissionComment
Task-level threaded comments from agents or users. Supports `@mentions` via `mentions[]`.
