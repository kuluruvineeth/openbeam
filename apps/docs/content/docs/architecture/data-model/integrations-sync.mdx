## Core Models

### Connector (60+ fields)
Central integration point. Tracks status, credentials, sync config, health, rate limits, webhook config, and document counts.

### OAuthProvider (25+ fields)
1:1 with Connector. Manages access/refresh tokens, scopes, sync tokens, and token refresh state.

### SyncJob (30+ fields)
Fencing protocol with `fenceToken` + `lockId`. Tracks progress, phases, items processed/failed, checkpoints.

### IndexedDocument (25+ fields)
Bridge between source systems and Vespa. `vespaId` (unique) links to search index. Tracks checksums for deduplication, sync versioning, soft deletes.

### IndexedFile
Full processing pipeline: PENDING → DOWNLOADING → PARSED → INDEXED. Tracks storage keys, page counts, chunk counts.
