## Workflow: `agentCanvasExecutionWorkflow`

### Node Types

| Type | Activity | Description |
|------|----------|-------------|
| **LLM** | `executeCanvasNode` | AI model invocation with tools |
| **Code** | `executeCanvasNode` | Code execution in sandbox |
| **Approval** | `AgentCanvasApproval` + signal | Human-in-the-loop gate |
| **Loop** | `executeLoopNode` | Iterative execution with exit conditions |
| **Parallel Split** | `executeParallelSplitNode` | Fan-out to multiple branches |
| **Parallel Map** | `executeParallelMapNode` | Map over collection |
| **Parallel Join** | `executeParallelJoinNode` | Aggregate branch results |

### Execution States

`PENDING` → `RUNNING` → `WAITING_APPROVAL` → `RUNNING` → `COMPLETED` / `FAILED` / `CANCELLED` / `TIMED_OUT`

### Session Events

`AgentCanvasSessionEvent` records an ordered log (`sequence` field) with: `eventType`, `source`, `visibility`, `payload`.
