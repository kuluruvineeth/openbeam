## Workflow: `connectorSyncWorkflow`

### Signals
- `pauseSignal` — Pause sync (rate limiting, user request)
- `resumeSignal` — Resume paused sync
- `cancelSignal` — Cancel sync
- `updateConfigSignal` — Update batch size, concurrency

### Query
- `progressQuery` — Returns `SyncState` (stage, processed, indexed, errors, cursor)

### Activity Chain
1. `validateConnection` — Check connector status, token freshness
2. `fetchBatch` — Call connector API with cursor, handle rate limits
3. `transformBatch` — Convert to `GenericDocument` via connector transformer
4. `indexDocuments` — Bulk feed to Vespa with heartbeat
5. `completeSyncJob` — Update `SyncHistory` with metrics

### Error Handling
- **AuthorizationError** → Non-retryable, mark `AUTH_EXPIRED`
- **RateLimitError** → Retryable with `nextRetryDelay`
- **TransientError** → Automatic retry with exponential backoff

### continueAsNew
Triggered when `workflowInfo().historyLength > 10_000` to prevent history bloat.
