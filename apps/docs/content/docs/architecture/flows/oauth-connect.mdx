## Flow

1. **User clicks Connect** — UI generates state with userId, nonce, timestamp
2. **Redirect** — Browser redirected to provider's authorization URL with scopes
3. **Authorization** — User grants access at provider (Google, Slack, GitHub, etc.)
4. **Callback** — Provider redirects to `/auth/callback/:provider` with auth code
5. **State Verification** — Validate CSRF state (userId match, nonce, freshness under 5 min)
6. **Token Exchange** — Server exchanges auth code for access/refresh tokens
7. **Encryption** — Tokens encrypted at rest (`encryptedCredentials`, `accessTokenIv`)
8. **Storage** — Create/update `Connector` + `OAuthProvider` records
9. **Sync Trigger** — Start `connectorSyncWorkflow` for initial full sync

## Security

- State parameter: `{userId, nonce: crypto.randomUUID(), timestamp: Date.now()}`
- Timing-safe comparison for state verification
- Tokens never appear in workflow history (fetched by activities from DB)
- Token refresh tracked: `tokenRefreshedAt`, `refreshFailures`, `refreshError`
