## Feature Modules

| Feature | Path | Description |
|---------|------|-------------|
| **search** | `features/search/` | Hybrid search UI, filters, result ranking |
| **chat** | `features/chat/` | AI assistant with RAG, citations, streaming |
| **agents** | `features/agents/` | Background agent management |
| **mission-control** | `features/mission-control/` | Multi-agent missions, task boards, event feeds |
| **connectors** | `features/connectors/` | Connector setup, OAuth flows, sync status |
| **command-palette** | `features/command-palette/` | Global keyboard-driven navigation |
| **content-preview** | `features/content-preview/` | Document and file previews |
| **file-preview** | `features/file-preview/` | File viewer with parsing status |
| **overview** | `features/overview/` | Dashboard and analytics |
| **sync** | `features/sync/` | Sync job monitoring |

## Technology Stack

| Layer | Technology |
|-------|-----------|
| Framework | Next.js 16 (App Router) |
| UI | React 19, TailwindCSS 4, shadcn/ui, Radix |
| State | Zustand (client), tRPC + React Query (server) |
| URL State | nuqs |
| Icons | HugeIcons via `@openplane/ui` |
| Keyboard | react-hotkeys-hook |
| Animation | Framer Motion (selective) |
