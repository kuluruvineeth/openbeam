## Architecture

The engine is a Python FastAPI service with separate CPU and GPU endpoints for ML workloads.

| Endpoint | Port | Workloads |
|----------|------|-----------|
| **CPU** | `:8000` | Document parsing, text chunking, entity extraction |
| **GPU** | `:8001` | Embedding generation, re-ranking |

## Pipeline Stages

| Stage | Input | Output | Called By |
|-------|-------|--------|-----------|
| **Parse** | Raw document (PDF, DOCX, HTML) | Structured elements, extracted text | `fileProcessingWorkflow` |
| **Chunk** | Extracted text | Semantic chunks with overlap | `fileProcessingWorkflow` |
| **Embed** | Text chunks | Vector embeddings (768/1536-dim) | `reembedWorkflow`, `indexDocumentsWorkflow` |
| **Extract** | Text content | Entities (PERSON, ORG, TOPIC, TECHNOLOGY) | `entityExtractionWorkflow` |
