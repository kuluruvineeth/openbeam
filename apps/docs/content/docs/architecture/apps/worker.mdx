## Task Queues

| Queue | Workflows | Purpose |
|-------|-----------|---------|
| **sync** | `connectorSyncWorkflow` | Full and incremental connector sync |
| **processing** | `fileProcessingWorkflow`, `entityExtractionWorkflow`, `indexDocumentsWorkflow`, `mediaProcessingWorkflow` | Document parsing, entity extraction, Vespa indexing |
| **canvas** | `agentCanvasExecutionWorkflow` | Agent canvas node execution |
| **mission** | `missionOrchestratorWorkflow`, `missionAgentRunWorkflow`, `sharedAgentPoolWorkflow` | Multi-agent mission orchestration |
| **scheduled** | `cleanupWorkflow`, `digestDeliveryWorkflow`, `emergenceDetectionWorkflow`, `ltrTrainingWorkflow`, `reembedWorkflow`, `knowledgeInferenceWorkflow` | Cron-based maintenance |
| **webhooks** | `webhookHandlerWorkflow` | External webhook processing |
| **agents** | `backgroundAgentWorkflow` | Long-running autonomous agents |
