## Architecture

The docs app runs on [Fumadocs](https://fumadocs.vercel.app/) with MDX content and custom components.

| Layer | Technology |
|-------|-----------|
| Framework | Next.js via Fumadocs |
| Content | MDX with frontmatter |
| Diagrams | Excalidraw (interactive, theme-aware) |
| Navigation | Auto-generated from `meta.json` |

## Custom MDX Components

| Component | Usage |
|-----------|-------|
| `ExcalidrawViewer` | Interactive Excalidraw diagrams with pan/zoom |
| `Mermaid` | Fallback diagram renderer (dormant) |
| `TypeTable` | API type documentation tables |
| `Steps` | Step-by-step guides |
| `Tabs` | Tabbed content sections |
| `Callout` | Info/warning/error callouts |
| `Files` | File tree visualization |
