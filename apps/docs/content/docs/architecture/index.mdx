OpenPlane is an enterprise search and AI platform. It connects to SaaS tools, IoT devices, and industrial systems, indexes everything, and makes it searchable with AI-powered answers.

## How It Works

1. **Connect** — OAuth or API key into Slack, Gmail, Notion, Linear, GitHub, MQTT, OPC-UA, and 20+ sources
2. **Sync** — Temporal workflows fetch, transform, chunk, embed, and index documents into Vespa
3. **Search** — Hybrid BM25 + semantic search with permission-aware filtering
4. **Answer** — AI agents ground answers in your data with citations

## Tech Stack

| Layer | Technology |
|-------|------------|
| Language | TypeScript 5.8+, Zod 4, Go 1.24 (CLI) |
| Frontend | Next.js 16, React 19, TailwindCSS 4 |
| API | Hono, tRPC 11, SuperJSON |
| Orchestration | Temporal (durable workflows) |
| Search | Vespa (hybrid BM25 + semantic vectors) |
| Database | PostgreSQL + Prisma |
| Cache | Redis |
| AI | Vercel AI SDK (Claude, GPT, Gemini) |
| Storage | S3/R2 |
| Edge | SQLite (bun:sqlite), FTS5 + vector |
| Linter | Biome |

## Principles

- **Unidirectional dependencies** — Apps depend on packages, never the reverse
- **Single source of truth** — `@openplane/types` owns all shared types
- **Durable execution** — Temporal workflows for all background processing
- **Agent-native** — Every capability is a composable tool
- **Edge-capable** — Search and AI run offline on SQLite
