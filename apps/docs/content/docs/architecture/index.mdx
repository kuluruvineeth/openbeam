## How It Works

1. **Connect** — OAuth into Slack, Gmail, Notion, Linear, Google Drive, and 100+ apps
2. **Sync** — Temporal workflows fetch, transform, and index documents into Vespa
3. **Search** — Hybrid semantic + keyword search with permission-aware filtering
4. **Answer** — AI agents ground answers in your company's data with citations

## Tech Stack

| Layer | Technology |
|-------|------------|
| Frontend | Next.js 16, React 19, TailwindCSS 4 |
| API | Hono, tRPC 11 |
| Orchestration | Temporal (durable workflows) |
| Search | Vespa (hybrid semantic + keyword) |
| Database | PostgreSQL + Prisma |
| Cache | Redis |
| AI | Vercel AI SDK, Claude, OpenAI embeddings |
| Storage | S3/R2 |

## System Boundary

| Component | Port | Purpose |
|-----------|------|---------|
| **web** | `:3001` | Next.js frontend |
| **server** | `:3000` | Hono API server |
| **worker** | — | Temporal workers (sync, agents, processing) |
| **engine** | `:8000` / `:8001` | Python ML service (CPU/GPU) |
| **docs** | `:4000` | Documentation site |

## Principles

- **Unidirectional dependencies** — Apps depend on packages, never the reverse
- **Single source of truth** — `@openplane/types` owns all shared types
- **Durable execution** — Temporal workflows for all background processing
- **Agent-native** — Every capability is a composable tool
