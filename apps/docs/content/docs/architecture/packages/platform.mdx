## @openplane/types

Single source of truth for all shared type definitions. Zod-first schemas with inferred TypeScript types.

| Sub-path | Content |
|----------|---------|
| `types/ai` | Tool definitions, agent patterns, RAG types |
| `types/db` | Database model types |
| `types/temporal` | Workflow/activity input/output schemas |
| `types/services/connectors/*` | Per-connector sync cursors, transform contexts |
| `types/search` | Search result types |
| `types/sync` | Sync status enums |
| `types/mission-control` | Mission runtime types |

## @openplane/api

tRPC 11 routers with SuperJSON serialization. Routers: search, connectors, sync, ai, canvas, mission-control.

## @openplane/auth

Session-based authentication. Models: User, Session, Account. OAuth2 callback handling.

## @openplane/ui

Shared React components: shadcn/ui primitives, HugeIcons registry, CVA variants, Zustand stores with storage adapters.
