## @openplane/ai

### Agent Patterns

| Pattern | Usage |
|---------|-------|
| `LlmAgent` | Single LLM with tools (ReAct loop) |
| `SequentialAgent` | Pipeline: A → B → C |
| `ParallelAgent` | Concurrent execution, aggregate results |
| `CoordinatorAgent` | Route to sub-agents by condition |
| `LoopAgent` | Repeat until stop condition |
| `GeneratorCriticAgent` | Generate → Critique → Refine |

| Component | Purpose |
|-----------|---------|
| `ToolRegistry` | Singleton registry, multi-execute, search |
