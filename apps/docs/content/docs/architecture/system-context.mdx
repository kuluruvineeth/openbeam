## External Actors

### Users

| Actor | Interaction |
|-------|-------------|
| **Team Members** | Search, chat, browse connected data via web UI |
| **Team Admins** | Configure connectors, manage permissions, view analytics |
| **API Consumers** | Programmatic access via API keys with scoped permissions |
| **Slack Users** | Ask questions via Slack assistant, receive digest notifications |

### SaaS Connectors (112 App Types)

OpenPlane connects to enterprise data across 15 categories:

| Category | Connectors |
|----------|-----------|
| **Messaging** | Slack, Microsoft Teams, Discord, WhatsApp |
| **Email** | Gmail, Outlook |
| **Storage** | Google Drive, OneDrive, SharePoint, Dropbox, Box |
| **Docs** | Notion, Confluence, Coda |
| **PM** | Jira, Asana, Trello, ClickUp, Linear, Monday, Basecamp |
| **Code** | GitHub, GitLab, Bitbucket |
| **CRM** | Salesforce, HubSpot, Pipedrive, Zoho |
| **Support** | Zendesk, Intercom, Freshdesk, ServiceNow |
| **Finance** | Stripe, Xero, QuickBooks, NetSuite, Sage |
| **Data** | Snowflake, BigQuery, Redshift, Databricks, Tableau, Looker |
| **Identity** | Okta, Azure AD, Google Workspace |
| **Collaboration** | Airtable, Figma, Miro, Loom, Zoom |

### AI Providers

| Provider | Usage |
|----------|-------|
| **Anthropic** | Claude for RAG, agents, entity extraction |
| **OpenAI** | Embeddings, fallback generation |

### Infrastructure

| Service | Role |
|---------|------|
| **PostgreSQL** | Primary data store (19 Prisma schema files, 60+ models) |
| **Redis** | Cache, pub/sub, distributed locks, rate limiting |
| **Vespa** | Hybrid search (semantic + keyword), document indexing |
| **S3/R2** | File and media storage |
| **Temporal** | Durable workflow orchestration (20+ workflow types) |
