# CLI Workflows

Practical recipes for everyday tasks. Each workflow shows the full command sequence from start to finish.

## Search Workflows

### Find and filter documents

```bash
# Search across all sources
openbeam search query --query "quarterly revenue report"

# Filter by connector type
openbeam search query --query "API docs" --connector-type notion --connector-type confluence

# Search with a specific ranking profile
openbeam search query --query "deployment checklist" --ranking enterprise_v2

# Search recent content
openbeam search recent --days 7

# Find similar documents
openbeam search similar --id "doc_abc123"

# Search media (video transcripts, recordings)
openbeam search media --query "product roadmap discussion"
```

### Process search results

```bash
# Extract just titles
openbeam search query --query "onboarding" --jq '.items[].title'

# Count results
openbeam search query --query "API" --jq '.items | length'

# Export to JSON file
openbeam search query --query "architecture" --output json > results.json

# Format with Go templates
openbeam search query --query "bugs" --template '\{{.title}} (\{{.connectorType}})'
```

## Connector Management

### Set up a new connector

```bash
# List available connectors
openbeam connectors list

# Connect with OAuth2 (opens browser for auth flow)
openbeam connectors connect --type slack

# Connect with API key
openbeam connectors connect --type samsara --api-key "samsara_api_xxxx"

# Check connector status
openbeam connectors status --id "conn_abc123"
```

### Sync operations

```bash
# Trigger full sync
openbeam connectors sync --id "conn_abc123" --mode full

# Trigger incremental sync
openbeam connectors sync --id "conn_abc123" --mode incremental

# View sync history
openbeam connectors history --id "conn_abc123" --limit 5

# Pause and resume sync
openbeam connectors pause --id "conn_abc123"
openbeam connectors resume --id "conn_abc123"
```

### Resource-level control

```bash
# List available resources (channels, repos, etc.)
openbeam connectors resources --id "conn_abc123"

# Enable/disable specific resources
openbeam connectors resource-sync --id "conn_abc123" --resource "channel_general" --enabled true
```

## AI Workflows

### Ask questions with RAG

```bash
# One-shot question grounded in your data
openbeam rag ask --query "What were the Q3 OKR results?"

# Stream the answer token by token
openbeam rag stream --query "Summarize the deployment runbook"

# Multi-turn conversation
openbeam rag conversations create --name "Q3 Review"
openbeam rag ask --conversation "conv_abc" --query "What was revenue?"
openbeam rag ask --conversation "conv_abc" --query "How does that compare to Q2?"

# List and manage conversations
openbeam rag conversations list
openbeam rag conversations delete --id "conv_abc"
```

### Run agents

```bash
# Execute an agent
openbeam agent run --agent "research" --input "Find all docs about auth flow"

# Stream agent events (SSE)
openbeam agent stream --agent "research" --input "Analyze API usage patterns"
```

### Background agents

```bash
# Create an autonomous background agent
openbeam background-agents create --name "weekly-report" --agent "research" --schedule "0 9 * * 1"

# Monitor running agents
openbeam background-agents list
openbeam background-agents logs --id "ba_abc123" --follow

# Pause and resume
openbeam background-agents pause --id "ba_abc123"
openbeam background-agents resume --id "ba_abc123"
```

## Knowledge Graph

```bash
# Search entities (people, teams, projects)
openbeam knowledge search --query "frontend team"

# Get entity details
openbeam knowledge get --id "entity_abc123"

# Find subject matter experts
openbeam knowledge experts --topic "kubernetes"

# View entity relationships
openbeam knowledge relations --id "entity_abc123"
```

## MCP Integration

Use the CLI as an MCP server for AI editors and external agents.

```bash
# Start MCP server (stdin/stdout JSON-RPC 2.0)
openbeam mcp serve

# List available MCP tools
openbeam mcp tools list

# Call a tool directly (useful for testing)
openbeam mcp tools call --name "search_hybrid" --args '\{"query": "test"\}'
```

### Configure in AI editors

Add to your editor's MCP configuration:

```json
{
  "mcpServers": {
    "openbeam": {
      "command": "openbeam",
      "args": ["mcp", "serve"]
    }
  }
}
```

## Automation Recipes

### Monitor connector health

```bash
# Check all connectors, alert on errors
openbeam connectors list --output json | \
  openbeam --jq '[.items[] | select(.status == "error")] | length' | \
  xargs -I {} test {} -eq 0 || echo "ALERT: Connectors in error state"
```

### Batch operations with scripting

```bash
# Trigger incremental sync on all active connectors
openbeam connectors list --jq '.items[] | select(.status == "active") | .id' | \
  while read id; do
    openbeam connectors sync --id "$id" --mode incremental
  done
```

### CI/CD integration

```bash
# In CI: verify search index health before deploy
export OPENBEAM_API_KEY="$CI_OPENBEAM_KEY"
export OPENBEAM_HOST="https://openbeam.internal"

# Search for deployment docs (exit 1 if none found)
count=$(openbeam search query --query "deployment runbook" --jq '.items | length')
if [ "$count" -eq 0 ]; then
  echo "No deployment docs found — check connector sync"
  exit 1
fi
```

## Environment Setup

### Multiple environments

```bash
# Set up production profile
openbeam config set --host https://openbeam.example.com
openbeam auth login --api-key "op_prod_key"

# Set up staging profile
openbeam config use staging
openbeam config set --host https://staging.openbeam.example.com
openbeam auth login --api-key "op_staging_key"

# Switch between environments
openbeam config use production
openbeam config use staging

# List all profiles
openbeam config profiles
```

### Debug API calls

```bash
# Trace HTTP requests and responses
openbeam search query --query "test" --trace

# Enable debug output
openbeam search query --query "test" --debug
```
