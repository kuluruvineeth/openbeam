# Command Reference

The CLI is organized into command groups. Mutation commands (create, delete, sync, pause) require `--yes` in non-interactive mode.

## search

Search indexed content across all connected data sources.

### search query

Search documents with filters and ranking.

```bash
openplane search query -q "quarterly report" --connector-type slack,notion --limit 10
```

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `-q`, `--query` | string | | Search query text |
| `--connector-type` | string[] | | Filter by connector type |
| `--connector-id` | string | | Filter by connector ID |
| `--document-type` | string[] | | Filter by document type |
| `--source-type` | string[] | | Filter by source type |
| `--status` | string[] | | Filter by status |
| `--priority` | string[] | | Filter by priority |
| `--label` | string[] | | Filter by label |
| `--author-id` | string | | Filter by author ID |
| `--source-id` | string | | Filter by source ID |
| `--from-date` | int64 | `0` | Filter results after this timestamp |
| `--to-date` | int64 | `0` | Filter results before this timestamp |
| `--limit` | int | `20` | Maximum results to return |
| `--offset` | int | `0` | Pagination offset |
| `--ranking` | string | `hybrid` | Ranking strategy |

### search hybrid

Hybrid search with explicit control over BM25, dense, and sparse vector weights.

```bash
openplane search hybrid -q "deployment process" --weight-bm25 0.3 --weight-dense 0.5 --weight-sparse 0.2
```

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `-q`, `--query` | string | | Search query text |
| `--mode` | string | `hybrid_v2` | Hybrid search mode |
| `--rrf-k` | int | `60` | RRF constant k parameter |
| `--weight-bm25` | float64 | `0.4` | BM25 ranking weight |
| `--weight-dense` | float64 | `0.4` | Dense vector ranking weight |
| `--weight-sparse` | float64 | `0.2` | Sparse vector ranking weight |
| `--connector-type` | string[] | | Filter by connector type |
| `--document-type` | string[] | | Filter by document type |
| `--source-id` | string[] | | Filter by source ID |
| `--from-date` | int64 | `0` | Filter after timestamp |
| `--to-date` | int64 | `0` | Filter before timestamp |
| `--limit` | int | `20` | Maximum results |
| `--offset` | int | `0` | Pagination offset |

### search recent

Retrieve recently indexed documents.

```bash
openplane search recent --hours 48 --limit 10
```

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--hours` | int | `24` | Lookback window in hours |
| `--limit` | int | `20` | Maximum results |

### search similar

Find documents similar to a given document.

```bash

```

| Flag | Type | Default | Required |
|------|------|---------|----------|
| `--document-id` | string | | Yes |
| `--limit` | int | `10` | No |

### search thread

```bash

```

| Flag | Type | Required |
|------|------|----------|
| `--thread-id` | string | Yes |

### search author


| Flag | Type | Default | Required |
|------|------|---------|----------|
| `--author-id` | string | | Yes |
| `--limit` | int | `50` | No |

### search media

Search media content (video, audio).

```bash

```

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `-q`, `--query` | string | | Search query text |
| `--connector-id` | string | | Filter by connector ID |
| `--source-id` | string | | Filter by source ID |
| `--media-type` | string | | Filter by media type |

## auth

Authentication and API key management.

### auth login

Store an API key for the active profile.

```bash
openplane auth login --api-key "op_..."
```

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--api-key` | string | | API key value |
| `--skip-verify` | bool | `false` | Skip server-side verification |

### auth logout

Remove the API key for the active profile.

```bash
openplane auth logout --yes
```

### auth status

Show authentication status for the active profile.

```bash
openplane auth status --verify
```

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--verify` | bool | `false` | Verify key against server |

### auth token print

Print the active API key (redacted by default).

```bash
openplane auth token print
openplane auth token print --redact=false
```

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--redact` | bool | `true` | Redact token output |

### auth key list

List API keys for a team.

```bash
openplane auth key list --team-id "team_abc"
```

| Flag | Type | Description |
|------|------|-------------|
| `--team-id` | string | Team identifier (defaults to active profile team) |

### auth key create

Create an API key.

```bash
openplane auth key create --name "CI Pipeline" --scope read:search --scope write:connectors --yes
```

| Flag | Type | Required | Description |
|------|------|----------|-------------|
| `--name` | string | Yes | API key name |
| `--team-id` | string | No | Team identifier |
| `--scope` | string[] | No | Scope values |
| `--expires-at` | string | No | Expiration in RFC3339 format |

### auth key revoke

Revoke an API key.

```bash
openplane auth key revoke --id "key_abc" --yes
```

| Flag | Type | Required | Description |
|------|------|----------|-------------|
| `--id` | string | Yes | API key identifier |
| `--team-id` | string | No | Team identifier |

## connectors

Manage data source connectors: list, connect, sync, pause, and disconnect.

### connectors list

List all connector apps and their installation status.

```bash
openplane connectors list
```

### connectors get

Get details for a specific connector.

```bash
openplane connectors get --id "conn_abc"
```

| Flag | Type | Required |
|------|------|----------|
| `--id` | string | Yes |

### connectors connect

Create a new connector installation.

```bash
openplane connectors connect \
  --app-id "slack" \
  --workspace-external-id "T0123456" \
  --name "Engineering Slack" \
  --type SOURCE \
  --auth-type OAUTH2 \
  --yes
```

| Flag | Type | Default | Required | Description |
|------|------|---------|----------|-------------|
| `--app-id` | string | | Yes | Connector app ID |
| `--workspace-external-id` | string | | Yes | Workspace external ID |
| `--name` | string | | Yes | Display name |
| `--type` | string | `SOURCE` | No | Connector type |
| `--auth-type` | string | `OAUTH2` | No | Authentication type |
| `--config` | string | `{}` | No | Config JSON object |

### connectors update

Update connector settings.

```bash
openplane connectors update --id "conn_abc" --config '{"syncInterval": 3600}' --yes
```

| Flag | Type | Required |
|------|------|----------|
| `--id` | string | Yes |
| `--config` | string | No |

### connectors sync

Trigger a sync on a connector.

```bash
openplane connectors sync --id "conn_abc" --type FULL --yes
```

| Flag | Type | Default | Required |
|------|------|---------|----------|
| `--id` | string | | Yes |
| `--type` | string | `FULL` | No |

### connectors status

Get the current sync status.

```bash
openplane connectors status --id "conn_abc"
```

### connectors history

View sync history with pagination.

```bash
openplane connectors history --id "conn_abc" --limit 10
```

| Flag | Type | Default |
|------|------|---------|
| `--id` | string | (required) |
| `--limit` | int | `20` |
| `--offset` | int | `0` |

### connectors pause / resume

Pause or resume a connector.

```bash
openplane connectors pause --id "conn_abc" --yes
openplane connectors resume --id "conn_abc" --yes
```

### connectors disconnect

Schedule a connector for disconnection.

```bash
openplane connectors disconnect --id "conn_abc" --yes
```

### connectors resources

List resources (channels, repositories, folders) for a connector.

```bash
openplane connectors resources --id "conn_abc" --search "engineering" --limit 50
```

| Flag | Type | Default |
|------|------|---------|
| `--id` | string | (required) |
| `--search` | string | |
| `--cursor` | string | |
| `--limit` | int | `50` |

### connectors resource-sync

Toggle sync for a specific resource.

```bash
openplane connectors resource-sync --resource-id "res_abc" --enabled=true --yes
```

| Flag | Type | Default | Required |
|------|------|---------|----------|
| `--resource-id` | string | | Yes |
| `--enabled` | bool | `true` | No |

## rag

RAG (Retrieval-Augmented Generation) workflows.

### rag ask

Ask a question and get a grounded answer with citations.

```bash
openplane rag ask -q "What is our SLA for enterprise customers?"
```

| Flag | Type | Default | Required |
|------|------|---------|----------|
| `-q`, `--query` | string | | Yes |
| `--conversation-id` | string | | No |
| `--model-id` | string | | No |
| `--temperature` | float64 | `0` | No |
| `--include-media` | bool | `true` | No |
| `--source-id` | string | | No |

### rag stream

Stream a RAG response via SSE.

```bash
openplane rag stream -q "How does our auth system work?" --output ndjson
```

Accepts the same flags as `rag ask`.

### rag conversations

Manage RAG conversation sessions.

```bash
# Create a conversation
openplane rag conversations create --yes

# List conversations
openplane rag conversations list --status active

# Get conversation details
openplane rag conversations get --id "conv_abc"

# Delete a conversation
openplane rag conversations delete --id "conv_abc" --yes
```

## background-agents

Manage long-running autonomous agents.

### background-agents list / get

```bash
openplane background-agents list --status running
openplane background-agents get --id "ba_abc"
```

### background-agents create

```bash
openplane background-agents create \
  --name "Nightly Research" \
  --prompt "Monitor competitor releases and summarize changes" \
  --preset researcher \
  --sandbox-type daytona \
  --yes
```

| Flag | Type | Default | Required |
|------|------|---------|----------|
| `--name` | string | | Yes |
| `--prompt` | string | | Yes |
| `--description` | string | | No |
| `--preset` | string | `researcher` | No |
| `--sandbox-type` | string | `daytona` | No |
| `--repository-url` | string | | No |
| `--base-branch` | string | | No |
| `--timeout-ms` | int | `0` | No |

### background-agents pause / resume / cancel / delete

```bash
openplane background-agents pause --id "ba_abc" --yes
openplane background-agents resume --id "ba_abc" --yes
openplane background-agents resume --id "ba_abc" --from-checkpoint 3 --yes
openplane background-agents cancel --id "ba_abc" --yes
openplane background-agents delete --id "ba_abc" --yes
```

### background-agents logs

View or follow agent logs.

```bash
# Fetch logs
openplane background-agents logs --id "ba_abc" --level error --limit 50

# Follow logs (poll every 2s)
openplane background-agents logs --id "ba_abc" --follow --interval 5s
```

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--id` | string | | Agent identifier (required) |
| `--level` | string | | Log level filter |
| `--limit` | int | `100` | Page size |
| `--offset` | int | `0` | Pagination offset |
| `--follow` | bool | `false` | Follow logs |
| `--interval` | duration | `2s` | Follow poll interval |

## permissions

Manage document permissions, access controls, and cache.

```bash
# Permission sync status
openplane permissions sync-status --connector-id "conn_abc"
openplane permissions sync-statuses

# Current user permissions
openplane permissions me

# Document permissions
openplane permissions document --document-id "doc_abc"

# User group memberships and scopes
openplane permissions groups --user-id "user_abc"
openplane permissions scopes --user-id "user_abc"

# Team-wide stats
openplane permissions stats

# Invalidate permission cache
openplane permissions invalidate --scope all --yes
openplane permissions invalidate --scope user --user-id "user_abc" --yes
openplane permissions invalidate --scope connector --connector-id "conn_abc" --yes
```
