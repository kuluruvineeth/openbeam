# Command Reference

Every command follows the pattern `openplane <resource> <action> [flags]`. Mutation commands (create, delete, sync) require `--yes` in non-interactive mode.

## search

Search across all indexed content. 8 subcommands covering text search, hybrid retrieval, media, and author-based queries.

### search query

Search documents with filters across connector types, date ranges, labels, and ranking strategies.

```bash
openplane search query --query "deployment checklist" --limit 10
```

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--query`, `-q` | string | | Search query text |
| `--connector-type` | string[] | | Filter by connector type (repeatable) |
| `--connector-id` | string | | Filter by connector ID |
| `--document-type` | string[] | | Filter by document type (repeatable) |
| `--source-type` | string[] | | Filter by source type (repeatable) |
| `--status` | string[] | | Filter by status (repeatable) |
| `--priority` | string[] | | Filter by priority level (repeatable) |
| `--label` | string[] | | Filter by label (repeatable) |
| `--author-id` | string | | Filter by author ID |
| `--source-id` | string | | Filter by source ID |
| `--from-date` | int64 | `0` | Filter results after this timestamp |
| `--to-date` | int64 | `0` | Filter results before this timestamp |
| `--limit` | int | `20` | Maximum results to return |
| `--offset` | int | `0` | Results offset for pagination |
| `--ranking` | string | `hybrid` | Ranking strategy |

```bash
# Search Slack messages from a specific connector
openplane search query -q "launch plan" --connector-type slack --limit 5

# Search with date range
openplane search query -q "Q4 report" --from-date 1696118400 --to-date 1704067200
```

### search hybrid

Advanced hybrid search with configurable RRF (Reciprocal Rank Fusion) weights for BM25, dense, and sparse retrieval.

```bash
openplane search hybrid -q "machine learning pipeline" --weight-bm25 0.3 --weight-dense 0.5 --weight-sparse 0.2
```

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--query`, `-q` | string | | Search query text |
| `--mode` | string | `hybrid_v2` | Hybrid search mode |
| `--rrf-k` | int | `60` | RRF constant k parameter |
| `--weight-bm25` | float64 | `0.4` | BM25 ranking weight |
| `--weight-dense` | float64 | `0.4` | Dense vector ranking weight |
| `--weight-sparse` | float64 | `0.2` | Sparse vector ranking weight |
| `--connector-type` | string[] | | Filter by connector type |
| `--document-type` | string[] | | Filter by document type |
| `--source-id` | string[] | | Filter by source ID |
| `--from-date` | int64 | `0` | Start timestamp |
| `--to-date` | int64 | `0` | End timestamp |
| `--limit` | int | `20` | Maximum results |
| `--offset` | int | `0` | Pagination offset |

## auth

### auth login


| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--api-key` | string | | API key value |
