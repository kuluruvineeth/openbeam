# MCP Server

OpenBeam ships an MCP (Model Context Protocol) server that gives AI assistants access to your enterprise knowledge — 103+ connectors, hybrid search, RAG answers, and agent execution.

<Callout type="info">
  The MCP server runs locally on your machine and connects to your OpenBeam instance. No additional server deployment needed.
</Callout>

## Setup

### Claude Desktop

Edit `~/Library/Application Support/Claude/claude_desktop_config.json` (macOS) or `%APPDATA%\Claude\claude_desktop_config.json` (Windows):

```json
{
  "mcpServers": {
    "openbeam": {
      "command": "npx",
      "args": ["-y", "@openbeam/mcp-server"],
      "env": {
        "MCP_API_KEY": "your-api-key",
        "DATABASE_URL": "postgresql://...",
        "VESPA_URL": "http://localhost:8080"
      }
    }
  }
}
```

Restart Claude Desktop after saving.

### Claude Code

```bash
claude mcp add openbeam -- npx -y @openbeam/mcp-server
```

Or add to `.claude/settings.json`:

```json
{
  "mcpServers": {
    "openbeam": {
      "command": "npx",
      "args": ["-y", "@openbeam/mcp-server"],
      "env": {
        "MCP_API_KEY": "your-api-key"
      }
    }
  }
}
```

### Cursor

Add to `.cursor/mcp.json` in your project root:

```json
{
  "mcpServers": {
    "openbeam": {
      "command": "npx",
      "args": ["-y", "@openbeam/mcp-server"],
      "env": {
        "MCP_API_KEY": "your-api-key"
      }
    }
  }
}
```

### Windsurf / Codex / Any MCP Host

Run the stdio transport directly:

```bash
MCP_API_KEY=your-api-key npx -y @openbeam/mcp-server
```

## Environment Variables

| Variable | Required | Description |
|----------|----------|-------------|
| `MCP_API_KEY` | Yes | API key from OpenBeam Settings > API Keys |
| `DATABASE_URL` | Self-hosted only | PostgreSQL connection string |
| `VESPA_URL` | Self-hosted only | Vespa search endpoint |
| `REDIS_URL` | No | Redis for rate limiting and caching |

<Callout type="warn">
  For OpenBeam Cloud users, only `MCP_API_KEY` is needed. The server connects to the hosted API automatically.
</Callout>

## Available Tools

Once connected, your AI assistant can use these tools:

### Search

| Tool | Description |
|------|-------------|
| `search_documents` | Hybrid semantic + keyword search across all connected sources |
| `search_people` | Find experts by name, email, department, or expertise |
| `get_document` | Retrieve full document content by ID |
| `get_related` | Find related documents by similarity or knowledge graph |

### Knowledge

| Tool | Description |
|------|-------------|
| `ask_question` | RAG-powered Q&A with citations from enterprise data |
| `list_connectors` | List all connected data sources and their sync status |
| `get_connector_stats` | Get detailed statistics for a connector |

### Agents

| Tool | Description |
|------|-------------|
| `run_agent` | Start an autonomous research or analysis agent |
| `deep_research` | Multi-step research across all enterprise sources |
| `get_job_status` | Check progress of async agent jobs |

## Resources

The server exposes enterprise data as browsable MCP resources:

| URI Pattern | Description |
|-------------|-------------|
| `openbeam://resources/{teamId}/` | Synced enterprise documents |
| `openbeam://user/{teamId}/{userId}/memories/` | User knowledge and preferences |
| `openbeam://agent/{teamId}/{agentId}/skills/` | Agent learned capabilities |
| `openbeam://tools/{teamId}/` | Available tool definitions |

## Authentication

The server supports three authentication modes, checked in order:

1. **API Key** (recommended) — Set `MCP_API_KEY`
2. **Bearer Token** — Set `MCP_TOKEN` for session-based auth
3. **Environment** — Set `MCP_TEAM_ID` + `MCP_USER_ID` for local development

## Verify It Works

After setup, ask your AI assistant:

> "What connectors are connected to OpenBeam?"

If configured correctly, the assistant will call `list_connectors` and show your connected data sources.

> "Search for our authentication architecture docs"

The assistant will call `search_documents` and return results from Confluence, Notion, Google Drive, or wherever your architecture docs live.

## Troubleshooting

| Issue | Fix |
|-------|-----|
| "Server not found" | Ensure Node.js 18+ is installed: `node --version` |
| "Authentication failed" | Verify `MCP_API_KEY` is correct in Settings > API Keys |
| "No results" | Check that connectors are synced: `list_connectors` tool |
| Server doesn't start | Check Claude Desktop logs: `~/Library/Logs/Claude/mcp*.log` |
