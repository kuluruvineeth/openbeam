# MCP Server

OpenBeam ships a Model Context Protocol (MCP) server that gives AI assistants access to your enterprise knowledge — 88+ connector integrations with write actions, hybrid search, RAG answers, rich UI views, and connector management.

## Quick Setup

### Claude Desktop (Recommended)

Open **Settings > Connectors** in Claude Desktop, then add OpenBeam as a remote MCP server:

```
URL: https://mcp.openbeam.work/mcp
```

Claude will prompt you to authenticate with your OpenBeam account via OAuth.

Alternatively, add to `~/Library/Application Support/Claude/claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "openbeam": {
      "url": "https://api.openbeam.dev/mcp",
      "headers": {
        "Authorization": "Bearer op_live_your_key_here"
      }
    }
  }
}
```

<Callout type="info">
  This connects to the hosted OpenBeam API. You only need an OpenBeam account — no database URLs, no infrastructure setup.
</Callout>

### Claude Code

```bash
claude mcp add --transport http openbeam https://mcp.openbeam.work/mcp
```

Then run `/mcp` in a Claude Code session to authenticate.

### Cursor

Add to `.cursor/mcp.json` in your project root:

```json
{
  "mcpServers": {
    "openbeam": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://mcp.openbeam.work/mcp"]
    }
  }
}
```

### Windsurf / Codex / Any MCP Host

Use the remote MCP URL directly if the host supports HTTP transport:

```
https://mcp.openbeam.work/mcp
```

Or use `mcp-remote` for stdio-based hosts:

```bash
npx -y mcp-remote https://mcp.openbeam.work/mcp
```

## What You Get

Once connected, your AI assistant can:

- **Search** across all connected data sources with hybrid semantic + keyword search
- **Ask questions** with RAG-powered answers and citations
- **Manage connectors** — list, inspect health, connect new sources via OAuth
- **Trigger syncs** — run full or incremental syncs and monitor progress
- **Execute actions** — create issues, send messages, update records across 88+ integrations
- **Browse context** — access the enterprise knowledge graph and context memory

## Verify It Works

After setup, ask your AI assistant:

> "What connectors are connected to OpenBeam?"

The assistant will call `connector_list` and show your connected data sources. If you see connector names, statuses, and document counts, the integration is working.

## Troubleshooting

| Issue | Fix |
|-------|-----|
| "Server not found" | Ensure Node.js 18+ is installed: `node --version` |
| "Authentication failed" | Re-authenticate via OAuth or check your API key |
| "No results" | Check that connectors are synced in the OpenBeam dashboard |
| Connection timeout | Verify `https://mcp.openbeam.work` is reachable |
