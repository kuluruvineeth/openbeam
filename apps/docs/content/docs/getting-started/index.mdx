# Getting Started

## Prerequisites

| Requirement | Version |
|-------------|---------|
| Docker | Latest |
| Docker Compose | v2.0+ |
| Bun | 1.3+ |

## Installation

<Tabs items={["Docker", "Development"]}>
  <Tab value="Docker">
    ```bash
    git clone https://github.com/kuluruvineeth/openplane.git
    cd openplane
    cp .env.example .env
    docker-compose up -d
    ```

    Services:
    - Web UI: http://localhost:3001
    - API: http://localhost:3000
  </Tab>
  <Tab value="Development">
    ```bash
    git clone https://github.com/kuluruvineeth/openplane.git
    cd openplane
    bun install
    bun run db:push
    bun run dev
    ```
  </Tab>
</Tabs>

## Environment

```bash title=".env"
DATABASE_URL=postgresql://postgres:postgres@localhost:5432/openplane
REDIS_URL=redis://localhost:6379
VESPA_URL=http://localhost:8080
```

  <Accordion title="Optional">
