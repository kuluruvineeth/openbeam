# Getting Started

## Requirements

| Component | Version |
|-----------|---------|
| Bun | 1.3+ |
| Python | 3.12+ |
| Docker | Latest |
| PostgreSQL | 14+ |
| Redis | 7+ |
| Vespa | 8+ |

## Quick Start

<Tabs items={["Docker", "Development"]}>
  <Tab value="Docker">
    ```bash
    git clone https://github.com/kuluruvineeth/openplane.git
    cd openplane
    cp .env.example .env
    docker-compose up -d
    ```

    **Services:**
    | Service | URL |
    |---------|-----|
    | Web | http://localhost:3001 |
    | API | http://localhost:3000 |
    | Docs | http://localhost:4000 |
  </Tab>
  <Tab value="Development">
    ```bash
    git clone https://github.com/kuluruvineeth/openplane.git
    cd openplane

    # Install dependencies
    bun install
    cd apps/engine && uv sync && cd ../..

    # Setup database
    bun run db:push

    # Start all services
    bun run dev
    ```
  </Tab>
</Tabs>

## Environment

```bash title=".env"
# Database
DATABASE_URL=postgresql://postgres:postgres@localhost:5432/openplane

# Redis
REDIS_URL=redis://localhost:6379

# Search
VESPA_URL=http://localhost:8080

# AI (at least one required)
OPENAI_API_KEY=sk-...
ANTHROPIC_API_KEY=sk-ant-...

# Auth
AUTH_SECRET=generate-a-secret-key
```

## Commands

| Command | Description |
|---------|-------------|
| `bun run dev` | Start all apps |
| `bun run dev:web` | Web only |
| `bun run dev:server` | Server only |
| `bun run check` | Lint + format |
| `bun run build` | Build all |
| `bun run db:push` | Push schema |
| `bun run db:studio` | Prisma Studio |
