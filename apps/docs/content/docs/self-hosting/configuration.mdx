# Configuration Reference

All configuration is done through environment variables. This page documents every variable used across the application services.

<Callout type="warn">
Never commit secrets to version control. Use a `.env` file or your deployment platform's secret management.
</Callout>

## Generating Secrets

```bash
# JWT_SECRET and ENCRYPTION_KEY (64-char hex strings)
openssl rand -hex 32
```

## Database

| Variable | Required | Default | Used By | Description |
|----------|----------|---------|---------|-------------|
| `DATABASE_URL` | Yes | -- | server, worker | PostgreSQL connection string |
| `POSTGRES_DB` | No | `openplane` | infra compose | Database name |
| `POSTGRES_USER` | No | `postgres` | infra compose | Database user |
| `POSTGRES_PASSWORD` | Yes | `postgres` | infra compose | Database password |

Connection string format:

```
postgresql://<user>:<password>@<host>:5432/<database>
```

Within Docker, use `postgres` as the host (Docker DNS). For external PostgreSQL, use the full hostname.

## URLs

| Variable | Required | Default | Used By | Description |
|----------|----------|---------|---------|-------------|
| `WEB_URL` | Yes | -- | server | Public URL of the web frontend |
| `SERVER_URL` | Yes | -- | server | Public URL of the API server |
| `WEB_APP_URL` | No | Same as `WEB_URL` | server | Alias for web URL |
| `NEXT_PUBLIC_SERVER_URL` | Yes | `http://localhost:3000` | web | API URL (baked at build time) |
| `NEXT_PUBLIC_WEB_URL` | No | -- | web | Web URL (baked at build time) |
| `SERVER_INTERNAL_URL` | No | -- | web | Internal server URL for SSR (bypasses public internet) |
| `CORS_ORIGIN` | No | `http://localhost:3001` | server | Allowed CORS origin |

<Callout type="info">
`NEXT_PUBLIC_*` variables are embedded at build time in the Next.js frontend. If you build the Docker image yourself, pass these as build args. The pre-built GHCR images have default values baked in.
</Callout>

## Object Storage (S3-Compatible)

OpenPlane uses S3-compatible storage for file uploads. Works with MinIO, AWS S3, Cloudflare R2, or any S3-compatible service.

| Variable | Required | Default | Used By | Description |
|----------|----------|---------|---------|-------------|
| `GCS_ENDPOINT` | Yes | `http://localhost:9000` | server, worker | S3 endpoint URL |
| `GCS_ACCESS_KEY_ID` | Yes | -- | server, worker | S3 access key |
| `GCS_SECRET_ACCESS_KEY` | Yes | -- | server, worker | S3 secret key |
| `GCS_BUCKET` | Yes | `openplane-files` | server, worker | Bucket name |
| `GCS_REGION` | No | `us-east-1` | server, worker | S3 region |
| `GCS_PUBLIC_ENDPOINT` | No | -- | server, worker | Public-facing storage URL (for webhooks that need file access) |

Within Docker with MinIO, use `http://minio:9000` as the endpoint.

For MinIO infrastructure setup:

| Variable | Required | Default | Used By | Description |
|----------|----------|---------|---------|-------------|
| `MINIO_ROOT_USER` | No | `openplane-minio` | infra compose | MinIO admin username |
| `MINIO_ROOT_PASSWORD` | Yes | -- | infra compose | MinIO admin password |
| `S3_BUCKET` | No | `openplane-files` | infra compose | Bucket created by init container |
