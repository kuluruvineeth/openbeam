# Configuration Reference

All configuration is done through environment variables set in the `.env` file or directly in the compose files. Variables marked **required** must be set before deployment.

<Callout type="warn">
  Never commit `.env` files to version control. They contain secrets that grant full access to your deployment.
</Callout>

## Security

These secrets protect authentication tokens, encrypted credentials, and session integrity. Generate unique values for each deployment.

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `JWT_SECRET` | Yes | -- | Secret for signing JWT tokens. Generate with `openssl rand -hex 32` |
| `ENCRYPTION_KEY` | Yes | -- | Key for encrypting OAuth tokens at rest. Generate with `openssl rand -hex 32` |
| `COOKIE_DOMAIN` | Yes | -- | Domain for auth cookies (e.g., `.example.com`) |

```bash
# Generate secure values
JWT_SECRET=$(openssl rand -hex 32)
ENCRYPTION_KEY=$(openssl rand -hex 32)
```

## URLs

Define where your services are accessible. These are used for OAuth redirects, CORS, and internal service communication.

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `WEB_URL` | Yes | -- | Public URL for the web frontend (e.g., `https://app.example.com`) |
| `SERVER_URL` | Yes | -- | Public URL for the API server (e.g., `https://api.example.com`) |
| `WEB_APP_URL` | No | Same as `WEB_URL` | Override for the web app URL (used in emails, notifications) |

## Database

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `DATABASE_URL` | Yes | -- | PostgreSQL connection string |
| `POSTGRES_DB` | No | `openplane` | Database name (infra compose) |
| `POSTGRES_USER` | No | `postgres` | Database user (infra compose) |
| `POSTGRES_PASSWORD` | No | `postgres` | Database password (infra compose) |

The `DATABASE_URL` format: `postgresql://user:password@host:port/database`

For the Docker Compose deployment, the default connection string is:

```bash
DATABASE_URL=postgresql://postgres:postgres@postgres:5432/openplane
```

<Callout type="warn">
  Change the default PostgreSQL password in production. The default `postgres:postgres` is only acceptable for local development.
</Callout>

## Redis

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `REDIS_URL` | Yes | `redis://redis:6379` | Redis connection URL |

In the Docker Compose deployment, the app services connect to Redis via Docker DNS at `redis://redis:6379`.

## Search (Vespa)

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `VESPA_URL` | Yes | `http://vespa:8080` | Vespa query endpoint |
| `VESPA_CONFIGSERVERS` | No | `vespa` | Vespa config server hostname (infra compose) |

## Workflow Engine (Temporal)

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `TEMPORAL_ADDRESS` | Yes | `temporal:7233` | Temporal gRPC endpoint |
| `DYNAMIC_CONFIG_FILE_PATH` | No | `/etc/temporal/config/dynamicconfig/development.yaml` | Path to Temporal dynamic config |

Temporal uses PostgreSQL as its persistence backend. It connects using the same `POSTGRES_USER` and `POSTGRES_PASSWORD` variables.

## Object Storage (MinIO / S3)

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `GCS_ENDPOINT` | Yes | `http://minio:9000` | S3-compatible endpoint URL |
| `GCS_ACCESS_KEY_ID` | Yes | -- | S3 access key |
| `GCS_SECRET_ACCESS_KEY` | Yes | -- | S3 secret key |
| `GCS_BUCKET` | Yes | `openplane-files` | Bucket name for file storage |
| `GCS_REGION` | No | `us-east-1` | S3 region |
| `GCS_PUBLIC_ENDPOINT` | No | -- | Public URL for file access (e.g., `https://storage.example.com`) |
| `MINIO_ROOT_USER` | No | `openplane-minio` | MinIO admin username (infra compose) |
| `MINIO_ROOT_PASSWORD` | No | `minioadmin` | MinIO admin password (infra compose) |
| `MINIO_SERVER_URL` | No | `http://localhost:9000` | MinIO server URL for console |
| `MINIO_BROWSER_REDIRECT_URL` | No | `http://localhost:9001` | MinIO browser console URL |
| `S3_BUCKET` | No | `openplane-files` | Bucket name for minio-init container |

## Authentication Providers

At least one OAuth provider must be configured for user login.

### Google OAuth

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `GOOGLE_CLIENT_ID` | Yes | -- | Google OAuth 2.0 client ID |
| `GOOGLE_CLIENT_SECRET` | Yes | -- | Google OAuth 2.0 client secret |

Set up credentials at [Google Cloud Console](https://console.cloud.google.com/apis/credentials). Configure the authorized redirect URI as `{SERVER_URL}/auth/google/callback`.

## AI Providers

Configure one or more AI providers for RAG, agents, and embeddings. At least one provider is required.

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `OPENAI_API_KEY` | Conditional | -- | OpenAI API key |
| `OPENAI_BASE_URL` | No | -- | Custom OpenAI-compatible endpoint |
| `OPENAI_ORGANIZATION` | No | -- | OpenAI organization ID |
| `ANTHROPIC_API_KEY` | Conditional | -- | Anthropic API key |
| `GOOGLE_AI_API_KEY` | Conditional | -- | Google AI (Gemini) API key |

<Callout type="info">
  At least one AI provider API key is required. OpenAI is recommended as the default provider for embeddings.
</Callout>

## Example .env File

A complete example for a production deployment:

```bash
# Security
JWT_SECRET=your_64_char_hex_string_here
ENCRYPTION_KEY=your_64_char_hex_string_here
COOKIE_DOMAIN=.example.com

# URLs
WEB_URL=https://app.example.com
SERVER_URL=https://api.example.com

# Database
DATABASE_URL=postgresql://postgres:a_strong_password_here@postgres:5432/openplane
POSTGRES_PASSWORD=a_strong_password_here

# Object Storage
GCS_ENDPOINT=http://minio:9000
GCS_ACCESS_KEY_ID=openplane-minio
GCS_SECRET_ACCESS_KEY=a_strong_minio_password_here
GCS_BUCKET=openplane-files
GCS_REGION=us-east-1
GCS_PUBLIC_ENDPOINT=https://storage.example.com
MINIO_ROOT_USER=openplane-minio
MINIO_ROOT_PASSWORD=a_strong_minio_password_here

# Auth
GOOGLE_CLIENT_ID=123456789.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=GOCSPX-xxxxxxxxxxxxxxxxxxxx

# AI
OPENAI_API_KEY=sk-xxxxxxxxxxxxxxxxxxxx
ANTHROPIC_API_KEY=sk-ant-xxxxxxxxxxxxxxxxxxxx

# Monitoring
GRAFANA_PASSWORD=a_strong_grafana_password_here
```

<Callout type="info">
  Generate unique secrets for every deployment. Reusing secrets across environments is a security risk.
</Callout>
