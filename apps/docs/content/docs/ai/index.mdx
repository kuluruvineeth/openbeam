# AI & Agents

OpenPlane is built agent-native. Every capability -- search, document retrieval, connector management, data analysis -- is a tool. Tools compose into agents. Agents orchestrate complex workflows autonomously. New capabilities emerge from prompts, not code.

## The Five Principles

| Principle | What It Means |
|-----------|---------------|
| **Parity** | Whatever users do in the UI, agents achieve through tools. No capability is human-only. |
| **Granularity** | Tools are atomic primitives. Judgment lives in agents, not tools. |
| **Composability** | New features emerge from prompt composition, not new code. |
| **Emergence** | Agents accomplish unanticipated tasks by combining tools in novel ways. |
| **Improvement** | The platform improves through context accumulation, not deploys. |

## Quick Start

Create an agent with search capabilities in 10 lines:

```typescript
import { createLlmAgent, createEmptyState } from "@openplane/ai";

const agent = createLlmAgent({
  type: "llm",
  name: "search-assistant",
  systemPrompt: "You are an enterprise search assistant. Use tools to find information.",
  tools: ["search_hybrid", "doc_get", "rag_answer"],
  maxSteps: 10,
});

const result = await agent.execute("Find our Q3 revenue report", {
  teamId: "team_123",
  userId: "user_456",
  state: createEmptyState(),
});

console.log(result.output);        // The agent's response
console.log(result.totalTokens);   // { inputTokens: 2340, outputTokens: 512 }
console.log(result.durationMs);    // 1847
console.log(result.trace);         // Full execution trace with tool calls
```

The agent receives the user's query, searches for relevant documents using `search_hybrid`, retrieves full content with `doc_get`, generates a grounded answer via `rag_answer`, and returns the result with citations.
