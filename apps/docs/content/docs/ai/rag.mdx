# RAG Pipeline

The RAG (Retrieval-Augmented Generation) pipeline grounds LLM answers in source documents. It handles query analysis, chunk reranking, answer generation, citation extraction, and claim verification.

## Architecture

```
User Query
    │
    ▼
┌──────────────────┐
│  Query Analyzer   │  Intent classification, entity extraction,
│                    │  temporal context, keyword extraction
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│  Chunk Reranking  │  Score and reorder retrieved chunks
│                    │  by relevance to the analyzed query
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│  Context Builder  │  Build prompt context with citation map,
│                    │  token budget management
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│  LLM Generation   │  Generate answer with source citations
│                    │  using CompletionService
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│  Grounding        │  Verify claims against source chunks,
│  Verification     │  compute confidence scores
└──────────────────┘
```

## Quick Start

```typescript
import { answerWithRAG, streamRAGAnswer } from "@openplane/ai";
import type { RAGChunk } from "@openplane/types/ai";

const chunks: RAGChunk[] = [
  {
    id: "chunk_1",
    content: "OpenPlane uses Vespa for hybrid search combining BM25 and vector similarity.",
    documentId: "doc_architecture",
    documentTitle: "Architecture Overview",
    documentUrl: "https://docs.openplane.dev/architecture",
    relevanceScore: 0.92,
  },
  // ... more chunks from search
];

// Non-streaming
const response = await answerWithRAG("How does search work?", chunks);
console.log(response.answer);
console.log(response.citations);
console.log(response.confidence); // "high" | "medium" | "low" | "uncertain"

// Streaming
for await (const event of streamRAGAnswer("How does search work?", chunks)) {
  switch (event.type) {
    case "analysis":
      // Query analysis complete
      break;
    case "text":
      process.stdout.write(event.content ?? "");
      break;
    case "citation":
      // Individual citation emitted
      break;
    case "grounding":
      // Grounding warning (if confidence is low)
      break;
    case "done":
      // Final usage stats
      break;
  }
}
```

## RAG Engine

The `RAGEngine` class orchestrates the full pipeline:

```typescript
import { RAGEngine } from "@openplane/ai";

const engine = new RAGEngine({
  providerId: "anthropic",
  modelId: "claude-sonnet-4-20250514",
  temperature: 0.3,
  enableGrounding: true,
  rerankingOptions: {
    maxChunks: 10,
    minRelevance: 0.3,
  },
});

const response = await engine.answer({
  query: "What is our deployment process?",
  chunks: retrievedChunks,
  conversationContext: {
    conversationId: "conv_123",
    turns: previousTurns,
    summary: null,
    entities: new Map(),
    topicShift: false,
  },
});
```

### RAG Response

```typescript
interface RAGResponse {
  answer: string;
  citations: RAGCitation[];
  grounding: GroundingResult | null;
  usage: RAGTokenUsage;
  timing: RAGTiming;
  confidence: GroundingConfidence;
  followUpQuestions: string[];
}
```

### Configuration

```typescript
interface RAGEngineConfig {
  providerId?: ProviderId;    // LLM provider
  modelId?: string;           // Model for generation
  temperature?: number;       // Default: 0.3
  enableGrounding?: boolean;  // Default: true
  groundingThreshold?: number;
  maxContextTokens?: number;
  maxChunks?: number;
  rerankingOptions?: {
    maxChunks?: number;
    minRelevance?: number;
  };
}
```

Create a customized engine with `withConfig()`:

```typescript
const strictEngine = engine.withConfig({
  temperature: 0.1,
  enableGrounding: true,
  groundingThreshold: 0.5,
});
```

## Query Analyzer

The query analyzer (`packages/ai/src/rag/query-analyzer.ts`) classifies intent, extracts entities, detects temporal references, and decomposes compound queries. This runs entirely on the client side without an LLM call.

```typescript
import { analyzeQuery } from "@openplane/ai";

const analysis = analyzeQuery("What changes did the engineering team make last month?");
```

### Query Analysis Result

```typescript
interface QueryAnalysis {
  originalQuery: string;
  normalizedQuery: string;
  intent: QueryIntent;
  subQueries: string[];
  entities: ExtractedEntity[];
  temporalContext: TemporalContext | null;
  requiresContext: boolean;
  confidence: number;
  keywords: string[];
}
```

### Intent Classification

| Intent | Triggers | Example |
|--------|----------|---------|
| `question` | Starts with what/why/how/when/where/who | "What is the deploy process?" |
| `definition` | "what is", "define", "meaning of" | "What is a connector?" |
| `comparison` | "vs", "compare", "difference between" | "Redis vs Memcached" |
| `howto` | "how to", "steps to", "guide to" | "How to add a connector?" |
| `command` | "show me", "find", "list", "get" | "Show me recent incidents" |
| `search` | General keyword queries | "Q3 revenue report" |
| `followup` | Pronouns, "also", "tell me more" | "What about their pricing?" |
| `clarification` | "I meant", "actually", "no," | "No, I meant the staging deploy" |

### Entity Extraction

Recognized entity types with pattern matching:

| Type | Examples |
|------|---------|
| `technology` | kubernetes, react, typescript, python, aws, docker |
| `product` | github, jira, notion, slack, linear, figma |
| `organization` | google, microsoft, anthropic, stripe |
| `person` | @mentions (`@john`) |
| `date` | Q1 2024, January 2025 |

### Temporal Context

Automatic date range extraction:

```typescript
// "last 7 days" → { type: "relative", start: <7 days ago>, end: <now> }
// "this quarter" → { type: "relative", start: <quarter start>, end: <now> }
// "yesterday" → { type: "relative", start: <yesterday>, end: <yesterday> }
// "after March 2024" → { type: "absolute", start: <2024-03-01> }
```

### Conversation Context

For multi-turn conversations, the analyzer resolves pronouns and detects topic shifts:

```typescript
import { buildConversationContext, enrichQueryWithContext } from "@openplane/ai";

const conversationCtx = buildConversationContext("conv_123", turns);
const analysis = analyzeQuery("What about their pricing?", conversationCtx);
const enrichedQuery = enrichQueryWithContext(analysis, conversationCtx);
// Pronouns like "their" get replaced with entities from prior turns
```

## Grounding & Verification

The grounding system verifies that generated answers are supported by source chunks.

```typescript
import { verifyGrounding, shouldWarnAboutGrounding, formatGroundingWarning } from "@openplane/ai";

const grounding = verifyGrounding(answer, chunks, 0.3);

console.log(grounding.overallScore);     // 0.0 - 1.0
console.log(grounding.confidence);       // "high" | "medium" | "low" | "uncertain"
console.log(grounding.unsupportedClaims); // Claims without source evidence
console.log(grounding.claims);           // Per-claim verification details
```

### How Grounding Works

1. **Claim extraction**: Split the answer into factual sentences, filtering out opinions and instructions
2. **Index building**: Build an inverted index of significant terms and bigrams from source chunks
3. **Claim verification**: For each claim, find candidate chunks by term overlap, then compute a support score
4. **Confidence scoring**: Aggregate per-claim scores into an overall confidence level

### Claim Verification

```typescript
interface ClaimVerification {
  claim: string;
  supported: boolean;
  evidenceChunkId: string | null;
  evidenceSnippet: string | null;
  confidence: number;
}
```

### Confidence Levels

| Level | Criteria |
|-------|----------|
| `high` | Overall score >= 0.8, average claim confidence >= 0.6 |
| `medium` | Overall score >= 0.5, average claim confidence >= 0.4 |
| `low` | Overall score >= 0.3 |
| `uncertain` | Overall score < 0.3 |

### Refusal Detection

When grounding is too low, the system can generate appropriate refusal messages:

```typescript
import { checkForRefusal } from "@openplane/ai";

const refusal = checkForRefusal(groundingResult, chunks);
if (refusal) {
  // refusal.type: "noSources" | "lowConfidence" | "mixedGrounding" | "outOfScope"
  // refusal.message: Human-readable explanation
  // refusal.suggestedAction: What the user should do instead
}
```

### Grounded Answers

Combine answer, chunks, and grounding into a complete result:

```typescript
import { createGroundedAnswer } from "@openplane/ai";

const grounded = createGroundedAnswer(answer, chunks, groundingResult);
// grounded.answer: The generated text
// grounded.citations: Deduplicated citations with evidence
// grounded.groundingScore: 0.0 - 1.0
// grounded.confidence: Numeric confidence
// grounded.ungroundedClaims: Claims without evidence
// grounded.suggestedFollowUp: Search suggestion for unverified claims
```

## Query Router

Route queries to the optimal retrieval backend:

```typescript
import { routeQuery, shouldUseVespa, shouldUseDuckDB } from "@openplane/ai";

const decision = routeQuery(analysis, routingContext);
// decision.route: "vespa" | "duckdb" | "hybrid"
// decision.explanation: Why this route was chosen

if (shouldUseDuckDB(analysis)) {
  // Route to structured data query
}

if (shouldUseVespa(analysis)) {
  // Route to Vespa hybrid search
}
```

## Timing

The RAG response includes detailed timing breakdowns:

```typescript
interface RAGTiming {
  analysisMs: number;    // Query analysis
  retrievalMs: number;   // Document retrieval
  rerankingMs: number;   // Chunk reranking
  generationMs: number;  // LLM generation
  groundingMs: number;   // Grounding verification
  totalMs: number;       // End-to-end
  firstTokenMs: number | null; // Time to first token (streaming)
}
```
