# Sync Behavior

## Sync Types

| Type | Trigger | Duration |
|------|---------|----------|
| **Full** | First connection, manual resync | 1-2 minutes |
| **Incremental** | Scheduled | < 1 minute |

## Full Sync Process

1. **Fetch content**: Download Markdown files from each enabled OWASP GitHub repository
2. **Parse Markdown**: Extract structured content, headings, code examples, and metadata
3. **Transform**: Convert each document to a searchable record with project attribution and CWE mappings
4. **Index**: Batch index documents (50 per batch)

## Incremental Sync

Checks each GitHub repository for new commits since the last sync. If changes are detected, re-fetches and re-processes only the modified files. Most OWASP projects update monthly with occasional patch releases.
