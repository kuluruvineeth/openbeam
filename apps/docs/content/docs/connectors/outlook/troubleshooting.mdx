# Troubleshooting

## OAuth Errors

| Error | Fix |
|-------|-----|
| `AADSTS50011` | Redirect URI mismatch — verify exact match in Azure AD app registration |
| `AADSTS65001` | Admin consent required — have an Azure AD admin grant consent |
| `AADSTS700016` | Application not found — verify Client ID matches your app registration |
| `invalid_grant` | Refresh token expired — reconnect the OAuth flow |
| `unauthorized_client` | Check Client ID and Secret are correct |

## Access Issues

| Issue | Fix |
|-------|-----|
| No emails syncing | Verify `Mail.Read` permission is granted and consented |
| Folders not found | Check folder name spelling in include/exclude filters |
| Shared mailbox not accessible | Shared mailboxes are not supported — only the user mailbox is indexed |

## Sync Issues

| Issue | Fix |
|-------|-----|
| Rate limit exceeded | Auto-backoff; wait for reset (10 min window) |
| Delta token expired | Full resync triggered automatically after 30 days |
| Attachments not extracted | Verify `sync_attachments` is enabled and file type is supported |
| Old emails missing | Increase `lookback_days` setting and trigger full resync |

## Connection Issues

| Issue | Fix |
|-------|-----|
| Cannot connect | Verify Azure AD credentials and tenant ID |
| Token expired | OAuth auto-refreshes; reconnect if persistent |
| API errors | Check [Microsoft 365 Service Health](https://status.office.com/) |

## Debug Commands

```bash
curl https://api.your-domain.com/webhooks/outlook/health

tail -f logs/worker.log | grep -i outlook
```

## Error Reference

| Error | Code | Fix |
|-------|------|-----|
| `AuthenticationError` | 401 | Reconnect OAuth |
| `Forbidden` | 403 | Check API permissions and admin consent |
| `MailboxNotFound` | 404 | User mailbox does not exist |
| `TooManyRequests` | 429 | Wait for `Retry-After` header duration |
| `ServiceUnavailable` | 503 | Microsoft Graph temporary outage — retry later |

## Common Patterns

### Issue: "No emails appearing in search"

1. Check connector status is Active
2. Verify `Mail.Read` permission has admin consent
3. Check folder filters are not excluding all folders
4. Verify `lookback_days` covers the desired date range
5. Try manual Full Resync

### Issue: "Slow initial sync"

Large mailboxes take time. Progress shown in connector status.
- 1,000 emails: ~2 minutes
- 10,000 emails: ~15 minutes
- 100,000+ emails: Several hours
