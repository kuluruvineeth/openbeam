# SharePoint Features

## Search

- **Full-text**: Document content, titles, and descriptions
- **File types**: Word, Excel, PowerPoint, PDF with text extraction
- **Sites**: Site names and metadata
- **Metadata**: Author, modified date, site, library filtering

## Content Types

| Type | Fields Indexed |
|------|----------------|
| Documents | Title, extracted text, author, modified date |
| Files | Filename, content (where extractable), size, type |
| Sites | Site name, description, URL |
| Drives | Library name, drive type (document library, shared) |

## Document Metadata

| Field | Searchable | Filterable |
|-------|------------|------------|
| Title | Yes | Yes |
| Author | Yes | Yes |
| Site | Yes | Yes |
| Library | Yes | Yes |
| Modified Date | Yes | Yes |
| File Type | Yes | Yes |
| File Size | No | Yes |
| Path | Yes | No |

## Sync Options

| Mode | Trigger | Latency |
|------|---------|---------|
| Full | First sync, manual | Minutes to hours |
| Incremental | Delta API (scheduled) | 15 min |

## AI Capabilities

- Semantic search across all SharePoint document content with site and library filtering
- Question answering from documents, policies, and knowledge base content
- Related document discovery by content similarity across sites
- Full-text extraction from Office documents, PDFs, and common file formats
- Document summarization for long reports and policy documents

## Limitations

| Limit | Value |
|-------|-------|
| Microsoft Graph throttling | 10,000 requests per 10 minutes |
| File size for text extraction | Up to 50 MB |
| Delta sync token expiry | 30 days |
| Personal OneDrive | Not included (SharePoint sites only) |
| List items | Not indexed (documents and files only) |
