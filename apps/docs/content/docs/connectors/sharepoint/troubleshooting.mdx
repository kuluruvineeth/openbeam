# Troubleshooting

## OAuth Errors

| Error | Fix |
|-------|-----|
| `AADSTS50011` | Redirect URI mismatch — verify exact match in Azure AD app registration |
| `AADSTS65001` | Admin consent required — `Sites.Read.All` needs admin approval |
| `AADSTS700016` | Application not found — verify Client ID matches your app registration |
| `invalid_grant` | Refresh token expired — reconnect the OAuth flow |
| `unauthorized_client` | Check Client ID and Secret are correct |

## Access Issues

| Issue | Fix |
|-------|-----|
| No sites found | Verify `Sites.Read.All` permission is granted with admin consent |
| Missing documents | Check site filters and user access to the SharePoint site |
| Personal OneDrive files | OneDrive personal files are not indexed — only SharePoint sites |

## Sync Issues

| Issue | Fix |
|-------|-----|
| Rate limit exceeded | Auto-backoff; wait for reset (10 min window) |
| Delta token expired | Full resync triggered automatically after 30 days |
| File content not extracted | File type may not support text extraction — check supported formats |
| Large files skipped | Files over 50 MB are indexed by metadata only |

## Connection Issues

| Issue | Fix |
|-------|-----|
| Cannot connect | Verify Azure AD credentials and tenant ID |
| Token expired | OAuth auto-refreshes; reconnect if persistent |
| API errors | Check [Microsoft 365 Service Health](https://status.office.com/) |

## Debug Commands

```bash
curl https://api.your-domain.com/webhooks/sharepoint/health

tail -f logs/worker.log | grep -i sharepoint
```

## Error Reference

| Error | Code | Fix |
|-------|------|-----|
| `AuthenticationError` | 401 | Reconnect OAuth |
| `AccessDenied` | 403 | Check API permissions and admin consent |
| `ItemNotFound` | 404 | Site or drive deleted |
| `TooManyRequests` | 429 | Wait for `Retry-After` header duration |
| `ServiceUnavailable` | 503 | Microsoft Graph temporary outage — retry later |

## Common Patterns

### Issue: "No documents appearing in search"

1. Check connector status is Active
2. Verify `Sites.Read.All` has admin consent
3. Check site filters are not excluding all sites
4. Verify the user has access to the SharePoint sites
5. Try manual Full Resync

### Issue: "Slow initial sync"

Large SharePoint deployments take time. Progress shown in connector status.
- 100 documents: ~2 minutes
- 10,000 documents: ~30 minutes
- 100,000+ documents: Several hours
