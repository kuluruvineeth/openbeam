# Zoom Features

## Indexed Content

### Past Meetings

Meeting metadata is indexed for search, including:
- Meeting topic and agenda
- Start time and duration
- Host information
- Participant count

### Cloud Recordings

Recording metadata with direct links:
- Recording file types and sizes
- Play and share URLs for quick access
- Recording type classification

### Transcripts

Full-text VTT transcript content is extracted and indexed:
- Spoken words from recorded meetings become searchable
- Find specific discussions, decisions, and action items
- Transcript text is cleaned of VTT formatting markers

## Search Capabilities

| Feature | Description |
|---------|-------------|
| Full-text transcript search | Search for specific words or phrases spoken in meetings |
| Meeting topic search | Find meetings by topic name or agenda content |
| Host filtering | Filter results by meeting host |
| Date range filtering | Search within specific time periods |
| Recording type filtering | Filter by recording type (speaker view, screen share, etc.) |

## Actions

| Action | Description |
|--------|-------------|
| Create Meeting | Schedule a new Zoom meeting for a user |
| Update Meeting | Modify topic, time, duration, or agenda |
| Delete Meeting | Remove a scheduled meeting |
