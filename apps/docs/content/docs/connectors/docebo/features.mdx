# Docebo Features

## Indexed Content Types

### Courses

Training courses are indexed with full metadata including name, code, type, status, category, duration, language, and enrollment count. Search across all course content to find relevant training materials.

### Learning Plans

Structured learning paths are indexed with their descriptions, associated course counts, duration, and category. Find learning plans by topic or organizational category.

### Users

Learner profiles are indexed with username, full name, email, role, status, and branch assignment. Search the user directory to find specific learners or filter by role and branch.

### Enrollments

Course enrollment records capture user-course relationships including enrollment status, progress percentage, completion dates, and scores. Track training completion across your organization.

### Certifications

Certification definitions are indexed with title, code, description, status, duration requirements, and expiration policies. Find certification programs and their requirements.

## Search Capabilities

| Feature | Description |
|---------|-------------|
| Full-text search | Search across all indexed Docebo content |
| Type filtering | Filter results by course, learning plan, user, enrollment, or certification |
| Status filtering | Filter by active, completed, or other status values |
| Category browsing | Browse content by Docebo categories |
| Progress tracking | Find enrollments by completion status |
