# Klue Setup

## Prerequisites

- A Klue account with admin or API access
- Access to Klue API key management

## Step 1: Generate an API Key

1. Log into [Klue](https://app.klue.com)
2. Go to **Settings > API**
3. Click **Generate API Key**
4. Name it something like "OpenBeam Integration"
5. Copy the generated API key

## Step 2: Add Connector in OpenBeam

1. Navigate to **Settings > Connectors**
2. Click **Add Connector** and select **Klue**
3. Enter your **API Key**
4. Click **Connect** to validate and activate

## Step 3: Initial Sync

After activation, OpenBeam runs a full sync of your Klue data. The first sync fetches all competitors, battlecards, intel items, and boards.
