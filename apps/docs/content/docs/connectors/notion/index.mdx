# Notion Connector

The Notion connector is coming soon.

## Planned Features

- Full-text search across pages and databases
- Database property indexing
- Block-level content extraction
- Workspace permission sync
- Real-time updates via Notion webhooks

## Content Types

| Type | Support |
|------|---------|
| Pages | Full content indexing |
| Databases | Properties and content |
| Comments | Thread indexing |
| Files | Attachment extraction |

## Authentication

Will use Notion OAuth 2.0 with read access to:
- Pages and databases
- User information
- Comments

Watch the [GitHub repository](https://github.com/kuluruvineeth/openplane) for updates on Notion connector availability.
