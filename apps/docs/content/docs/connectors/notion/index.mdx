## What's Indexed

- **Pages** - Full content with nested blocks
- **Databases** - Schema, properties, and entries
- **Comments** - Page and block discussions

## Quick Start

1. Create Notion integration at notion.so/my-integrations
2. Enable OAuth and add redirect URI
3. Connect in OpenPlane UI
4. Select pages to share with integration
