# Notion

Index pages, databases, and blocks from Notion with recursive content extraction. Supports OAuth 2.0 authentication and incremental sync.

## What Gets Indexed

| Content | Details |
|---------|---------|
| **Pages** | Full content with nested blocks recursively extracted |
| **Databases** | Schema, properties, and all entries |
| **Comments** | Page and block discussions |

## Authentication

**Method:** OAuth 2.0

Create a Notion integration at [notion.so/my-integrations](https://www.notion.so/my-integrations), enable OAuth, and add the redirect URI.

## Quick Start

1. Create a Notion integration at [notion.so/my-integrations](https://www.notion.so/my-integrations)
2. Enable OAuth and configure the redirect URI
3. Connect Notion in the OpenPlane UI
4. Select pages and databases to share with the integration
