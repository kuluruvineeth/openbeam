# Asana

Index project management data from Asana including tasks, projects, and comments. Supports OAuth 2.0 with incremental sync via the Search API's modified_at filtering.

## What Gets Indexed

| Content | Details |
|---------|---------|
| **Tasks** | Name, notes, assignee, due date, tags, custom fields, section |
| **Projects** | Name, notes, owner, status, team, color |
| **Comments** | Comment text, author, timestamp, parent task |

## Authentication

**Method:** OAuth 2.0

**Scopes:** `default` (read access to all resources)

Create an app in the [Asana Developer Console](https://app.asana.com/0/developer-console) and configure the OAuth settings.

## Quick Start

1. Create an app in the Asana Developer Console
2. Configure the OAuth redirect URL
3. Add the Asana connector in OpenBeam with your Client ID and Secret
4. Authorize and start the initial sync
