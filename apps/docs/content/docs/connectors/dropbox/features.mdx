## Indexed Content

| Content Type | Indexed | Searchable Fields |
|-------------|---------|-------------------|
| Files | Yes | Name, path, extension, size |
| Folders | Yes | Name, path |
| Sharing info | Yes | Shared status |
| Content hash | Yes | Deduplication |

## File Type Detection

Files are automatically classified by extension:

| Category | Extensions |
|----------|-----------|
| Document | doc, docx, pdf, txt, md, odt, rtf |
| Spreadsheet | xls, xlsx, csv, ods, tsv |
| Presentation | ppt, pptx, odp, key |
| Image | png, jpg, jpeg, gif, svg, webp, heic |

## Search Capabilities

- Full-text search across file and folder names
- Filter by file type (document, spreadsheet, presentation, image)
- Filter by path or parent folder
- Sort by modification date or size
