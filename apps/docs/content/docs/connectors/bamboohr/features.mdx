# Features

## Employee Directory

The connector indexes the complete employee directory including:

- **Personal info**: Name, preferred name, email, phone
- **Job details**: Title, department, division, location
- **Organization**: Manager, reporting chain
- **Employment**: Hire date, employee number, status
- **Address**: City, state, country

## Time Off Requests

When enabled, the connector also indexes time off requests:

- Request type (vacation, sick, personal)
- Date range and duration
- Approval status
- Employee and manager notes

## Search Capabilities

- Search employees by name, title, department, or location
- Find who reports to whom
- Look up time off schedules
- Filter by department, division, or employment status
