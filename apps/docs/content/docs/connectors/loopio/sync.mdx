# Sync Behavior

## Full Sync

The initial sync fetches all entities from Loopio:

1. **Projects** with status, deadline, owner, and question count
2. **Library Entries** with question, answer, category, tags, and review history
3. **Tags** with associated entry counts

Results are streamed in batches to minimize memory usage.

## Incremental Sync

Subsequent syncs use Loopio's `updated_after` query parameter to fetch only projects and library entries modified since the last sync. Tags are always fully re-synced since they change infrequently.

If the incremental sync fails, OpenBeam automatically falls back to a full sync.

## Sync Schedule

| Entity | Default Interval |
|--------|-----------------|
| Projects | Every 60 minutes |
| Library Entries | Every 30 minutes |
| Tags | Every 120 minutes |

## Rate Limits

Loopio enforces rate limits of 100 API requests per minute. The connector handles rate limiting with exponential backoff and quota waiting.
