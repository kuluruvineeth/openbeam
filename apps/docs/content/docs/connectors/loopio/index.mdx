# Loopio

Index RFP response management data from Loopio including projects, library entries (reusable Q&A pairs), and tags. Supports API key authentication (Bearer token) with page-based pagination and updated_after incremental sync.

## What Gets Indexed

| Content | Details |
|---------|---------|
| **Projects** | Name, description, status, deadline, owner, question count, tags |
| **Library Entries** | Question, answer, category, tags, reviewer, last reviewed date |
| **Tags** | Name, associated library entry count |

## Authentication

**Method:** API Key (Bearer Token)

Generate an API key from **Settings > API** in Loopio. The key must have read access to projects, library entries, and tags.

## Quick Start

1. Generate an API key in Loopio
2. Add the Loopio connector in OpenBeam
3. Enter your API key
4. Start the initial sync
