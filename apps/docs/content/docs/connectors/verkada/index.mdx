# Verkada

Index cameras, door access controllers, and environmental sensors from the Verkada physical security platform with API key authentication and webhook support.

## What Gets Indexed

| Entity | Description |
|--------|-------------|
| Cameras | Name, model, status, site, firmware version |
| Doors | Name, status, lock state, site, access events |
| Sensors | Name, type, readings (temperature, humidity, air quality) |

## Authentication

Verkada uses **API key** authentication. Generate an API key from the Verkada Command dashboard.

Multi-region support is available for US, EU, and AU deployments.

## Sync

| Mode | Supported |
|------|-----------|
| Full sync | Yes |
| Incremental sync | Yes |
| Real-time (webhooks) | Yes |

Incremental sync uses `lastSyncTime` timestamps to fetch only modified devices. Webhooks provide real-time event delivery.

## Setup

1. Log in to **Verkada Command**
2. Navigate to the API settings and generate an API key
3. In OpenPlane, add the Verkada connector
4. Enter the API key, select your region, and start the initial sync

### Settings

| Setting | Default | Description |
|---------|---------|-------------|
| API Key | — | Verkada API key (required) |
| Region | US | US, EU, or AU deployment |
| Sync Cameras | On | Include cameras in search |
| Sync Doors | On | Include door controllers in search |
| Sync Sensors | On | Include environmental sensors in search |
