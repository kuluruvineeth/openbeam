# NetSuite Troubleshooting

## Authentication Errors

### 401 Unauthorized

- Verify your consumer key, consumer secret, token ID, and token secret are correct
- Ensure the integration record has Token-Based Authentication enabled
- Check that the access token has not been revoked
- Verify the user/role associated with the token has REST Web Services permission

### 403 Forbidden

- The role associated with the token lacks permissions for the record type
- Add the required permissions (Customer, Vendor, Invoice, etc.) to the role
- Ensure the role has "REST Web Services" permission at Full level

### Invalid Account ID

- Account IDs are case-insensitive but must match exactly (e.g., `1234567` or `TSTDRV1234567`)
- The account ID determines the API endpoint URL
- Find your account ID under **Setup > Company > Company Information**

## Sync Issues

### Rate Limiting (429 Responses)

NetSuite enforces concurrency limits per account. If you see rate limit errors:

- The connector automatically retries with exponential backoff
- Consider reducing the sync frequency if errors persist
- Check if other integrations are consuming your API quota

### Empty Sync Results

- Verify the role has View permission for each record type
- Check that records exist in the account
- For incremental sync, ensure records have been modified since the last sync timestamp

### Slow Sync Performance

- NetSuite REST API has lower throughput than SuiteTalk SOAP
- Large accounts with thousands of records may take several minutes for initial sync
- Consider disabling entity types you do not need to reduce sync time

## Connection Issues

### DNS Resolution Failures

- Verify the account ID format produces a valid hostname
- The API URL format is `{account_id}.suitetalk.api.netsuite.com`
- Underscores in account IDs are converted to hyphens in the hostname

### Timeout Errors

- Default timeout is 30 seconds per request
- NetSuite may be slow during peak hours
- The connector retries server errors (5xx) up to 3 times with backoff
