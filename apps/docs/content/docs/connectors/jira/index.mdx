# Jira

Index issues, comments, and project data from Atlassian Jira Cloud. Supports OAuth 2.0 via Atlassian 3LO (shared auth with Confluence), JQL-based incremental sync, and real-time webhook deletion detection.

## What Gets Indexed

| Content | Details |
|---------|---------|
| **Issues** | Summary, description, status, assignee, priority, labels |
| **Comments** | Full comment text with author and timestamps |
| **Projects** | Project name, key, lead, category |
| **Sprints** | Sprint name, state, dates |

## Authentication

**Method:** OAuth 2.0 (Atlassian 3LO, shared with Confluence)

**Scopes:** `read:jira-work`, `read:jira-user`, `manage:jira-webhook`, `offline_access`, `read:me`

Uses the same Atlassian OAuth app as Confluence. Add Jira-specific scopes to your existing app at [developer.atlassian.com](https://developer.atlassian.com/console/myapps/).

## Quick Start

1. Create an OAuth 2.0 app at [developer.atlassian.com](https://developer.atlassian.com/console/myapps/) (or reuse your Confluence app)
2. Add Jira API scopes and configure the callback URL
3. Add the Jira connector in OpenBeam with your Client ID and Secret
4. Authorize and start the initial sync
