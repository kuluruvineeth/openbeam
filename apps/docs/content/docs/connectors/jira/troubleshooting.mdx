# Troubleshooting

## OAuth Errors

| Error | Fix |
|-------|-----|
| `invalid_client` | Check Client ID and Secret match your Atlassian app |
| `access_denied` | User denied authorization or insufficient scopes |
| `invalid_grant` | Refresh token rotated and expired — reconnect OAuth flow |
| `unauthorized_client` | App not configured for OAuth 2.0 (3LO) |

## Access Issues

| Issue | Fix |
|-------|-----|
| Projects not found | User must have Browse Projects permission |
| Issues missing | Check project filters and issue-level security schemes |
| Comments missing | Enable `sync_comments` setting |
| Sprints not appearing | Sprint data is extracted from issue fields |

## Sync Issues

| Issue | Fix |
|-------|-----|
| Rate limit exceeded | Auto-backoff; varies by endpoint |
| Content not indexed | Check connector status and JQL query results |
| Deleted issues still in results | Enable webhooks for real-time deletion detection |
| Custom fields not searchable | Custom fields are indexed as metadata key-value pairs |

## Connection Issues

| Issue | Fix |
|-------|-----|
| Cannot connect | Verify Atlassian OAuth credentials |
| Token refresh failed | Rotating refresh token was reused — reconnect OAuth |
| Site selection failed | Verify the user has access to the Jira site |
| API errors | Check [Atlassian Status](https://status.atlassian.com/) |

## Webhook Issues

| Issue | Fix |
|-------|-----|
| Events not received | Check webhook URL accessibility from the internet |
| Webhook registration failed | Verify `manage:jira-webhook` scope is granted |
| Deletion not detected | Enable `enable_webhooks` in settings |

## Debug Commands

```bash
curl https://api.your-domain.com/webhooks/jira/health

tail -f logs/worker.log | grep -i jira
```

## Error Reference

| Error | Code | Fix |
|-------|------|-----|
| `AUTHENTICATION_ERROR` | 401 | Reconnect OAuth |
| `FORBIDDEN` | 403 | Check project permissions |
| `NOT_FOUND` | 404 | Issue or project deleted |
| `RATE_LIMITED` | 429 | Wait for backoff period |
| `SERVER_ERROR` | 500 | Atlassian service issue — retry later |

## Common Patterns

### Issue: "No issues appearing in search"

1. Check connector status is Active
2. Verify user has Browse Projects permission
3. Check project filters match actual project keys
4. Verify `lookback_days` covers the desired date range
5. Try manual Full Resync

### Issue: "Slow initial sync"

Large Jira instances take time. Progress shown in connector status.
- 1,000 issues: ~5 minutes
- 10,000 issues: ~30 minutes
- 100,000+ issues: Several hours

### Issue: "Webhook not working"

1. Verify `enable_webhooks` is true
2. Verify `manage:jira-webhook` scope is granted
3. Check webhook URL is publicly accessible
4. Verify SSL certificate is valid
5. Check server logs for incoming requests

Still stuck? [Open an issue](https://github.com/kuluruvineeth/openbeam/issues) with error messages and logs.
