# Configuration

## Label Filtering

| Setting | Default | Description |
|---------|---------|-------------|
| `includeLabels` | `[]` | Only sync these (empty = all) |
| `excludeLabels` | `["SPAM", "TRASH"]` | Skip these labels |

```json
{
  "includeLabels": ["INBOX", "IMPORTANT"],
  "excludeLabels": ["SPAM", "TRASH", "CATEGORY_PROMOTIONS"]
}
```

Common labels: `INBOX`, `SENT`, `IMPORTANT`, `STARRED`, `CATEGORY_PERSONAL`, `CATEGORY_PROMOTIONS`

## Sync Settings

| Setting | Default | Description |
|---------|---------|-------------|
| `lookbackDays` | `365` | Days of history to sync |
| `threadAware` | `true` | Group emails by thread |
| `fullSyncInterval` | `24h` | Full resync frequency |
| `incrementalInterval` | `15m` | Check frequency |

## Attachment Settings

| Setting | Default | Description |
|---------|---------|-------------|
| `indexAttachments` | `true` | Extract attachment content |
| `maxAttachmentSize` | `26214400` | Max size (25MB) |
| `ocrEnabled` | `true` | OCR for images |
| `transcribeMedia` | `false` | Audio/video transcription |

## Real-time Sync

| Setting | Description |
|---------|-------------|
| `realtimeEnabled` | Enable Pub/Sub push |
| `pubsubTopic` | `projects/PROJECT/topics/gmail-notifications` |

## Environment Variables

```bash
GOOGLE_CLIENT_ID=your-client-id.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=GOCSPX-your-secret
WEB_URL=https://your-domain.com
SERVER_URL=https://api.your-domain.com
```

## Resync Required

| Change | Resync |
|--------|--------|
| Add includeLabels | Full sync |
| Increase lookback | Full sync |
| Enable attachments | Full sync |

Trigger via **Actions → Full Resync** in connector settings.
