# Sync Behavior

## Sync Types

| Type | Trigger | Duration |
|------|---------|----------|
| **Full** | First connection, manual resync | Minutes to hours |
| **Incremental** | Scheduled / Pub/Sub notification | Seconds to minutes |

## Status

| Status | Meaning |
|--------|---------|
| **Active** | Synced, watching for changes |
| **Syncing** | Sync in progress |
| **Error** | Check logs |

## History ID

Gmail tracks changes via history IDs. OpenPlane stores the last ID and fetches only changes.

History expires after ~7 days. If expired, OpenPlane auto-triggers full sync.

## Watch Management

Pub/Sub watches expire after 7 days. OpenPlane auto-renews 1 day before expiration.

## Rate Limits

| Quota | Limit |
|-------|-------|
| Per 100 seconds per user | 250 requests |
| Concurrent | 10 requests |

OpenPlane handles limits with exponential backoff.

## Controls

- **Full Resync**: Settings → Connectors → Gmail → Actions → Full Resync
- **Pause/Resume**: Stop processing temporarily
- **Sync Now**: Trigger immediate incremental sync

## Troubleshooting

| Issue | Fix |
|-------|-----|
| Sync stuck | Rate limited - wait |
| Old emails missing | Increase `lookbackDays`, resync |
| New emails delayed | Check Pub/Sub webhook |
| Token expired | Reconnect connector |
