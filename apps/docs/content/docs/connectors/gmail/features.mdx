# Gmail Features

## Search

- **Full-text**: Subject, body, sender, recipient
- **Thread grouping**: Conversations indexed together
- **Attachments**: Text extraction from PDF, DOCX, XLSX, images (OCR)
- **Labels**: Filter by Gmail labels

### Search Operators

| Operator | Example |
|----------|---------|
| `from:` | `from:john@company.com` |
| `to:` | `to:team@company.com` |
| `subject:` | `subject:meeting` |
| `has:attachment` | Emails with files |
| `after:` / `before:` | `after:2024-01-01` |
| `label:` | `label:important` |

## Attachment Indexing

| Format | Extraction |
|--------|------------|
| PDF, DOCX, TXT | Full text |
| XLSX, CSV | Cell content |
| PPTX | Slide text |
| Images | OCR |
| Audio/Video | Transcription (requires TwelveLabs) |

## Sync Options

- **Polling**: Every 15 minutes (default)
- **Real-time**: Via Pub/Sub, seconds latency

## AI Capabilities

- Semantic search across email threads, subjects, and attachment content beyond keyword matching
- Question answering grounded in email context: "What did John say about the budget in last week's thread?"
- Thread summarization with key decisions, action items, and participant identification
- Attachment intelligence — answer questions from content inside PDFs, spreadsheets, and presentations
- Contact interaction analysis — surface communication patterns and response time trends per sender

## Limitations

| Limit | Value |
|-------|-------|
| Access | Read-only |
| History | Configurable (default 1 year) |
| Attachment size | 25MB max |
