# Gmail Connector

The Gmail connector is coming soon.

## Planned Features

- Full-text search across emails
- Attachment indexing (PDF, DOCX, etc.)
- Label and folder support
- Thread grouping
- Real-time sync via Gmail push notifications

## Authentication

Will use Google OAuth 2.0 with the following scopes:
- `gmail.readonly` - Read email messages
- `gmail.metadata` - Access email metadata

Watch the [GitHub repository](https://github.com/kuluruvineeth/openplane) for updates on Gmail connector availability.
