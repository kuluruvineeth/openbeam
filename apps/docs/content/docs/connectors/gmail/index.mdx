Index emails, threads, and attachments. Optional real-time sync via Pub/Sub.

## What's Indexed

- **Emails & threads** - Full-text search, grouped conversations
- **Attachments** - Text extraction (PDF, DOCX, images via OCR)
- **Labels** - Filter by Gmail labels

## Quick Start

1. Create Google Cloud project with OAuth credentials
2. Enable Gmail API and People API
3. Configure OAuth redirect URI
4. Connect in OpenPlane UI
