# Gmail

Index emails, threads, and attachments from Gmail. Supports OAuth 2.0 authentication, full and incremental sync, and optional real-time updates via Google Pub/Sub.

## What Gets Indexed

| Content | Details |
|---------|---------|
| **Emails and threads** | Full-text search across grouped conversations |
| **Attachments** | Text extraction from PDF, DOCX, and images via OCR |
| **Labels** | Filter results by Gmail labels |

## Authentication

**Method:** OAuth 2.0

**Scopes:** `gmail.readonly`, `contacts.readonly`

Create OAuth credentials in the Google Cloud Console. Enable the Gmail API and People API for your project.

## Quick Start

1. Create a Google Cloud project with OAuth credentials
2. Enable the Gmail API and People API
3. Configure the OAuth redirect URI to match your OpenPlane instance
4. Connect Gmail in the OpenPlane UI and authorize
