# Enterprise Deployment

## Deployment Options

| Model | Access | Setup |
|-------|--------|-------|
| Per-user OAuth | Individual mailboxes | Simple |
| Domain-wide delegation | All mailboxes | Moderate |

## Domain-Wide Delegation

Access all mailboxes without individual consent.

### 1. Create Service Account

1. Go to [Google Cloud IAM](https://console.cloud.google.com/iam-admin/serviceaccounts)
2. Create service account: `openbeam-gmail`
3. Create JSON key, download securely

### 2. Enable Delegation

1. In service account settings, enable **Domain-wide Delegation**
2. Note the **Client ID**

### 3. Authorize in Workspace Admin

1. Go to [admin.google.com](https://admin.google.com) → Security → API Controls → Domain-wide Delegation
2. Add new:
   - Client ID from service account
   - Scopes: `https://www.googleapis.com/auth/gmail.readonly,https://www.googleapis.com/auth/userinfo.email,https://www.googleapis.com/auth/userinfo.profile`
3. Authorize

### 4. Configure

```bash
GOOGLE_SERVICE_ACCOUNT_EMAIL=openbeam-gmail@your-project.iam.gserviceaccount.com
GOOGLE_SERVICE_ACCOUNT_KEY_PATH=/path/to/key.json
GOOGLE_WORKSPACE_DOMAIN=your-company.com
```

## Access Controls

| Role | Access |
|------|--------|
| Admin | All mailboxes |
| User | Own mailbox only |

## Compliance

- Retention policies respected
- Audit logging for all access
- Data at rest: AES-256
- Data in transit: TLS 1.3

## Shared Mailboxes

1. Create service account with delegation
2. Grant access to shared mailbox
3. Configure connector with shared address
