# OAuth Scopes

## Required Scopes

| Scope | Purpose |
|-------|---------|
| `gmail.readonly` | Read emails, threads, labels, attachments |
| `userinfo.email` | Identify connected account |
| `userinfo.profile` | Display user name |

OpenPlane uses read-only access. No send, modify, or delete permissions.

## Add Scopes

In **APIs & Services → OAuth consent screen → Scopes**:

```
https://www.googleapis.com/auth/gmail.readonly
https://www.googleapis.com/auth/userinfo.email
https://www.googleapis.com/auth/userinfo.profile
```

## Google Verification

The `gmail.readonly` scope is classified as **Sensitive**:

| Mode | Limit |
|------|-------|
| Testing | 100 users, no verification |
| Production | Unlimited, requires verification |

For production (100+ users), Google verification requires:
- Privacy policy and terms URLs
- Application homepage
- Video demo of OAuth flow
- Written explanation of data usage

Verification typically takes 2-6 weeks. Start early.
