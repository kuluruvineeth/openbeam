# Troubleshooting

## OAuth Errors

| Error | Fix |
|-------|-----|
| `redirect_uri_mismatch` | Exact match required in Google Cloud Console |
| `access_denied` | Add user to test users (testing mode) |
| `invalid_grant` | Token expired - disconnect and reconnect |

## Pub/Sub Issues

| Issue | Fix |
|-------|-----|
| No notifications | Verify `gmail-api-push@system.gserviceaccount.com` has Publisher role |
| 403 on webhook | Use valid SSL certificate (not self-signed) |
| Duplicate syncs | Check for multiple subscriptions on topic |

## Sync Issues

| Issue | Fix |
|-------|-----|
| `HISTORY_ID_EXPIRED` | Auto-triggers full sync |
| Rate limit exceeded | Auto-backoff; wait for reset |
| Quota exceeded | Wait for reset (midnight PT) or request increase |
| Emails not appearing | Check label configuration |
| Attachments not indexed | Enable `indexAttachments`; check size limit |

## Connection Issues

| Issue | Fix |
|-------|-----|
| Cannot connect | Verify environment variables and API enabled |
| Keeps disconnecting | Token revoked - reconnect |

## Debug Commands

```bash
# Check webhook health
curl https://api.your-domain.com/api/v1/webhooks/gmail/health

# Check logs
tail -f logs/worker.log | grep -i gmail
```

## Error Reference

| Error | Code | Fix |
|-------|------|-----|
| `redirect_uri_mismatch` | 400 | Fix OAuth credentials |
| `access_denied` | 403 | Add to test users |
| `invalid_grant` | 400 | Reconnect |
| `rate_limit_exceeded` | 429 | Wait |
| `history_id_expired` | 404 | Auto full sync |
