# Gmail Quick Start

## Prerequisites

- Google Cloud Console access
- OpenBeam instance with HTTPS endpoint

## 1. Create Google Cloud Project

1. Go to [console.cloud.google.com](https://console.cloud.google.com/)
2. Create a new project (or use existing)
3. Enable **Gmail API** and **People API** in APIs & Services → Library

## 2. Configure OAuth

1. Go to **APIs & Services → OAuth consent screen**
2. Select External (or Internal for Workspace)
3. Add app name and email, save
4. Add test users if in testing mode

## 3. Create Credentials

1. Go to **APIs & Services → Credentials**
2. Click **Create Credentials → OAuth client ID**
3. Select **Web application**
4. Add redirect URI:
   ```text
   https://your-domain.com/connectors/setup/gmail/oauth/callback
   ```
5. Save Client ID and Client Secret

## 4. Configure Environment

```bash
GOOGLE_CLIENT_ID=your-client-id.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=GOCSPX-your-secret
WEB_URL=https://your-domain.com
SERVER_URL=https://api.your-domain.com
```

## 5. Connect

1. Go to **Settings → Connectors → Add Connector → Gmail**
2. Click **Connect** and authorize
3. Configure labels to include/exclude

Initial sync runs in background. Large mailboxes may take 1+ hours.
