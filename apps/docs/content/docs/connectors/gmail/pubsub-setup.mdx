# Pub/Sub Setup

Enable real-time email sync. New emails appear in seconds instead of minutes.

**Without Pub/Sub**: Polling every 15 minutes
**With Pub/Sub**: Push notifications, seconds latency

## Prerequisites

- Cloud Pub/Sub API enabled
- OpenPlane server accessible via HTTPS
- Valid SSL certificate

## 1. Create Topic

1. Go to [Cloud Console → Pub/Sub](https://console.cloud.google.com/cloudpubsub)
2. Click **Create Topic**
3. Topic ID: `gmail-notifications`
4. Uncheck "Add default subscription"
5. Create

Note the full name: `projects/YOUR-PROJECT-ID/topics/gmail-notifications`

## 2. Grant Gmail Permission

1. Select your topic → **Permissions**
2. Click **Grant Access**
3. Principal: `gmail-api-push@system.gserviceaccount.com`
4. Role: **Pub/Sub Publisher**
5. Save

## 3. Create Push Subscription

1. Click your topic → **Create Subscription**
2. Configure:

| Setting | Value |
|---------|-------|
| ID | `gmail-push-subscription` |
| Delivery type | **Push** |
| Endpoint URL | `https://your-server.com/api/v1/webhooks/gmail/push` |
| Expiration | Never expire |
| Ack deadline | 60 seconds |

3. Create

## 4. Enable Push Authentication

**Required for production.** Secures webhook endpoint with OIDC JWT verification.

1. Create a service account (or use existing):
   ```bash
   gcloud iam service-accounts create pubsub-invoker \
     --display-name="Pub/Sub Push Invoker"
   ```

2. Update subscription with OIDC auth:
   ```bash
   gcloud pubsub subscriptions update gmail-push-subscription \
     --push-auth-service-account=pubsub-invoker@YOUR-PROJECT.iam.gserviceaccount.com \
     --push-auth-token-audience=https://your-server.com/api/v1/webhooks/gmail/push
   ```

3. Set environment variable on OpenPlane server:
   ```bash
   PUBSUB_AUDIENCE=https://your-server.com/api/v1/webhooks/gmail/push
   ```

The audience URL must match exactly between the subscription and environment variable.

## 5. Configure OpenPlane

1. Go to **Settings → Connectors → Gmail**
2. Enable **Real-time sync**
3. Enter topic: `projects/YOUR-PROJECT-ID/topics/gmail-notifications`
4. Save

## Verify

Send a test email to your connected Gmail. Check logs for:
```text
Gmail push notification received
```

## Troubleshooting

| Issue | Fix |
|-------|-----|
| No notifications | Verify `gmail-api-push@...` has Publisher role |
| 403 on webhook | Check SSL certificate is valid (not self-signed) |
| 403 token validation | Verify `PUBSUB_AUDIENCE` matches subscription audience exactly |
| pubsub_not_configured | Set `PUBSUB_AUDIENCE` environment variable |
| Watch expired | Click **Refresh Watch** in connector settings |
