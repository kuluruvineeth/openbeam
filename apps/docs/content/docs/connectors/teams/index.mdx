# Microsoft Teams

Index channel messages and replies from Microsoft Teams. Supports OAuth 2.0 via Azure AD with shared authentication alongside Outlook and SharePoint. Full and incremental sync via Microsoft Graph API.

## What Gets Indexed

| Content | Details |
|---------|---------|
| **Channel messages** | Message text, sender, timestamps, mentions |
| **Replies** | Threaded replies within channel conversations |
| **Teams** | Team names, descriptions, membership |
| **Channels** | Channel names and descriptions |

## Authentication

**Method:** OAuth 2.0 via Azure AD (shared with Outlook and SharePoint)

**Scopes:** `ChannelMessage.Read.All`, `Team.ReadBasic.All`, `User.Read`, `offline_access`

Uses the same Azure AD app registration as other Microsoft connectors. Add Teams-specific permissions to your existing app.

## Quick Start

1. Register an application in Azure AD (or reuse your existing Microsoft app)
2. Add `ChannelMessage.Read.All` and `Team.ReadBasic.All` permissions
3. Add the Teams connector in OpenBeam with your Azure AD credentials
4. Authorize and start the initial sync
