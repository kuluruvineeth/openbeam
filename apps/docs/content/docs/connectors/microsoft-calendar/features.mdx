# Features

## Indexed Content

The Microsoft Calendar connector indexes all events from your calendar view, including:

- **Event metadata**: Subject, body preview, full body content (HTML stripped)
- **Time information**: Start/end datetime with timezone, all-day event detection
- **Location**: Display name of event location
- **People**: Organizer name/email, attendee list with response status
- **Status**: Show-as status (busy, free, tentative), importance level
- **Recurrence**: Recurring event detection

## Search Capabilities

- Full-text search across event subjects and body content
- Filter by date range, attendees, or location
- Find meetings with specific participants
- Search across all calendar events in a unified index

## Privacy

Calendar events are marked as PII (personally identifiable information). Access control is enforced based on attendee email addresses.
