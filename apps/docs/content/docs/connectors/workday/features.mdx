# Workday Features

## Worker Directory

Search across the complete worker directory including:

- **Name and Contact**: Full name, work email, phone numbers
- **Job Information**: Title, department, division, location
- **Reporting Chain**: Direct manager and supervisory organization
- **Employment Details**: Hire date, worker type, employee ID, status

## Organization Hierarchy

Navigate organizational structure:

- **Supervisory Organizations**: Departments and teams
- **Cost Centers**: Financial groupings
- **Parent-Child Relationships**: Full org hierarchy
- **Organization Managers**: Leadership visibility

## Search Capabilities

- Find workers by name, title, department, or location
- Browse organizational charts
- Discover team structures and reporting chains
- Filter by active/inactive status
