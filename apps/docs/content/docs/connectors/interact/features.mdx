# Features

## Indexed Entities

### Pages
Full-text search across intranet page titles, body content, and section metadata. Content is automatically stripped of HTML for clean indexing.

### News Articles
Search across company news and announcements. Metadata includes category, tags, publication date, and author attribution.

### Documents
Document library entries with titles, descriptions, file names, types, and sizes. Enables discovery of files stored in the Interact document management system.

### People
Employee directory profiles with names, job titles, departments, locations, managers, and bios. Enables quick lookup of colleagues and organizational structure.

### Spaces
Community spaces and team areas with descriptions, types, member counts, and ownership. Useful for discovering relevant teams and communities.

## Actions

The connector supports write operations for agent workflows:

| Action | Description |
|--------|-------------|
| **Create Page** | Create a new intranet content page |
| **Update Page** | Update an existing page title or content |

## Knowledge Graph

The connector feeds the knowledge graph with:
- **Author attribution** from pages, news articles, and documents
- **Organizational structure** from people profiles and manager relationships
- **Community membership** from spaces and their owners
