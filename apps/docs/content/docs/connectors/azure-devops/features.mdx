# Features

## Indexed Content

### Work Items
All work item types are indexed: Bugs, Tasks, User Stories, Features, and Epics. Each work item includes:
- Title and description
- State, priority, and assigned user
- Tags, area path, and iteration path
- Project and work item type

### Repositories
Git repositories across all projects with:
- Repository name and default branch
- Project association
- Web URL for direct navigation

### Pull Requests
All pull requests (active, completed, abandoned) with:
- Title and description
- Source and target branches
- Creator and reviewer information
- Status and merge status
- Labels

### Wiki Pages
Project wiki content with:
- Page title and full content
- Path hierarchy
- Project and wiki association

## Search Capabilities

- Full-text search across all indexed entities
- Filter by document type (work item, repository, PR, wiki page)
- Filter by project, state, priority, or work item type
- Semantic search understands natural language queries

## Actions

| Action | Description |
|--------|-------------|
| Create Work Item | Create bugs, tasks, stories, features, or epics |
| Update Work Item | Modify title, description, state, priority, assignee, or tags |
| Add Comment | Add a discussion comment to any work item |
