# AWS IoT Core

Index IoT things, device shadows, and thing groups from the AWS IoT Core registry. The connector uses IAM access keys and supports multi-region deployments.

AWS IoT Core gives you searchable access to your entire device fleet -- thing attributes, shadow state (reported and desired), and organizational grouping.

## Authentication

**Method:** IAM Access Keys

Provide an AWS Access Key ID and Secret Access Key for an IAM user or role with IoT read permissions.

Required IAM permissions:
- `iot:ListThings`
- `iot:DescribeThing`
- `iot:GetThingShadow`
- `iot:ListThingGroups`
- `iot:DescribeThingGroup`

[AWS IoT security docs](https://docs.aws.amazon.com/iot/latest/developerguide/security-iam.html)

## Data Streams

| Stream | Description | Sync Mode | Interval |
|--------|-------------|-----------|----------|
| **Things** | Name, thing type, attributes, ARN, connectivity, shadow state | Periodic | 30 min |
| **Thing Groups** | Name, description, parent group, ARN, attributes | Periodic | 60 min |

Both streams support full backfill.

## Setup

1. In the **AWS IAM Console**, create an IAM user or role with the permissions listed above
2. Generate an **Access Key ID** and **Secret Access Key**
3. In OpenPlane, add the AWS IoT Core connector
4. Enter the credentials and select the AWS region where your IoT resources are deployed
5. Start the initial sync

## Configuration

| Setting | Default | Description |
|---------|---------|-------------|
| AWS Access Key ID | -- | IAM access key with IoT read permissions (required) |
| AWS Secret Access Key | -- | Corresponding secret key (required) |
| AWS Region | us-east-1 | Region where your IoT resources are deployed (required) |
| Sync Thing Groups | On | Include thing groups in the search index |
| Sync Device Shadows | On | Include device shadow state in thing documents |

### Supported Regions

US East (N. Virginia), US East (Ohio), US West (N. California), US West (Oregon), EU (Ireland), EU (London), EU (Frankfurt), Asia Pacific (Tokyo), Asia Pacific (Singapore), Asia Pacific (Sydney).

## Sync Details

**Full sync** lists all things in the registry and fetches their attributes, shadow state, and group memberships.

**Incremental sync** uses the IoT registry API to detect changes since the last sync timestamp.

Device shadows are embedded into thing documents when the "Sync Device Shadows" setting is enabled, making reported and desired state searchable alongside thing metadata.
