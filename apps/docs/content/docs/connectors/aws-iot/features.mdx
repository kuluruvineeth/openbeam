# AWS IoT Core Features

## Content Types

| Type | Fields Indexed |
|------|----------------|
| Things | Name, thing type, attributes, ARN, connectivity status |
| Thing Groups | Name, description, parent group, ARN, attributes |
| Device Shadows | Reported state, desired state, metadata, version |

## Metadata

| Field | Searchable | Filterable |
|-------|------------|------------|
| Thing name | Yes | Yes |
| Thing type | Yes | Yes |
| Connectivity | No | Yes |
| Shadow state | Yes | No |
| Group name | Yes | Yes |
| ARN | No | Yes |

## Sync Modes

| Mode | Trigger | Latency |
|------|---------|---------|
| Full | First sync, manual | Minutes |
| Incremental | Scheduled | 15 min |

## AI Capabilities

- Semantic search across all indexed things, thing groups, and device shadows
- Question answering about device fleet configuration and connectivity status
- Device fleet health analysis from connectivity patterns and shadow state aggregation
- Shadow drift detection between reported and desired states across thing groups
- Connectivity pattern analysis to identify unreliable devices and network issues

## Limitations

| Limit | Value |
|-------|-------|
| API rate limit | 300 req/min, 10,000 req/hour |
| Burst limit | 10 concurrent |
| Page size | 250 things per page |
| Regions | 10 AWS regions supported |
