# Coupa

Index business spend management data from Coupa including purchase orders, invoices, requisitions, suppliers, contracts, and expense reports. Supports OAuth 2.0 client credentials authentication with offset-based pagination and updated_at incremental sync.

## What Gets Indexed

| Content | Details |
|---------|---------|
| **Purchase Orders** | PO number, status, total, currency, supplier, requester, line items |
| **Invoices** | Invoice number, status, total, supplier, due date, payment date, line items |
| **Requisitions** | Requisition number, status, total, requester, department, justification |
| **Suppliers** | Name, number, status, payment terms, primary contact, address, tax ID |
| **Contracts** | Name, number, status, start/end dates, value, supplier, terms |
| **Expense Reports** | Title, status, total, submitter, department, expense lines |

## Authentication

**Method:** OAuth 2.0 Client Credentials (server-to-server)

Create an OAuth 2.0 client from **Setup > Integrations > OAuth2/OpenID Connect Clients** in Coupa. The client must have `core.read` scope.

## Quick Start

1. Create an OAuth 2.0 client in Coupa
2. Add the Coupa connector in OpenBeam
3. Enter your instance URL, client ID, and client secret
4. Start the initial sync
