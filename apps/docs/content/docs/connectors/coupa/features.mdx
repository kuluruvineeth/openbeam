# Coupa Features

## Indexed Content

### Purchase Orders
- PO number, status, total amount with tax
- Supplier name and number
- Requester and ship-to address
- Line item descriptions

### Invoices
- Invoice number, status, total amount
- Supplier, due date, payment date
- Line item descriptions

### Requisitions
- Requisition number, status, total
- Requester, department, justification
- Line item descriptions

### Suppliers
- Name, supplier number, status
- Payment terms, primary contact
- Address, tax ID, website

### Contracts
- Name, contract number, status
- Start and end dates, max/min value
- Supplier, description, terms

### Expense Reports
- Title, status, total amount
- Submitter, department
- Expense line items with categories and dates

## Search Capabilities

- Full-text search across all entity types
- Filter by document type (purchase order, invoice, etc.)
- Filter by status, supplier, department
- Sort by created or updated date
