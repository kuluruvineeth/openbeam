# Egnyte

Index enterprise content from Egnyte including files, folders, and shared links. Supports OAuth 2.0 with domain-specific authentication and events-based incremental sync for efficient change detection.

## What Gets Indexed

| Content | Details |
|---------|---------|
| **Files** | Name, path, size, checksum, upload date, modifier |
| **Folders** | Name, path, file count, folder count |
| **Shared Links** | URL, path, accessibility, creation date, expiry |

## Authentication

**Method:** OAuth 2.0 (Authorization Code Grant)

Requires an Egnyte API key (client ID and secret) created in the Egnyte Developer Portal. Each Egnyte domain (e.g., acme.egnyte.com) requires its own OAuth application.

## Quick Start

1. Create an API application in the Egnyte Developer Portal
2. Add the Egnyte connector in OpenBeam
3. Enter your domain, client ID, and client secret
4. Authorize via OAuth
5. Start the initial sync
