# Evernote

Index notes, notebooks, and tags from Evernote. Note content is extracted from ENML (Evernote Markup Language) and converted to plain text for full-text search. Supports incremental sync via update sequence numbers (USN).

## What Gets Indexed

| Content | Details |
|---------|---------|
| **Notes** | Title, ENML content (converted to plain text), tags, notebook, author, source URL |
| **Notebooks** | Name, stack grouping, default status |
| **Tags** | Name, parent tag hierarchy |

## Authentication

**Method:** Developer Token (API Key)

Generate a developer token from [dev.evernote.com](https://dev.evernote.com/get-api-key). The token provides read/write access to the account's notes.

## Quick Start

1. Generate a developer token at dev.evernote.com
2. Add the Evernote connector in OpenBeam
3. Enter your developer token and select your environment
4. Start the initial sync
