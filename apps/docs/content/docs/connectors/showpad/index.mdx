# Showpad

Index sales enablement content from Showpad including assets, channels, shared experiences, and tags. Supports OAuth 2.0 with subdomain-specific URLs and updatedSince-based incremental sync.

## What Gets Indexed

| Content | Details |
|---------|---------|
| **Assets** | Documents, videos, presentations, images with tags, channels, expiration |
| **Channels** | Content collections for organizing and distributing sales material |
| **Experiences** | Shared content packages and microsites for buyer engagement |
| **Tags** | Content categorization tags used across the platform |

## Authentication

**Method:** OAuth 2.0 (Authorization Code Grant)

Showpad uses subdomain-specific OAuth URLs. You need your Showpad subdomain, client ID, and client secret from the Showpad Admin portal.

## Quick Start

1. Register an OAuth app in Showpad Admin
2. Add the Showpad connector in OpenBeam
3. Enter your subdomain, client ID, and client secret
4. Complete the OAuth authorization flow
5. Start the initial sync
