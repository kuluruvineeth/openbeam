# Permissions

OpenBeam respects Slack's native permissions. Users can only search content from channels they're members of.

## Access Rules

| Content | Who Can Search |
|---------|---------------|
| Public channel | All workspace users |
| Private channel | Channel members only |
| DMs | Participants only |
| Files | Inherits from share location |
| Threads | Inherits from parent message |

## Permission Sync

Permissions sync:
- On initial setup
- Every 12 hours
- On membership change events (via webhooks)

## Slack Connect

| Setting | Behavior |
|---------|----------|
| `sync_external_channels: false` | External channels not indexed |
| `sync_external_channels: true` | External channels indexed |
| `index_external_content: false` | Only your org's messages |
| `index_external_content: true` | All messages |

Guest users only see their invited channels.
