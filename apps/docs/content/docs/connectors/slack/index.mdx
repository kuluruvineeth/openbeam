Index messages, threads, files, canvases, and clips. Real-time sync via Event Subscriptions.

## What's Indexed

- **Messages & threads** - Full-text search with context
- **Files** - Text extraction (PDF, DOCX, images via OCR)
- **Canvases** - Full content indexing
- **Clips** - Audio/video transcription

## Quick Start

1. Create Slack app using the [manifest](/docs/connectors/slack/app-setup)
2. Set OAuth redirect URI and scopes
3. Enable Event Subscriptions
4. Connect in OpenPlane UI

## Interactive Features

- `/openplane search <query>` - Search all content
- `/openplane ask <question>` - AI-powered answers
- `@OpenPlane` - Mention in any channel for contextual help
- Message shortcuts - Summarize threads, save messages, find related
