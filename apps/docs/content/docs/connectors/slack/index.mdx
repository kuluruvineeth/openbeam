# Slack

Index messages, threads, files, canvases, and clips from Slack. Supports OAuth 2.0 authentication, real-time sync via Event Subscriptions, and interactive slash commands.

## What Gets Indexed

| Content | Details |
|---------|---------|
| **Messages and threads** | Full-text search with conversation context |
| **Files** | Text extraction from PDF, DOCX, and images via OCR |
| **Canvases** | Full content indexing |
| **Clips** | Audio and video transcription |

## Authentication

**Method:** OAuth 2.0

Create a Slack app using the provided [manifest](/docs/connectors/slack/app-setup), then configure OAuth redirect URI and scopes.

## Quick Start

1. Create a Slack app using the [manifest](/docs/connectors/slack/app-setup)
2. Set the OAuth redirect URI and required scopes
3. Enable Event Subscriptions for real-time sync
4. Connect Slack in the OpenPlane UI and authorize

## Interactive Features

| Command | Action |
|---------|--------|
| `/openplane search <query>` | Search all connected content |
| `/openplane ask <question>` | AI-powered answers with citations |
| `@OpenPlane` | Mention in any channel for contextual help |
| Message shortcuts | Summarize threads, save messages, find related content |
