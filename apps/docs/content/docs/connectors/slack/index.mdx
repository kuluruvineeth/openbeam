## Indexed Content

| Type | Indexed | Searchable |
|------|---------|------------|
| Messages | Yes | Yes |
| Threads | Yes | Yes |
| Files | Yes | Yes |
| Canvases | Yes | Yes |
| Bookmarks | Yes | Yes |
| Clips | Yes | Yes |

## Setup

1. Create a Slack app ([setup guide](/docs/connectors/slack/setup))
2. Install to workspace with required scopes
3. Configure sync settings
4. Start searching
