# Slack Quick Start

## Prerequisites

- Slack workspace admin access
- OpenPlane instance with HTTPS endpoint

## 1. Create Slack App

1. Go to [api.slack.com/apps](https://api.slack.com/apps)
2. Click **Create New App → From an app manifest**
3. Select workspace and paste the [manifest](/docs/connectors/slack/app-setup)
4. Click **Create**

Replace `your-domain.com` in the manifest with your actual domain.

## 2. Get Credentials

From **Settings → Basic Information**, copy:
- Client ID
- Client Secret
- Signing Secret

## 3. Configure Environment

```bash
SLACK_CLIENT_ID=your-client-id
SLACK_CLIENT_SECRET=your-client-secret
SLACK_SIGNING_SECRET=your-signing-secret
WEB_URL=https://your-domain.com
SERVER_URL=https://api.your-domain.com
```

## 4. Install & Connect

1. In Slack app settings, go to **Install App → Install to Workspace**
2. In OpenPlane, go to **Settings → Connectors → Add Connector → Slack**
3. Click **Connect** and authorize

## Verify

1. Check connector shows **Active** status
2. Search for a recent message
3. Test `@OpenPlane` mention in any channel

Initial sync runs in background. Large workspaces (100k+ messages) may take 1-4 hours.
