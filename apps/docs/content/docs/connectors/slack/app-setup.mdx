# Slack App Manifest

Use this manifest to create your Slack app with all features pre-configured.

## Create App

1. Go to [api.slack.com/apps](https://api.slack.com/apps)
2. Click **Create New App → From an app manifest**
3. Select your workspace
4. Paste the manifest below
5. Click **Create**

Replace `your-domain.com` with your actual domain.

## Manifest

```yaml

  name: OpenBeam
  description: AI-powered search from your knowledge base
  background_color: "#1a1a2e"

  app_home:

    messages_tab_enabled: true

  bot_user:

  shortcuts:

      type: message
      callback_id: search_context
      description: Find related information using this message
    - name: Search OpenBeam
      type: global

      description: Search all connected data sources
    - name: Ask OpenBeam
      type: global

```

## After Creating

1. Go to **Basic Information** and copy:
   - Client ID
   - Client Secret
   - Signing Secret

2. Go to **Install App → Install to Workspace**

3. Configure environment variables:
```bash
SLACK_CLIENT_ID=your-client-id
SLACK_CLIENT_SECRET=your-client-secret
SLACK_SIGNING_SECRET=your-signing-secret
```

See [Quick Start](/docs/connectors/slack/setup) for complete setup.
