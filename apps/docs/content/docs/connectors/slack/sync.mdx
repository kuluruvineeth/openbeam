# Sync Behavior

## Sync Types

| Type | Trigger | Duration |
|------|---------|----------|
| **Full** | First connection, manual resync | Minutes to hours |
| **Incremental** | Scheduled (every 6h) | Seconds to minutes |
| **Real-time** | Event Subscriptions | Instant |

## What Gets Synced

**Messages**: Thread context, mentions resolved to names, reactions

**Files**: Text extraction for documents, OCR for images, transcription for audio/video

| Format | Extraction |
|--------|------------|
| PDF, DOCX, TXT | Full text |
| XLSX, CSV | Cell content |
| PNG, JPG | OCR |
| MP3, MP4 | Transcription |

**Canvases & Clips**: Full content with transcription

## Status

| Status | Meaning |
|--------|---------|
| **Active** | Synced, watching for changes |
| **Syncing** | Sync in progress |
| **Error** | Check logs |
| **Rate Limited** | Auto-resumes when quota resets |

## Controls

- **Full Resync**: Settings → Connectors → Slack → Actions → Full Resync
- **Pause/Resume**: Stop processing temporarily

## Rate Limits

OpenPlane handles Slack rate limits automatically with exponential backoff.

## Troubleshooting

| Issue | Fix |
|-------|-----|
| Sync stuck | Rate limited - wait for reset |
| Private channels missing | Invite bot to channel |
| Files not indexed | Check file size limit |
| Messages delayed | Verify Event Subscription URL |
