# Slack Features

## AI Assistant

Mention `@OpenPlane` in any channel or thread:

```text
@OpenPlane What was the decision on the Q4 roadmap?
```

Or open a direct conversation via **Apps → OpenPlane → Messages**.

## Slash Commands

```text
/openplane search <query>     # Search all indexed content
/openplane ask <question>     # AI-powered answers
/openplane digest [#channel]  # Channel summary
/openplane configure          # Settings
```

### Search Filters

| Filter | Example |
|--------|---------|
| `in:#channel` | `in:#engineering` |
| `from:@user` | `from:@john` |
| `after:YYYY-MM-DD` | `after:2024-01-01` |
| `type:file` | `type:message` |

## Message Shortcuts

Right-click any message (or use `⋮` menu):

- **Save to OpenPlane** - Bookmark for later
- **Ask about this** - AI context on the message
- **Summarize thread** - AI summary
- **Find related** - Search similar content

## Global Shortcuts

Press `⌘G` (Mac) or `Ctrl+G` (Windows):

- **Search OpenPlane** - Global search
- **Ask OpenPlane** - Quick AI query

## Daily Digests

Automated channel summaries with key discussions, decisions, and action items. Configure via `/openplane digest configure`.

## App Home

Access via **Apps → OpenPlane → Home** for:
- Quick search
- Recent activity
- Saved items
- Sync status

## AI Capabilities

- Cross-channel knowledge synthesis — answer questions by combining context from multiple channels and threads
- Decision archaeology — surface past decisions buried in long threads with timestamps and participants
- Meeting follow-up extraction — identify action items, owners, and deadlines from discussion threads
- Expert routing — identify who in the organization has discussed a topic most and in which channels
- Sentiment and tone analysis across channels to surface emerging concerns or blockers
