# Slack Features

## AI Assistant

Mention the bot to get answers from your knowledge base:

```
@OpenPlane What was the decision on the Q4 roadmap?
```

### Response Modes

| Mode | Behavior |
|------|----------|
| Confident | Direct answers |
| Hesitant | Qualified responses |
| Disabled | No AI responses |

## Daily Digests

Automated channel summaries delivered on schedule.

| Content | Description |
|---------|-------------|
| Discussions | Key conversations |
| Action Items | Assigned tasks |
| Announcements | Updates |

## Search

Use `/openplane` to search:

```
/openplane find design system documentation
```

### Filters

| Filter | Example |
|--------|---------|
| Channel | `in:#engineering` |
| User | `from:@john` |
| Date | `after:2024-01-01` |
| Type | `type:file` |

## Message Actions

Right-click on any message:

- **Save** — Bookmark for later
- **Ask** — Query AI about context
- **Find related** — Search similar content

## Notifications

- Saved search matches
- Topic mentions
- Action items assigned
