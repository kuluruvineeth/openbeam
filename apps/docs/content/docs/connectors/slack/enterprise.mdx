# Enterprise Grid

## Installation Options

**Organization-level** (cross-workspace search):
1. Create app in Enterprise Grid admin console
2. Install to organization
3. Grant access to specific workspaces

**Workspace-level** (individual control):
1. Install app per workspace
2. Search limited to installed workspaces

## Additional Scopes

| Scope | Purpose |
|-------|---------|
| `admin.conversations:read` | List all org conversations |
| `admin.teams:read` | List all workspaces |
| `admin.users:read` | List all org users |

## Per-Workspace Settings

```json
{
  "workspaces": {
    "T01234567": { "enabled": true, "index_private_channels": false },
    "T89012345": { "enabled": true, "index_private_channels": true }
  },
  "excluded_workspace_ids": ["T99999999"]
}
```

## Shared Channels

- **Internal**: Indexed once, accessible from both workspaces
- **External (Slack Connect)**: Configure via `sync_external_channels`

## Compliance

- Discovery API supported for exports and legal holds
- Retention policies respected
- Audit logging for all access
