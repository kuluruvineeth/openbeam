# Troubleshooting

## OAuth Errors

| Error | Fix |
|-------|-----|
| `not_authed` / `invalid_auth` | Disconnect and reconnect |
| `missing_scope` | Add scope in Slack app, reinstall app |
| `token_revoked` | Reconnect; check app wasn't uninstalled |
| `invalid_client_id` | Verify `SLACK_CLIENT_ID` env var |

## Sync Issues

| Issue | Fix |
|-------|-----|
| Messages not appearing | Check connector is Active; invite bot to private channels |
| Files not indexed | Enable file indexing; check `files:read` scope |
| Slow initial sync | Normal for large workspaces (100k+ = 1-4 hours) |
| Rate limited | Automatic backoff; wait for reset |

## Webhook Issues

| Issue | Fix |
|-------|-----|
| Events not received | Verify Event Subscription URL is correct and accessible |
| Signature verification failed | Check `SLACK_SIGNING_SECRET` matches app settings |
| Interactivity not working | Check Interactivity Request URL |

## Bot Issues

| Issue | Fix |
|-------|-----|
| Bot not responding | Verify `@OpenBeam` mention; invite bot to channel |
| Response timeout | AI processing exceeded 30s limit; simplify query |
| Shortcuts not appearing | Reinstall app; refresh Slack (Cmd+R) |

## Debug Commands

```bash
# Check webhook health
curl https://api.your-domain.com/api/v1/webhooks/slack/health

# Check logs
tail -f logs/worker.log | grep -i slack
```

## Error Reference

| Error | Code | Fix |
|-------|------|-----|
| `not_authed` | 401 | Reconnect |
| `missing_scope` | 403 | Add scope, reinstall |
| `ratelimited` | 429 | Wait |
| `channel_not_found` | 404 | Channel deleted |
| `service_unavailable` | 503 | Check status.slack.com |
