# Configuration

## Content Settings

| Setting | Default | Description |
|---------|---------|-------------|
| `index_private_channels` | `false` | Index private channels (bot must be member) |
| `index_dms` | `false` | Index direct messages |
| `index_group_dms` | `false` | Index multi-person DMs |
| `index_canvases` | `true` | Index Slack Canvases |
| `index_clips` | `true` | Index video/audio clips |
| `index_bookmarks` | `true` | Index channel bookmarks |
| `sync_external_channels` | `false` | Index Slack Connect channels |

## Channel Filtering

```json
{
  "enabled_channel_ids": ["C01234567"],
  "disabled_channel_ids": ["C99999999"]
}
```

## AI Assistant

| Setting | Options | Description |
|---------|---------|-------------|
| `responseMode` | `confident`, `hesitant`, `none` | Bot response style |
| `reactionsEnabled` | boolean | Bot adds emoji reactions |

## Sync Settings

```json
{
  "syncConfig": {
    "schedule": "0 */6 * * *",
    "batchSize": 100,
    "maxConcurrency": 5,
    "fullSyncInterval": 86400000
  }
}
```

Rate limits are handled automatically with exponential backoff.
