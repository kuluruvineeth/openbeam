# OAuth Scopes

The [app manifest](/docs/connectors/slack/app-setup) includes all required scopes. This page explains what each does.

## Bot Token Scopes (Required)

| Scope | Purpose |
|-------|---------|
| `channels:read`, `channels:history`, `channels:join` | Public channel access |
| `groups:read`, `groups:history` | Private channel access (where bot is member) |
| `im:read`, `im:history` | DM access |
| `mpim:read`, `mpim:history` | Group DM access |
| `users:read`, `users:read.email` | User profiles |
| `team:read` | Workspace info |
| `files:read` | File access |
| `app_mentions:read` | Receive @mentions |
| `chat:write` | Send messages |
| `commands` | Slash commands |
| `assistant:write` | AI assistant responses |

## Bot Token Scopes (Optional)

| Scope | Purpose |
|-------|---------|
| `bookmarks:read` | Channel bookmarks |
| `pins:read` | Pinned messages |
| `reactions:read`, `reactions:write` | Reactions |
| `links:read`, `links:write` | URL unfurling |

## User Token Scopes (Optional)

For admin-level sync and federated search:

| Scope | Purpose |
|-------|---------|
| `search:read` | Federated search via Slack API |
| `channels:history`, `groups:history` | History access on behalf of user |

## Scope Errors

| Error | Fix |
|-------|-----|
| `missing_scope` | Add scope in app settings, reinstall |
| `not_in_channel` | Add `channels:join`, invite bot |
| `cannot_dm_bot` | Add `im:write` |

Adding or removing scopes requires reinstalling the app.
