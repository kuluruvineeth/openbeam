# HubSpot Features

## Indexed Content

### Contacts
- Full name, email address, phone number
- Job title, company association
- Lifecycle stage and owner
- Custom properties (configurable)

### Companies
- Company name and domain
- Industry and description
- Employee count, phone, location
- Website URL

### Deals
- Deal name, amount, and close date
- Pipeline and stage tracking
- Deal probability
- Owner assignment

### Tickets
- Subject and description
- Pipeline stage and priority
- Creation and close dates

## Search Capabilities

- Full-text search across all CRM object types
- Filter by document type (contact, company, deal, ticket)
- Metadata filtering by stage, pipeline, priority, industry
- Direct links to records in HubSpot portal
