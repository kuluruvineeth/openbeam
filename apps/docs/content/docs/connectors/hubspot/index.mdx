# HubSpot

Index CRM data from HubSpot including contacts, companies, deals, and tickets. Supports OAuth 2.0, incremental sync via the Search API with lastmodifieddate filtering.

## What Gets Indexed

| Content | Details |
|---------|---------|
| **Contacts** | Name, email, phone, job title, company, lifecycle stage |
| **Companies** | Name, domain, industry, description, employee count |
| **Deals** | Name, amount, stage, pipeline, close date |
| **Tickets** | Subject, content, pipeline stage, priority |

## Authentication

**Method:** OAuth 2.0

**Scopes:** `crm.objects.contacts.read`, `crm.objects.companies.read`, `crm.objects.deals.read`, `tickets`

Create a developer app at [HubSpot Developer Portal](https://developers.hubspot.com) and configure OAuth settings.

## Quick Start

1. Create a developer app in the HubSpot Developer Portal
2. Configure OAuth redirect URL and required scopes
3. Add the HubSpot connector in OpenBeam with your Client ID and Secret
4. Authorize and start the initial sync
