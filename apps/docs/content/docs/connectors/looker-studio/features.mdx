# Features

## Indexed Entities

### Reports

Full-text search across Looker Studio report names and descriptions. Reports include interactive dashboards and visualizations. Metadata includes ownership, creation date, last modified date, and direct URLs to the report in Looker Studio.

### Data Sources

Connected data sources that power Looker Studio reports. Includes data source names, descriptions, and ownership information. Useful for understanding data lineage and finding who manages specific data connections.

## Actions

The connector supports read-only operations:

| Action | Description |
|--------|-------------|
| **Get Report Metadata** | Fetch metadata for a specific report by ID |

## Search Capabilities

- Search reports by name, description, or owner
- Filter by entity type (report or data source)
- Sort by last modified date for recently updated dashboards
- Find data sources by name to understand data dependencies
