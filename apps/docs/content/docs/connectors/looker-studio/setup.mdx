# Looker Studio Setup

## Prerequisites

- A Google account with access to Looker Studio
- Access to Google Cloud Console for OAuth credentials

## Step 1: Create OAuth Credentials

1. Go to [Google Cloud Console](https://console.cloud.google.com)
2. Select or create a project
3. Navigate to **APIs & Services > Credentials**
4. Click **Create Credentials > OAuth client ID**
5. Select **Web application** as the application type
6. Add your OpenBeam callback URL as an authorized redirect URI
7. Download the credentials JSON file

## Step 2: Enable Required APIs

1. In Google Cloud Console, go to **APIs & Services > Library**
2. Enable **Google Drive API** (used to discover Looker Studio files)

## Step 3: Add Connector in OpenBeam

1. Navigate to **Settings > Connectors**
2. Click **Add Connector** and select **Looker Studio**
3. Choose your authentication method:
   - **OAuth 2.0**: Upload credentials JSON or enter client ID/secret manually
   - **Service Account**: For Google Workspace domain-wide delegation
4. Click **Connect** to start the OAuth flow
5. Authorize the requested permissions in Google

## Step 4: Initial Sync

After authorization, OpenBeam runs a full sync of all Looker Studio reports and data sources accessible to the authenticated user.

## Service Account Setup (Workspace)

For organizations using Google Workspace:

1. Create a service account in Google Cloud Console
2. Enable domain-wide delegation
3. Add the required scopes in Workspace Admin Console
4. Upload the service account key JSON in OpenBeam
5. Enter the admin email for impersonation
