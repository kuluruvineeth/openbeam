# Troubleshooting

## Authentication Errors

**Token expired:** Pipedrive access tokens expire after 1 hour. OpenBeam automatically refreshes tokens. If you see auth errors, try disconnecting and reconnecting the connector.

**Invalid credentials:** Verify your Client ID and Client Secret match the values in Pipedrive Marketplace Manager.

## Rate Limiting

**429 Too Many Requests:** The connector automatically backs off when rate limited. If syncs are consistently slow, consider reducing the number of enabled entity types.

## Missing Data

**Deals not appearing:** Check if a pipeline filter is configured. Only deals in the specified pipelines will be indexed.

**Activities/Notes missing:** Verify these entity types are enabled in the connector settings.

## Sync Failures

**Incremental sync falling back to full:** This happens when the cursor timestamp is too old. The connector automatically recovers by running a full sync.

**Connection timeout:** Pipedrive API may be temporarily unavailable. The connector will retry automatically with exponential backoff.
