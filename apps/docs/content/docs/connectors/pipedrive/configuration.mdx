# Configuration

## Settings

| Setting | Description | Default |
|---------|-------------|---------|
| **Sync Activities** | Index activities (calls, meetings, tasks) | Enabled |
| **Sync Notes** | Index notes attached to deals and contacts | Enabled |
| **Sync Organizations** | Index organizations | Enabled |
| **Pipeline Filter** | Comma-separated pipeline IDs to restrict deal sync | All pipelines |
| **History (days)** | How far back to sync | Unlimited |

## Pipeline Filtering

To sync deals from specific pipelines only, enter a comma-separated list of pipeline IDs in the **Pipeline Filter** field. Pipeline IDs can be found in the Pipedrive URL when viewing a pipeline.

## Entity Toggles

Use the entity toggles to control which data types are indexed. Deals and persons are always synced. Activities, notes, and organizations can be individually disabled.
