# OPC-UA

Browse OPC-UA server address spaces, subscribe to node value changes, and index historical data from industrial automation servers. The connector supports OPC-UA 1.05, companion specifications (MTConnect, PackML, PLCopen), and X.509 certificate authentication.

OPC-UA is the standard for industrial automation data. This connector makes PLC values, SCADA alarms, and historian data searchable.

## Authentication

**Method:** Username/Password or Anonymous

Two authentication modes are supported:

| Mode | When to use |
|------|------------|
| **Username/Password** | Standard credentials for the OPC-UA server |
| **Anonymous** | Leave username and password empty |

Security is configured separately with message security modes and cryptographic policies.

### Security Modes

| Mode | Protection |
|------|-----------|
| None | No security (development only) |
| Sign | Message integrity |
| Sign and Encrypt | Message integrity + confidentiality |

### Security Policies

| Policy | Strength |
|--------|----------|
| None | No encryption |
| Basic256 | Legacy (acceptable) |
| Basic256Sha256 | Recommended |
| AES-128 SHA-256 RSA-OAEP | Strongest |

## Data Streams

| Stream | Description | Sync Mode | Interval |
|--------|-------------|-----------|----------|
| **Node Values** | Real-time node value changes from server-push subscriptions (NodeId, value, status code, timestamp) | Real-time | 60s |
| **Alarms and Conditions** | OPC-UA alarm and condition events (type, severity, source, message) | Real-time | Instant |

Node values support backfill via Historical Data Access (HDA). Alarms do not.

## Setup

1. Identify your **OPC-UA server** endpoint URL (e.g., `opc.tcp://server:4840`)
2. In OpenPlane, add the OPC-UA connector
3. Enter the endpoint URL, security mode, and security policy
4. Provide credentials if required (leave empty for anonymous)
5. Start the initial sync to browse the address space

## Configuration

| Setting | Default | Description |
|---------|---------|-------------|
| Endpoint URL | -- | OPC-UA server endpoint, e.g., `opc.tcp://server:4840` (required) |
| Security Mode | Sign and Encrypt | None, Sign, or Sign and Encrypt |
| Security Policy | Basic256Sha256 | Cryptographic policy for the connection |
| Username | -- | Server username (leave empty for anonymous) |
| Password | -- | Server password |

## Sync Details

**Full sync** browses the OPC-UA address space starting from the root node. It discovers all variable nodes, reads their current values, and creates searchable documents with node metadata.

**Real-time subscriptions** create OPC-UA monitored items for variable nodes. The server pushes value changes to the connector, which indexes them immediately.

**Historical Data Access (HDA)** retrieves archived values from OPC-UA historian nodes for backfill. The connector queries the historian for a configurable time range.

**Companion specifications** like MTConnect, PackML, and PLCopen define standard node structures. The connector recognizes these structures and enriches documents with domain-specific metadata (e.g., machine state, tool wear, cycle count).
