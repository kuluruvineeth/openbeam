# Marketo

Index marketing automation data from Adobe Marketo Engage including leads, activities, campaigns, programs, emails, and landing pages. Uses OAuth 2.0 client credentials with cursor-based pagination and incremental sync via updatedAt filters.

## What Gets Indexed

| Content | Details |
|---------|---------|
| **Leads** | Name, email, company, title, phone, lead source, status, location |
| **Activities** | Type, lead, primary attribute, date, custom attributes |
| **Campaigns** | Name, type, program, workspace, active status |
| **Programs** | Name, type, channel, status, workspace, folder |
| **Emails** | Name, subject, from name, status, workspace |
| **Landing Pages** | Name, URL, status, template, workspace |

## Authentication

**Method:** OAuth 2.0 Client Credentials (server-to-server)

**Required:** Munchkin ID, Client ID, Client Secret

Create a LaunchPoint API Only service in Admin > Integration > LaunchPoint.

## Quick Start

1. Find your Munchkin ID in Admin > Integration > Munchkin
2. Create a LaunchPoint service in Admin > Integration > LaunchPoint
3. Add the Marketo connector in OpenBeam with your credentials
4. Authenticate and start the initial sync
