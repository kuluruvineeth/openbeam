# Marketo Features

## Indexed Content

### Leads
- Full name, email, company, title, phone
- Lead source, lead status, industry
- Geographic location (city, state, country)
- Creation and last modified timestamps

### Activities
- Activity type classification (email opens, clicks, form fills, web visits)
- Primary attribute values (email name, web page, form name)
- Lead association and custom attributes
- Activity date tracking

### Campaigns
- Campaign name, type (batch, trigger), and description
- Associated program and workspace
- Active/inactive status
- Creation and modification timestamps

### Programs
- Program name, type (email, event, engagement, default)
- Channel, status, and workspace
- Folder hierarchy
- Direct URL to program in Marketo

### Emails
- Email name and subject line
- From name and from email address
- Approval status and operational flag
- Associated workspace and folder

### Landing Pages
- Page name, title, and description
- Published URL and status
- Mobile-enabled flag
- Associated template and workspace

## Search Capabilities

- Full-text search across all lead fields and content
- Filter by document type (lead, activity, campaign, program, email, landing_page)
- Filter by metadata fields (status, type, workspace)
- Sort by recency (updatedAt)
