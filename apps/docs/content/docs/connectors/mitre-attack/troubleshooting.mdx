# Troubleshooting

## Sync Issues

<Accordions>
  <Accordion title="STIX bundle download fails">
    The GitHub raw content URL may be temporarily unavailable or rate-limited.

    **Fix:**
    1. The connector retries failed downloads automatically
    2. GitHub rate limits unauthenticated requests to 60 per hour -- the connector needs only 3 requests (one per matrix)
    3. If persistent, verify network connectivity to `raw.githubusercontent.com`
  </Accordion>

  <Accordion title="Relationships not resolved">
    STIX relationship objects link techniques to groups, tactics, and mitigations. Missing relationships usually indicate a partial download.

    **Fix:**
    - Trigger a full resync to re-download all STIX bundles
    - Verify all enabled matrices completed successfully in the sync status
  </Accordion>
</Accordions>

## Missing Data

<Accordions>
  <Accordion title="Sub-techniques not appearing">
    Sub-techniques (e.g., T1566.001) are separate STIX objects linked to parent techniques via relationships.

    **Fix:**
    - Verify the sync completed successfully
    - Search by the full sub-technique ID: `T1566.001`
    - If missing, trigger a full resync
  </Accordion>

  <Accordion title="ICS or Mobile techniques missing">
    These matrices may be disabled in the connector configuration.

    **Fix:**
    1. Go to the connector settings
    2. Verify the desired matrices are enabled
    3. Trigger a full resync after enabling a new matrix
  </Accordion>
</Accordions>
