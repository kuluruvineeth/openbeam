# Sync Behavior

## Sync Types

| Type | Trigger | Duration |
|------|---------|----------|
| **Full** | First connection, manual resync | 2-5 minutes |
| **Incremental** | Scheduled | < 1 minute |

## Full Sync Process

1. **Download STIX bundles**: Fetch JSON files from the MITRE CTI GitHub repository for each enabled matrix
2. **Parse objects**: Extract STIX objects by type (attack-pattern, intrusion-set, malware, course-of-action, x-mitre-tactic)
3. **Resolve relationships**: Link techniques to tactics, groups to techniques, and mitigations to techniques using STIX relationship objects
4. **Transform**: Convert each object to a searchable document with resolved references
5. **Index**: Batch index documents (50 per batch)

## Incremental Sync

Checks the GitHub repository for new commits or releases since the last sync. If the STIX bundles have been updated, re-downloads and re-processes only the changed files. MITRE ATT&CK updates quarterly with occasional interim patches.
