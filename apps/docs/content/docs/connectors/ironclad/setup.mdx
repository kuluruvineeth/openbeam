# Ironclad Setup

## Prerequisites

- An Ironclad account with admin access
- Access to Ironclad API settings

## Step 1: Generate an API Key

1. Log into [Ironclad](https://ironcladapp.com)
2. Navigate to **Admin Settings > API**
3. Click **Generate API Key**
4. Name it something like "OpenBeam Integration"
5. Copy the generated API key

## Step 2: Add Connector in OpenBeam

1. Navigate to **Settings > Connectors**
2. Click **Add Connector** and select **Ironclad**
3. Enter your **API Key**
4. Click **Connect** to validate and activate

## Step 3: Initial Sync

After activation, OpenBeam runs a full sync of your Ironclad data. The first sync fetches all workflows (active contracts), their approvals and comments, plus all executed records.
