# Seismic Features

## Indexed Content Types

### Contents
Sales documents, presentations, videos, and other content assets stored in Seismic. Each content item includes:
- Name and description
- Content type and format (PDF, PPTX, DOCX, etc.)
- Version number
- Workspace assignment
- Tags and metadata
- Author information

### Workspaces
Content organization units (teamsites) in Seismic. Each workspace includes:
- Name and description
- Default workspace status

### LiveDocs
Dynamic content templates that use merge fields to generate personalized documents. Each LiveDoc includes:
- Template name and description
- Template format
- Tags
- Author information

## Search Capabilities

- Full-text search across all content names, descriptions, and tags
- Filter by content type, workspace, or format
- Find content by author
- Search LiveDoc templates by name or description
