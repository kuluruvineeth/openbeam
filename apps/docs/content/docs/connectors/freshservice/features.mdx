# Freshservice Features

## Indexed Content

### Tickets

Every ticket includes:
- Subject and description (full text searchable)
- Status (Open, Pending, Resolved, Closed)
- Priority (Low, Medium, High, Urgent)
- Type (Incident, Service Request, etc.)
- Requester name and email
- Category and sub-category
- Tags
- Created and updated timestamps

### Knowledge Articles

Solution articles from your knowledge base:
- Title and body content
- Folder and category hierarchy
- Publication status (Draft, Published)
- Tags
- Author information

### Changes (Optional)

Change management records:
- Subject and description
- Status (Open, Planning, Awaiting Approval, etc.)
- Priority and change type (Minor, Standard, Major, Emergency)
- Planned start and end dates

### Problems (Optional)

Problem management records:
- Subject and description
- Status, priority, and impact level
- Known error flag
- Category classification

## Actions

| Action | Description |
|--------|-------------|
| **Create Ticket** | Create a new ticket with subject, description, priority |
| **Update Ticket** | Change status, priority, or description |
| **Add Note** | Add a private note to an existing ticket |
| **Reply** | Send a reply on a ticket |

## Search Capabilities

- Full-text search across all indexed content
- Filter by document type (ticket, article, change, problem)
- Filter by status, priority, and category metadata
- Direct links to items in Freshservice
