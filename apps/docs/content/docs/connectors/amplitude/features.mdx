# Amplitude Features

## Indexed Content

### Charts

Saved analysis charts from Amplitude including:

- Chart name and description
- Chart type (Event Segmentation, Funnel Analysis, Retention, etc.)
- Creator/owner
- Public/private sharing status
- Project association
- Last modified timestamp

### Dashboards

Amplitude dashboards with:

- Dashboard name and description
- List of included charts
- Chart count
- Creator/owner
- Public/private sharing status
- Last modified timestamp

### Cohorts

User segment definitions including:

- Cohort name and description
- Segment definition criteria
- Estimated user count
- Published status
- Creator/owner
- Last computed and modified timestamps

## Search Examples

| Query | Finds |
|-------|-------|
| "retention analysis" | Charts of type retention_analysis |
| "weekly active users" | Charts and dashboards mentioning WAU |
| "power users cohort" | Cohort definitions for power user segments |
| "funnel conversion" | Funnel analysis charts |
| "product overview dashboard" | Dashboards with product metrics |
