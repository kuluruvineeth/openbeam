# Amplitude

Index product analytics data from Amplitude including saved charts, dashboards, and user cohorts. Supports API key + secret key authentication with Basic auth encoding.

## What Gets Indexed

| Content | Details |
|---------|---------|
| **Charts** | Name, chart type, description, creator, sharing status |
| **Dashboards** | Name, description, included charts, creator, sharing status |
| **Cohorts** | Name, description, definition, estimated size, creator |

## Authentication

**Method:** API Key + Secret Key (Basic Auth)

Both keys are found in **Settings > Projects > [Your Project]** in Amplitude. The connector uses HTTP Basic authentication with the API key as the username and secret key as the password.

## Quick Start

1. Copy your API Key and Secret Key from Amplitude project settings
2. Add the Amplitude connector in OpenBeam
3. Enter both keys and optionally your organization slug
4. Start the initial sync
