# Guru

Index knowledge management data from Guru including cards, collections, and folders. Supports Basic authentication (email + API token), Link-header pagination, and incremental sync via lastModified timestamps.

## What Gets Indexed

| Content | Details |
|---------|---------|
| **Cards** | Title, HTML content, collection, tags, verification state, owner |
| **Collections** | Name, description, color, type |
| **Folders** | Title, collection, card count, subfolder count |

## Authentication

**Method:** Basic Auth (email:token)

**Header:** `Authorization: Basic {base64(email:api_token)}`

Generate a user API token from your Guru account settings.

## Quick Start

1. Generate a user API token in Guru account settings
2. Add the Guru connector in OpenBeam
3. Enter your email and API token
4. Configure sync settings (verified only, collection filters)
5. Start the initial sync
