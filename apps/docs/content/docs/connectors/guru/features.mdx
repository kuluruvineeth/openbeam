# Guru Features

## Indexed Content

### Cards

Knowledge cards are the primary content type in Guru. Each card includes:

- **Title** (preferredPhrase)
- **HTML content** (automatically stripped for search indexing)
- **Collection** assignment
- **Tags** with categories
- **Verification state** (TRUSTED, NEEDS_VERIFICATION, etc.)
- **Owner** and last modifier
- **Boards** the card appears on
- **Created and last modified** timestamps

### Collections

Collections organize cards into logical groups:

- **Name** and description
- **Color** coding
- **Collection type**

### Folders

Folders provide hierarchical organization within collections:

- **Title**
- **Parent collection**
- **Card and subfolder counts**

## Actions

| Action | Description |
|--------|-------------|
| **Create Card** | Create a new knowledge card in a specified collection |
| **Update Card** | Update title or content of an existing card |

## Search Capabilities

- Full-text search across card titles and content
- Filter by collection, verification state, or tags
- Sort by relevance or last modified date
