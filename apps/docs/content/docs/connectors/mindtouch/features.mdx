# Features

## Pages

Knowledge base articles and documentation pages are indexed with:

- **Title** and full text content extracted from HTML
- **Path** in the page hierarchy (e.g., `Guides/Getting_Started`)
- **Tags** associated with the page
- **Author** information (name, email, username)
- **Parent page** reference for hierarchy navigation
- **Revision number** for change tracking

## Categories

Taxonomy categories organizing knowledge base content:

- **Title** of the category
- **Parent category** for hierarchical browsing
- **Page count** showing associated articles
- **Path** for category hierarchy

## Tags

Content tags used across knowledge base pages:

- **Tag name** and value
- **Tag type** (text, date, etc.)
- **Associated page count** for relevance

## Search Capabilities

- Full-text search across all page content
- Filter by document type (page, category, tag)
- Filter by tags to find related articles
- Navigate page hierarchies through parent references
- Find content by author
