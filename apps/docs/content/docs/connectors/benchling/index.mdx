# Benchling

Index life sciences R&D data from Benchling including notebook entries, DNA/protein sequences, projects, folders, and assay results. Supports API key authentication with Basic auth encoding and cursor-based pagination.

## What Gets Indexed

| Content | Details |
|---------|---------|
| **Notebook Entries** | Name, content fields, authors, schema, folder, review status |
| **Folders** | Name, parent folder, project association |
| **Projects** | Name, owner, archive status |
| **DNA Sequences** | Name, length, bases, circular flag, annotations, schema, registry ID |
| **Protein Sequences** | Name, length, amino acids, annotations, schema, registry ID |
| **Assay Results** | Schema, field values, associated entry and project |

## Authentication

**Method:** API Key (Basic auth)

Generate an API key from **Settings > API keys** in your Benchling tenant. The key is used as the username in HTTP Basic authentication with an empty password.

## Quick Start

1. Generate an API key in Benchling
2. Add the Benchling connector in OpenBeam
3. Enter your API key and tenant name
4. Start the initial sync
