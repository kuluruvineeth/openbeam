# Benchling Features

## Notebook Entries

Lab notebook entries are the primary content type indexed from Benchling. Each entry includes:

- **Name and display ID** for quick identification
- **Schema fields** with structured data values
- **Authors** associated with the entry
- **Review status** (in review, accepted, etc.)
- **Folder** location in the project hierarchy

## DNA Sequences

DNA sequence records include:

- **Name and registry ID** for identification
- **Sequence length** in base pairs
- **Circular/linear** topology flag
- **Annotations** with names, types, and positions
- **Schema metadata** if registered

## Protein Sequences

Amino acid sequence records include:

- **Name and registry ID** for identification
- **Sequence length** in amino acids
- **Annotations** with names, types, and positions
- **Schema metadata** if registered

## Projects and Folders

The organizational hierarchy is fully indexed:

- **Projects** with owner information
- **Folders** with parent-child relationships
- **Archive status** for both projects and folders

## Assay Results

Experimental results with structured data:

- **Schema name** identifying the result type
- **Field values** with display-friendly formatting
- **Associated entry** and project links
