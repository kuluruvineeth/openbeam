# SmartThings Features

## Content Types

| Type | Fields Indexed |
|------|----------------|
| Devices | Name, type, capabilities, health status, location, room |
| Locations | Name, timezone, country, temperature scale |
| Scenes | Scene name, location, last executed timestamp |

## Metadata

| Field | Searchable | Filterable |
|-------|------------|------------|
| Device name | Yes | Yes |
| Device type | Yes | Yes |
| Capability | Yes | Yes |
| Location | Yes | Yes |
| Room | Yes | Yes |
| Health status | No | Yes |

## Sync Modes

| Mode | Trigger | Latency |
|------|---------|---------|
| Full | First sync, manual | Minutes |
| Incremental | Scheduled | 15 min |

## AI Capabilities

- Semantic search across all indexed devices, locations, and scenes
- Question answering about smart home device capabilities and room assignments
- Device fleet health analysis from health status patterns across locations
- Connectivity pattern analysis to identify offline devices and degraded rooms
- Scene utilization insights from execution timestamps and device participation

## Limitations

| Limit | Value |
|-------|-------|
| API rate limit | 50 req/min |
| Token expiration | Tokens do not expire (PAT) |
| Multi-location | Supported (syncs all accessible locations) |
