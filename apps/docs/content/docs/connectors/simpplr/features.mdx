# Simpplr Features

## Indexed Content

### Sites
Content hubs and community spaces with metadata including name, description, type, member count, and owner information.

### Pages
Wiki pages and content articles with full-text indexing. HTML content is stripped to plain text for search. Includes author, site association, and status tracking.

### News
Company news articles and announcements with category classification, tags, and publication dates.

### Files
Uploaded documents and files with metadata including file name, type, size, and description.

### People
Employee directory profiles with name, email, job title, department, location, phone, bio, and manager relationships.

## Search Capabilities

- Full-text search across all indexed content
- Filter by document type (site, page, news, file, person)
- Author-based filtering
- Department and location filtering for people
- Category and tag filtering for news articles
