# Canva

Index design content from Canva including designs, brand templates, folders, and comments. Supports OAuth 2.0 with PKCE and incremental sync via updated_at filtering.

## What Gets Indexed

| Content | Details |
|---------|---------|
| **Designs** | Title, type, owner, page count, thumbnail, edit URL |
| **Brand Templates** | Title, description, thumbnail |
| **Folders** | Name, creation and modification timestamps |
| **Comments** | Message text, author, associated design |

## Authentication

**Method:** OAuth 2.0 with PKCE (Authorization Code Grant)

Create an integration in the [Canva Developer Portal](https://www.canva.dev/) to obtain client credentials. The integration requires scopes for reading designs, folders, brand templates, and comments.

## Quick Start

1. Create an integration in the Canva Developer Portal
2. Add the Canva connector in OpenBeam
3. Enter your Client ID and Client Secret
4. Complete the OAuth authorization flow
5. Start the initial sync
