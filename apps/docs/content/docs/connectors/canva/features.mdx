# Features

## Indexed Entities

### Designs
Full-text search across design titles and metadata. Includes design type (Presentation, SocialMedia, Doc, etc.), page count, owner, and direct edit URLs.

### Brand Templates
Search across brand template titles and descriptions. Useful for finding approved brand assets and design starting points.

### Folders
Folder names and organization structure. Enables discovery of design collections and project folders.

### Comments
Design comment messages with author attribution. Search conversations attached to specific designs.

## Actions

The connector supports write operations for agent workflows:

| Action | Description |
|--------|-------------|
| **Create Design** | Create a new design with specified type, title, and dimensions |
| **Create Folder** | Create a new folder with optional parent folder |

## Knowledge Graph

The connector feeds the knowledge graph with:
- **Owner attribution** from design ownership metadata
- **Team relationships** from team-scoped designs and templates
- **Folder hierarchy** from folder organization structure
