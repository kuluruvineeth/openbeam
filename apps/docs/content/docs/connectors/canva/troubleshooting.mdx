# Troubleshooting

## Authentication Errors

**Invalid credentials:** Verify your Client ID and Client Secret match the values in your Canva Developer Portal integration settings.

**403 Forbidden:** The OAuth scopes may be insufficient. Re-authorize the connector to request all required scopes.

**Token refresh failed:** If token refresh fails repeatedly, disconnect and reconnect the Canva integration to obtain fresh credentials.

## Rate Limiting

**429 Too Many Requests:** The connector automatically backs off when rate limited. If syncs are consistently slow, consider disabling comment syncing or reducing the number of enabled entity types.

## Missing Data

**Designs not appearing:** Only designs accessible to the authenticated user are synced. Team designs require the user to have team membership.

**Brand templates missing:** Brand templates require a Canva Pro or Enterprise account. Free accounts do not have access to brand templates.

**Comments not synced:** Comment syncing is disabled by default. Enable it in the connector settings.

## Sync Failures

**Incremental sync falling back to full:** This happens when the cursor state is stale or the API returns errors. The connector automatically recovers by running a full sync.

**Connection timeout:** The Canva API may be temporarily unavailable. The connector retries with exponential backoff up to 3 times.

**Empty sync results:** Verify that the authenticated user has designs in their account. New Canva accounts start with no designs.
