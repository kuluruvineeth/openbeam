# Haystack

Index employee directory data from Haystack including people profiles, teams, departments, and office locations. Supports API key authentication with offset-based pagination and updated_after incremental sync.

## What Gets Indexed

| Content | Details |
|---------|---------|
| **People** | Name, email, title, department, team, manager, location, phone, bio, start date |
| **Teams** | Name, description, lead, member count, member list |
| **Departments** | Name, description, head, headcount, parent department hierarchy |
| **Locations** | Name, address, city, country, timezone, capacity |

## Authentication

**Method:** API Key (Bearer token)

Generate an API key from **Settings > Integrations > API** in your Haystack workspace. The key must have read access to people, teams, departments, and locations.

## Quick Start

1. Generate an API key in Haystack
2. Add the Haystack connector in OpenBeam
3. Enter your API key
4. Start the initial sync
