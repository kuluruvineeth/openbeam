# Troubleshooting

## Authentication Errors

**Invalid API key:** Verify your API key is correct and has not been revoked. Re-generate from Haystack Settings > Integrations > API if needed.

**403 Forbidden:** The API key lacks sufficient permissions. Ensure it has at least Read access to people, teams, departments, and locations.

## Rate Limiting

**429 Too Many Requests:** The connector automatically backs off when rate limited. If syncs are consistently slow, consider reducing the number of enabled entity types or increasing the sync interval.

## Missing Data

**People not appearing:** Verify the API key has access to the full directory. Some Haystack workspaces restrict API access by role.

**Teams/Departments/Locations missing:** Verify these entity types are enabled in the connector settings.

## Sync Failures

**Incremental sync falling back to full:** This happens when the cursor state is stale or the API returns errors. The connector automatically recovers by running a full sync.

**Connection timeout:** Haystack API may be temporarily unavailable. The connector retries with exponential backoff up to 3 times.

**Empty sync results:** If your Haystack workspace has no records, the sync completes with zero documents.
