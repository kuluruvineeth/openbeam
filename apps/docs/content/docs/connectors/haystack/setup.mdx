# Haystack Setup

## Prerequisites

- A Haystack workspace with admin access
- Access to Haystack API key management

## Step 1: Generate an API Key

1. Log into your [Haystack](https://www.haystackteam.com) workspace
2. Go to **Settings > Integrations > API**
3. Click **Create API Key**
4. Name it something like "OpenBeam Integration"
5. Grant **Read** access to people, teams, departments, and locations
6. Copy the generated API key

## Step 2: Add Connector in OpenBeam

1. Navigate to **Settings > Connectors**
2. Click **Add Connector** and select **Haystack**
3. Enter your **API Key**
4. Click **Connect** to validate and activate

## Step 3: Initial Sync

After activation, OpenBeam runs a full sync of your Haystack directory. The first sync fetches all people, teams, departments, and locations.
