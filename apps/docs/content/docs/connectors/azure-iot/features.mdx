# Azure IoT Hub Features

## Content Types

| Type | Fields Indexed |
|------|----------------|
| Devices | Device ID, connection state, status, authentication type, last activity |
| Device Twins | Tags, reported properties, desired properties, version |

## Metadata

| Field | Searchable | Filterable |
|-------|------------|------------|
| Device ID | Yes | Yes |
| Connection state | No | Yes |
| Status | No | Yes |
| Twin tags | Yes | Yes |
| Reported properties | Yes | No |
| Last activity | No | Yes |

## Sync Modes

| Mode | Trigger | Latency |
|------|---------|---------|
| Full | First sync, manual | Minutes |
| Incremental | Scheduled | 15 min |

## AI Capabilities

- Semantic search across all indexed devices and device twins
- Question answering about device fleet status and twin property configurations
- Device fleet health analysis from connection state patterns and activity timestamps
- Twin drift detection between reported and desired properties across the device registry
- Connectivity pattern analysis to surface devices with frequent disconnects or stale activity

## Limitations

| Limit | Value |
|-------|-------|
| Rate limit | 15 req/min (most conservative IoT connector) |
| Query page size | 100 devices per page |
| Twin properties | Limited to 32 KB per twin |
