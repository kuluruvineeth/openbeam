# Azure IoT Hub

Index IoT devices with device twin state, tags, and connection status from Azure IoT Hub. The connector uses a shared access connection string and queries devices using the IoT Hub SQL-like query API.

Azure IoT Hub integration makes your entire device fleet searchable -- twin tags, reported properties, desired properties, and connection state.

## Authentication

**Method:** Shared Access Connection String

Retrieve the connection string from the Azure Portal under **IoT Hub** > **Shared access policies**. Use the `registryRead` or `iothubowner` policy.

Connection string format:
```
HostName=myhub.azure-devices.net;SharedAccessKeyName=...;SharedAccessKey=...
```

[Azure IoT Hub authentication docs](https://learn.microsoft.com/en-us/azure/iot-hub/authenticate-authorize-sas)

## Data Streams

| Stream | Description | Sync Mode | Interval |
|--------|-------------|-----------|----------|
| **Devices** | Device ID, connection state, status, twin tags, reported properties, desired properties, last activity | Periodic | 30 min |

Supports full backfill.

## Setup

1. In the **Azure Portal**, navigate to your IoT Hub
2. Go to **Shared access policies** and select a policy with registry read permissions
3. Copy the **Connection string (primary key)**
4. In OpenPlane, add the Azure IoT Hub connector
5. Paste the connection string and start the initial sync

## Configuration

| Setting | Default | Description |
|---------|---------|-------------|
| IoT Hub Connection String | -- | From Azure Portal shared access policies (required) |

## Sync Details

**Full sync** uses the IoT Hub Query API to enumerate all registered devices and fetch their twin state, including tags, reported properties, and desired properties.

**Incremental sync** filters by `lastActivityTime` to fetch only devices with recent activity since the last sync.

The SQL-like query language enables efficient filtering during sync:
```sql
SELECT * FROM devices WHERE lastActivityTime > '2024-01-01T00:00:00Z'
```
