# Configuration

## Settings

| Setting | Description | Default |
|---------|-------------|---------|
| **API Key** | Datadog API key for authentication | Required |
| **Application Key** | Datadog Application key for authentication | Required |
| **Site** | Datadog site region (us1, us3, us5, eu, ap1, gov) | us1 |
| **Sync Dashboards** | Index dashboard titles, descriptions, and widgets | Enabled |
| **Sync Incidents** | Index incidents with severity and status | Enabled |
| **Sync Service Catalog** | Index service catalog entries | Enabled |
| **Sync Notebooks** | Index notebooks and cell content | Enabled |
| **Sync SLOs** | Index Service Level Objectives | Enabled |
| **Lookback Days** | How far back to sync incidents | 90 days |

## Site Selection

Datadog operates across six regional sites with separate API endpoints:

| Site | API Base URL |
|------|-------------|
| US1 | `https://api.datadoghq.com` |
| US3 | `https://api.us3.datadoghq.com` |
| US5 | `https://api.us5.datadoghq.com` |
| EU | `https://api.datadoghq.eu` |
| AP1 | `https://api.ap1.datadoghq.com` |
| GOV | `https://api.ddog-gov.com` |

Select the site that matches your Datadog instance. The site is determined by your organization's Datadog URL.

## Entity Toggles

Use the entity toggles to control which data types are indexed. Monitors are always synced. Dashboards, incidents, service catalog, notebooks, and SLOs can be individually disabled to reduce sync time and API usage.

## Lookback Period

The lookback setting controls how far back the initial full sync fetches incidents. Set to 0 to use the default of 90 days.
