# Datadog

Index monitoring and observability data from Datadog including monitors, dashboards, incidents, service catalog entries, notebooks, and SLOs. Supports dual API key authentication (API Key + Application Key) with multi-site support across US1, US3, US5, EU, AP1, and GOV regions.

## What Gets Indexed

| Content | Details |
|---------|---------|
| **Monitors** | Name, query, status, type, priority, tags, creator, thresholds |
| **Dashboards** | Title, description, layout type, widget titles, author |
| **Incidents** | Title, severity, state, commander, customer impact, detection method |
| **Service Catalog** | Service name, description, team ownership, tier, lifecycle, contacts, links |
| **Notebooks** | Name, markdown cells, author, status |
| **SLOs** | Name, description, type, target thresholds, tags, overall status |

## Authentication

**Method:** Dual API Key (API Key + Application Key)

Both keys are required. Generate them from **Organization Settings** in Datadog.

## Quick Start

1. Generate an API Key and Application Key in Datadog
2. Add the Datadog connector in OpenBeam
3. Enter both keys and select your site region
4. Start the initial sync
