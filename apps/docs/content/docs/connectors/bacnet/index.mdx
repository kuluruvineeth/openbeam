# BACnet

Discover BACnet/IP devices on your network and index HVAC readings, schedules, and alarms from building automation systems. The connector supports Who-Is device discovery, object polling, Change of Value (COV) subscriptions, and trend log extraction.

BACnet is the standard protocol for building management systems. This connector makes temperature setpoints, occupancy schedules, and equipment alarms searchable.

## Authentication

**Method:** Network Access

BACnet/IP uses network-level access. No API keys or OAuth -- the connector communicates directly on the BACnet/IP UDP port (default 47808). The OpenBeam host must have network connectivity to the BACnet/IP segment.

## Data Streams

| Stream | Description | Sync Mode | Interval |
|--------|-------------|-----------|----------|
| **BACnet Objects** | Polled values from analog, binary, and multistate inputs/outputs (object type, value, units, status flags) | Real-time | 30s polling |
| **Schedules** | HVAC and lighting schedule definitions (name, effective period, weekly schedule) | Periodic | 60 min |

Backfill is not available for real-time object values. Trend log data extraction provides historical context.

## Setup

1. Ensure the OpenBeam host has **network access** to the BACnet/IP segment
2. In OpenBeam, add the BACnet connector
3. Configure the BACnet port (default 47808) and optionally specify a network interface
4. Optionally list specific device IDs, or leave empty to discover all devices via Who-Is broadcast
5. Start the initial sync

## Configuration

| Setting | Default | Description |
|---------|---------|-------------|
| Network Interface | -- | Network interface for BACnet/IP (e.g., `eth0`) |
| BACnet Port | 47808 | BACnet/IP UDP port (required) |
| Device IDs | -- | Comma-separated device IDs, or empty to discover all |
| Poll Interval | 30s | How often to poll device object values |

## Sync Details

**Device discovery** uses the BACnet Who-Is broadcast to find all devices on the network. Each device's object list is enumerated to identify available data points.

**Object polling** reads present values from analog inputs (temperatures, pressures), analog outputs (setpoints), binary inputs (occupancy, switches), and multistate objects (mode selectors). Values are indexed with their engineering units and status flags.

**COV subscriptions** register for Change of Value notifications on monitored objects. The BACnet device pushes updates when values change beyond a configurable deadband, providing near-real-time data without continuous polling.

**Schedule objects** contain weekly schedules and exception schedules for HVAC and lighting systems. These are indexed as structured documents with day/time programming.

**Trend logs** contain historical recordings of object values. The connector extracts trend log data to backfill historical readings.
