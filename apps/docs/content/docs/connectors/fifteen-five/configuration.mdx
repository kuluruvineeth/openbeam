# 15Five Configuration

## Settings

### Sync Reviews
Toggle whether performance reviews are included in search results. Enabled by default.

### Sync High Fives
Toggle whether peer recognition (High Fives) are included in search results. Enabled by default.

### Lookback Days
Number of days of history to sync on the first run. Set to `0` for all available history. Useful for limiting initial sync scope in organizations with years of 15Five data.

## Entity Selection

| Entity | Default | Notes |
|--------|---------|-------|
| Check-ins | Always synced | Core 15Five content |
| Objectives | Always synced | OKR objectives |
| Key Results | Always synced | Linked to objectives |
| High Fives | Configurable | Peer recognition |
| Reviews | Configurable | Performance reviews |
