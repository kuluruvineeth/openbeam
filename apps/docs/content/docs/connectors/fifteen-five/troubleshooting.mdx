# 15Five Troubleshooting

## Authentication Errors

### Invalid API Key
- Verify the API key is correctly copied from 15Five admin settings
- Ensure the key has not been revoked or expired
- Check that Public API access is enabled in your 15Five plan

### 403 Forbidden
- The API key user may lack sufficient permissions
- Ensure the key was generated by an admin with full read access
- Contact 15Five support to verify API access is enabled for your plan

## Sync Issues

### Missing Check-ins
- Check-ins in draft status (not submitted) are still indexed but marked as drafts
- Verify the user who generated the API key has access to view all check-ins

### Empty Objectives/Key Results
- Objectives may be filtered by visibility settings in 15Five
- Ensure the API key user has access to company-wide OKRs

### Rate Limiting
- The connector respects 15Five rate limits (typically 100 requests/minute)
- If rate limited, the connector will automatically retry with exponential backoff
- For large organizations, initial sync may take longer due to rate limiting

## Data Freshness

### Stale Data
- Incremental sync runs at configured intervals (default: 15-60 minutes)
- Trigger a manual sync from the connector settings if needed
- If incremental sync fails repeatedly, a full re-sync may resolve the issue

## Support

If issues persist, check the OpenBeam server logs for detailed error messages with the `fifteen-five` connector ID prefix.
