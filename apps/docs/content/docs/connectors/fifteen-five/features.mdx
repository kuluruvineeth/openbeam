# 15Five Features

## Indexed Content Types

### Check-ins
Weekly check-in reports including pulse scores, manager questions, and employee answers. Each check-in is indexed with the author, report date, and all Q&A pairs.

### Objectives
OKR objectives with name, description, status, owner, progress percentage, start and end dates. Supports filtering by active/closed status.

### Key Results
Key results linked to parent objectives with target and current values, progress calculation, status, and owner information.

### High Fives
Peer recognition messages with sender, receiver, and message text. Enables searching for recognition given to or received by specific people.

### Reviews
Performance reviews with reviewer, reviewee, cycle name, status, and submission date. Supports tracking across review cycles.

## Search Capabilities

- Full-text search across all check-in questions and answers
- Filter by content type (check-ins, objectives, key results, high fives, reviews)
- Search recognition messages by sender or receiver name
- Find objectives by status, owner, or progress
- Track review cycles and submission status
