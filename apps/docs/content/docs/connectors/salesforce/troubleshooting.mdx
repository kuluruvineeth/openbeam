# Troubleshooting

## OAuth Errors

| Error | Fix |
|-------|-----|
| `invalid_client_id` | Consumer Key does not match — verify in Connected App settings |
| `invalid_client` | Consumer Secret is wrong — regenerate in Manage Consumer Details |
| `redirect_uri_mismatch` | Callback URL must match exactly in Connected App configuration |
| `invalid_grant` | Refresh token expired or revoked — reconnect OAuth flow |
| `inactive_org` | Salesforce org is locked or inactive |

## Access Issues

| Issue | Fix |
|-------|-----|
| No records syncing | Verify `api` scope is enabled in Connected App |
| Records missing | Check sharing rules and record-level security for the connecting user |
| Knowledge articles empty | Enable `sync_knowledge` in settings and verify Knowledge is enabled in the org |
| Cases not appearing | Enable `sync_cases` in settings |

## Sync Issues

| Issue | Fix |
|-------|-----|
| API limit exceeded | Monitor daily usage in Setup > System Overview; reduce sync frequency |
| SOQL query timeout | Large object tables may timeout — OpenBeam retries with smaller date ranges |
| Deleted records still in results | `getDeleted()` API is called every incremental sync — verify sync is running |
| Sandbox records stale | Sandbox data may be outdated — refresh sandbox from production |

## Connection Issues

| Issue | Fix |
|-------|-----|
| Cannot connect | Verify Consumer Key, Secret, and Login URL |
| Wrong environment | Use `login.salesforce.com` for production, `test.salesforce.com` for sandbox |
| IP restrictions | Set IP Relaxation to "Relax IP restrictions" in Connected App policies |
| Connected App not active | New apps take 2-10 minutes to activate after creation |
| API errors | Check [Salesforce Trust](https://status.salesforce.com/) |

<Callout type="info">
Newly created Connected Apps may take 2-10 minutes to propagate. If you get `invalid_client_id` immediately after creation, wait and retry.
</Callout>

## Error Reference

| Error | Code | Fix |
|-------|------|-----|
| `INVALID_SESSION_ID` | 401 | Reconnect OAuth — session expired |
| `INSUFFICIENT_ACCESS` | 403 | Check user profile permissions and sharing rules |
| `NOT_FOUND` | 404 | Record deleted |
| `REQUEST_LIMIT_EXCEEDED` | 429 | Daily API limit reached — wait until reset |
| `SERVER_UNAVAILABLE` | 503 | Salesforce maintenance — retry later |

## Common Patterns

### Issue: "No records appearing in search"

1. Check connector status is Active
2. Verify `api` scope is granted in Connected App
3. Check which object types are enabled in configuration
4. Verify the connecting user has read access to the object types
5. Try manual Full Resync

### Issue: "Slow initial sync"

Large Salesforce orgs take time. Progress shown in connector status.
- 10,000 records: ~5 minutes
- 100,000 records: ~30 minutes
- 1,000,000+ records: Several hours

### Issue: "API limit warnings"

1. Check current usage in Setup > System Overview
2. Reduce `incrementalInterval` to sync less frequently
3. Disable object types you do not need
4. Consider upgrading your Salesforce edition for higher API limits

Still stuck? [Open an issue](https://github.com/kuluruvineeth/openbeam/issues) with error messages and logs.
