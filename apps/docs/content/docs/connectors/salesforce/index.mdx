# Salesforce

Index CRM data from Salesforce including accounts, contacts, opportunities, cases, and knowledge articles. Supports OAuth 2.0 Web Server Flow, SOQL-based incremental sync, and deleted record detection via the getDeleted() API.

## What Gets Indexed

| Content | Details |
|---------|---------|
| **Accounts** | Name, industry, type, description, website |
| **Contacts** | Name, email, phone, title, account association |
| **Opportunities** | Name, stage, amount, close date, owner |
| **Cases** | Subject, description, status, priority, contact |
| **Knowledge Articles** | Title, body, article type, publish status |

## Authentication

**Method:** OAuth 2.0 (Web Server Flow)

**Scopes:** `api`, `refresh_token`, `offline_access`

Create a Connected App in [Salesforce Setup](https://login.salesforce.com) and configure the OAuth settings.

## Quick Start

1. Create a Connected App in Salesforce Setup
2. Enable OAuth and configure the callback URL
3. Add the Salesforce connector in OpenBeam with your Consumer Key and Secret
4. Authorize and start the initial sync
