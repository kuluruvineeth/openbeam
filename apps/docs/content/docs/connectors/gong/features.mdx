# Features

## Call Indexing

Every call in Gong is indexed with full metadata:

- **Title** -- Call subject or auto-generated title
- **Date and duration** -- When the call happened and how long it lasted
- **Direction** -- Inbound or outbound
- **Participants** -- Internal and external parties with names, emails, and titles
- **Purpose and disposition** -- Why the call happened and the outcome

## Transcript Search

When transcript sync is enabled, the full text of each call transcript is indexed:

- Speaker-attributed segments
- Timestamp markers for each segment
- Full-text search across all conversation content
- Find specific topics, objections, or talking points

## Participant Search

Search for calls by participant:

- Find all calls with a specific customer or prospect
- Filter by internal vs external participants
- Search by participant name, email, or title

## Call Direction Filtering

Optionally filter sync to only include:

- **Inbound** calls
- **Outbound** calls
- Or leave empty for all calls
