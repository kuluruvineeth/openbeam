# Aha! Features

## Indexed Content

### Ideas
- Name and full description (HTML stripped)
- Workflow status with color coding
- Categories and tags
- Vote count and endorsements
- Assignee and creator information

### Features
- Name and description
- Workflow status and assignee
- Due date and start date
- Linked release, epic, and initiative
- Score and tags

### Releases
- Name and theme description
- Release date and released status
- Workflow status and progress percentage
- Owner information

### Initiatives
- Name and description
- Status and progress tracking
- Effort and value scores

### Epics
- Name and description
- Workflow status and progress
- Reference number

## Search Capabilities

- Full-text search across all entity types
- Filter by document type (idea, feature, release, initiative, epic)
- Filter by status, assignee, or product
- Sort by relevance, creation date, or update date

## Actions

The Aha! connector supports write operations:

- **Create Idea** — Submit new product ideas
- **Update Idea** — Modify existing idea properties
- **Create Feature** — Add new features to a product
