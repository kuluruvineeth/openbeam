# InSided

Index customer community data from InSided (Gainsight Customer Communities) including forum posts, knowledge base articles, and product ideation boards. Supports API key authentication with page-based pagination and updated_after incremental sync.

## What Gets Indexed

| Content | Details |
|---------|---------|
| **Posts** | Title, content, author, category, replies, reactions, view count |
| **Articles** | Title, content, author, category, status, helpful votes |
| **Ideas** | Title, content, author, category, status, vote count, comments |

## Authentication

**Method:** API Key (Bearer token)

Generate an API key from your InSided community admin panel under **Settings > API**. The key must have read access to posts, articles, and ideas.

## Quick Start

1. Generate an API key in your InSided admin panel
2. Add the InSided connector in OpenBeam
3. Enter your API key and community URL
4. Start the initial sync
