# Greenhouse Features

## Indexed Entities

### Jobs

| Field | Indexed |
|-------|---------|
| Job title | Yes |
| Status (open/closed/draft) | Yes |
| Departments | Yes |
| Offices | Yes |
| Hiring managers | Yes |
| Recruiters | Yes |
| Open positions count | Yes |
| Notes | Yes |

### Candidates

| Field | Indexed |
|-------|---------|
| Name | Yes |
| Email addresses | Yes |
| Phone numbers | Yes |
| Current title | Yes |
| Company | Yes |
| Tags | Yes |
| Active application count | Yes |

### Applications

| Field | Indexed |
|-------|---------|
| Status | Yes |
| Current stage | Yes |
| Source | Yes |
| Job association | Yes |
| Rejection reason | Yes |
| Applied date | Yes |

### Offers

| Field | Indexed |
|-------|---------|
| Status | Yes |
| Start date | Yes |
| Sent date | Yes |
| Resolved date | Yes |

## Actions

| Action | Description |
|--------|-------------|
| Add Candidate Note | Add a note to a candidate's activity feed |
