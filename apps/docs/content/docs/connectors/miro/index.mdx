# Miro

Index collaborative whiteboard content from Miro including boards, sticky notes, shapes, text, cards, and frames. Supports OAuth 2.0 with timestamp-based incremental sync via board modifiedAt filtering.

## What Gets Indexed

| Content | Details |
|---------|---------|
| **Boards** | Name, description, owner, creation and modification timestamps |
| **Sticky Notes** | Text content, position, board association |
| **Shapes** | Content, type, board association |
| **Text** | Text content, board association |
| **Cards** | Title, description, board association |
| **Frames** | Title, child items, board association |

## Authentication

**Method:** OAuth 2.0

**Scopes:** `boards:read`, `boards:write`

Create an app in the [Miro Developer Portal](https://developers.miro.com/page/app-settings) and configure the OAuth settings.

## Quick Start

1. Create an app in the Miro Developer Portal
2. Configure the OAuth redirect URL
3. Add the Miro connector in OpenBeam with your Client ID and Secret
4. Authorize and start the initial sync
