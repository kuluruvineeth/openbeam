# Troubleshooting

## Authentication Errors

**Invalid client credentials:** Verify your Client ID and Client Secret match those in your Panopto Identity Provider configuration. Re-copy them if needed.

**401 Unauthorized:** The access token may have expired. OpenBeam automatically refreshes tokens, but if the refresh token is also expired, you may need to re-authorize the connector.

**Wrong instance URL:** Ensure the instance URL exactly matches your Panopto deployment. Do not include trailing slashes or path segments like `/Panopto`.

## Rate Limiting

**429 Too Many Requests:** The connector automatically backs off when rate limited. If syncs are consistently slow, consider increasing the sync interval.

## Missing Data

**Videos not appearing:** Sessions must be in a "Complete" state to appear in API results. In-progress uploads or processing videos may not be returned.

**Playlists missing:** Verify playlist sync is enabled in the connector settings.

**Folders empty:** The connector syncs all accessible folders. If folders are missing, check that the OAuth user has view permissions on those folders.

## Sync Failures

**Incremental sync falling back to full:** This happens when the cursor state is stale or the API returns errors. The connector automatically recovers by running a full sync.

**Connection timeout:** Your Panopto instance may be temporarily unavailable. The connector retries with exponential backoff up to 3 times.

**SSL certificate errors:** Self-hosted Panopto instances must have valid SSL certificates. Ensure your certificate chain is complete.
