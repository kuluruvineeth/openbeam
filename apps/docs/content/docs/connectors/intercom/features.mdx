# Features

## Indexed Content

### Conversations

Support conversations including the initial message and all reply parts. Each conversation includes:

- Title or first message excerpt
- Full message thread content
- State (open, closed, snoozed)
- Priority level
- Assignee name
- Tags
- Message count

### Help Center Articles

Knowledge base articles from Intercom Articles:

- Title and body content
- Description
- Publication state (draft, published)
- Author information
- Article URL

### Collections

Article categories that organize help center content:

- Collection name
- Description
- URL

### Contacts (Opt-in)

Users and leads from your Intercom workspace:

- Name and email
- Role (user, lead)
- Company associations
- Location information

Contact sync is disabled by default due to potential data volume.

## Actions

| Action | Description |
|--------|-------------|
| **Reply to Conversation** | Send a reply as an admin |
| **Tag Conversation** | Apply a tag to a conversation |
| **Create Article** | Create a new Help Center article |
