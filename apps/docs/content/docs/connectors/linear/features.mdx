# Linear Features

## Search

- **Full-text**: Issue titles, descriptions, comments
- **Projects**: Project names and documentation
- **Documents**: Wiki pages and specifications
- **Metadata**: Labels, states, priorities, cycles

## Content Types

| Type | Fields Indexed |
|------|----------------|
| Issues | Title, description, identifier (e.g., ENG-123) |
| Comments | Full comment text with author |
| Projects | Name, description, status |
| Documents | Title, content, project association |
| Cycles | Name, dates, team |

## Issue Metadata

| Field | Searchable | Filterable |
|-------|------------|------------|
| State | Yes | Yes |
| Priority | Yes | Yes |
| Labels | Yes | Yes |
| Assignee | Yes | Yes |
| Team | Yes | Yes |
| Cycle | Yes | Yes |
| Project | Yes | Yes |

## Sync Options

| Mode | Trigger | Latency |
|------|---------|---------|
| Full | First sync, manual | Minutes |
| Incremental | Scheduled | 15 min |
| Real-time | Webhooks | Seconds |

## AI Capabilities

- Semantic search across issues, projects, documents, and cycle content with metadata filtering
- Question answering about project status, blockers, and historical decisions from issue threads
- Related issue discovery — find duplicate or similar issues across teams and projects by semantic similarity
- Sprint and cycle summarization with completed vs. planned work and velocity analysis
- Dependency chain analysis — trace blocking relationships and identify critical path items across projects

## Limitations

| Limit | Value |
|-------|-------|
| API complexity budget | ~1,800 points/hour |
| Archived content | Excluded by default |
| Private teams | Based on user access |
| Attachments | URLs indexed, not content |
