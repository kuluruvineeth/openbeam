# Linear

Index issues, projects, documents, and cycles from Linear. Supports OAuth 2.0 authentication, full and incremental sync, and real-time webhook updates.

## What Gets Indexed

| Content | Details |
|---------|---------|
| **Issues** | Title, description, comments, labels, state, assignee |
| **Projects** | Name, description, status, milestones |
| **Documents** | Wiki pages and project documentation |
| **Cycles** | Sprint names, dates, progress |

## Authentication

**Method:** OAuth 2.0

**Scopes:** `read`, `write`

Create an OAuth application at [linear.app/settings/api](https://linear.app/settings/api) and provide the Client ID and Client Secret.

## Quick Start

1. Create a Linear OAuth application at [linear.app/settings/api](https://linear.app/settings/api)
2. Configure the redirect URI and copy your credentials
3. Add the Linear connector in OpenBeam with Client ID and Secret
4. Authorize and start the initial sync
