# Linear Connector

The Linear connector is coming soon.

## Planned Features

- Full-text search across issues and projects
- Comment and activity indexing
- Project and team filtering
- Label and status metadata
- Real-time sync via Linear webhooks

## Content Types

| Type | Support |
|------|---------|
| Issues | Title, description, comments |
| Projects | Project documentation |
| Comments | Full thread indexing |
| Documents | Project docs and specs |

## Authentication

Will use Linear OAuth 2.0 with read access to:
- Issues and projects
- Teams and users
- Comments and activities

## Stay Updated

Watch the [GitHub repository](https://github.com/kuluruvineeth/openplane) for updates on Linear connector availability.
