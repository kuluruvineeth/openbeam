## What's Indexed

- **Issues** - Title, description, comments, labels, state
- **Projects** - Name, description, status, milestones
- **Documents** - Wiki pages and project documentation
- **Cycles** - Sprint names, dates, progress

## Quick Start

1. Create Linear OAuth application at linear.app/settings/api
2. Configure redirect URI and get credentials
3. Add connector in OpenPlane with Client ID/Secret
4. Authorize and start sync
