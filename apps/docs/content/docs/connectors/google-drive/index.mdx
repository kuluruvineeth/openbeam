# Google Drive Connector

Index and search across your Google Drive files, including documents, spreadsheets, presentations, and media files.

## Features

- Full-text search across all file types
- Google Docs, Sheets, Slides content extraction
- PDF and Office document parsing
- Shared Drive support for Google Workspace
- Real-time sync via Drive push notifications
- Video/audio transcription
- OAuth for personal accounts
- Service Account for domain-wide access

## Supported File Types

| Type | Support |
|------|---------|
| Google Docs | Full text extraction |
| Google Sheets | Cell content and metadata |
| Google Slides | Slide text and notes |
| PDF | Full text extraction |
| DOCX/XLSX/PPTX | Full text extraction |
| Images | Metadata indexing |
| Video/Audio | Transcription via TwelveLabs |

## Authentication Methods

### OAuth 2.0 (Personal/Single User)

Best for personal Google accounts or single-user setups.

**Required scopes:**
- `drive.readonly` - Read file content
- `drive.metadata.readonly` - Access file metadata
- `userinfo.email` - User identification

### Service Account (Google Workspace)

Best for organizations with domain-wide access needs.

**Requirements:**
- Google Workspace admin access
- Domain-wide delegation enabled
- Service account key file

## Quick Start

1. Go to **Connectors** → **Add Connector** → **Google Drive**
2. Choose authentication method:
   - **OAuth**: Click "Connect with Google"
   - **Service Account**: Upload key file and enter admin email
3. Configure sync settings
4. Start initial sync

## Configuration Options

| Setting | Description | Default |
|---------|-------------|---------|
| Include Shared Drives | Index team shared drives | `true` |
| Extract Content | Parse document text | `true` |
| Transcribe Media | Process video/audio files | `true` |
| Real-time Updates | Enable push notifications | `true` |
| History (days) | How far back to sync | Unlimited |

## Sync Modes

| Mode | Description | Use Case |
|------|-------------|----------|
| Full Indexing | Store all content locally | Best search quality |
| Federated Search | Query Drive directly | Privacy-sensitive data |
| Hybrid | Index metadata, federate content | Balance of both |
