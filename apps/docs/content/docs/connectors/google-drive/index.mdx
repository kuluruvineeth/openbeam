Index documents, spreadsheets, presentations, and media files with full-text extraction.

## What's Indexed

- **Documents** - Google Docs, PDF, DOCX with full text
- **Spreadsheets** - Google Sheets, XLSX cell content
- **Presentations** - Google Slides, PPTX slide text
- **Media** - Video/audio transcription (optional)

## Quick Start

1. Create Google Cloud project with OAuth credentials
2. Enable Drive API
3. Configure OAuth redirect URI
4. Connect in OpenPlane UI
