# Google Drive Connector

The Google Drive connector is coming soon.

## Planned Features

- Full-text search across documents
- Support for Google Docs, Sheets, Slides
- PDF and Office document indexing
- Shared drive support
- Real-time sync via Drive push notifications

## Supported File Types

| Type | Support |
|------|---------|
| Google Docs | Full text extraction |
| Google Sheets | Cell content and metadata |
| Google Slides | Slide text and notes |
| PDF | Full text extraction with OCR |
| DOCX/XLSX/PPTX | Full text extraction |
| Images | OCR for text extraction |

## Authentication

Will use Google OAuth 2.0 with the following scopes:
- `drive.readonly` - Read file content
- `drive.metadata.readonly` - Access file metadata
