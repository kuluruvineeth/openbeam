# Google Drive

Index documents, spreadsheets, presentations, and media files from Google Drive. Supports OAuth 2.0 authentication, full-text extraction, and optional real-time sync.

## What Gets Indexed

| Content | Details |
|---------|---------|
| **Documents** | Google Docs, PDF, DOCX with full-text extraction |
| **Spreadsheets** | Google Sheets, XLSX with cell content |
| **Presentations** | Google Slides, PPTX with slide text |
| **Media** | Video and audio transcription (optional) |

## Authentication

**Method:** OAuth 2.0

Create OAuth credentials in the Google Cloud Console and enable the Drive API. Configure the OAuth redirect URI to match your OpenBeam instance.

## Quick Start

1. Create a Google Cloud project with OAuth credentials
2. Enable the Drive API
3. Configure the OAuth redirect URI
4. Connect Google Drive in the OpenBeam UI and authorize
