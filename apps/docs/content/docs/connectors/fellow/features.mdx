# Fellow Features

## Meetings

Every meeting synced from Fellow includes:

- **Title** and scheduling information
- **Notes** attached to the meeting (HTML converted to searchable text)
- **Attendees** with names and email addresses
- **Duration** calculated from start/end times
- **Timestamps** for creation and last update

## Action Items

Action items are synced with full context:

- **Title** and optional description
- **Assignee** name and email
- **Due date** when set
- **Completion status** (open or completed)
- **Linked meeting** title and ID
- **Completion timestamp** for done items

## Streams

Streams (note feeds) are indexed with:

- **Name** and description
- **Creation and update timestamps**

## Search Capabilities

- Full-text search across meeting notes content
- Filter by document type (meeting, action_item, stream)
- Filter by assignee on action items
- Filter by completion status
- Sort by meeting date or last update
