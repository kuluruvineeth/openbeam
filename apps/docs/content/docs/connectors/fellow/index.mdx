# Fellow

Index meeting management data from Fellow including meetings with notes, action items, and streams. Supports API key authentication with cursor-based pagination and updated_after incremental sync.

## What Gets Indexed

| Content | Details |
|---------|---------|
| **Meetings** | Title, notes, attendees, start/end time, duration |
| **Action Items** | Title, description, assignee, due date, status, linked meeting |
| **Streams** | Name, description, topic-based note feeds |

## Authentication

**Method:** API Key (Bearer token)

Generate an API key from **Settings > Integrations > API** in Fellow. The key must have read access to meetings, action items, and streams.

## Quick Start

1. Generate an API key in Fellow
2. Add the Fellow connector in OpenBeam
3. Enter your API key
4. Start the initial sync
