# Matterport Features

## Content Types

| Type | Fields Indexed |
|------|----------------|
| Spaces | Name, address, total rooms, floors, area, spatial dimensions |
| Rooms | Name, floor assignment, area, bounding box coordinates |
| Floors | Floor number, area, room count, elevation |
| Mattertags | Label, description, 3D position (x, y, z), attached media |
| Sweeps | Camera position, rotation, floor/room association |

## Spatial Search

Documents include 3D position metadata, enabling proximity-based queries:
- "annotations near the lobby"
- "rooms on the second floor"
- "sensors within 10 meters of the entrance"

## Metadata

| Field | Searchable | Filterable |
|-------|------------|------------|
| Space name | Yes | Yes |
| Room name | Yes | Yes |
| Floor number | No | Yes |
| Mattertag label | Yes | Yes |
| Area (sq ft/m) | No | Yes |
| Position (x,y,z) | No | No |

## AI Capabilities

- Semantic search across all indexed spaces, rooms, floors, and mattertags
- Question answering about spatial layouts and facility organization
- Spatial proximity queries to find annotations and assets near specific locations
- Room comparison analysis across spaces for layout benchmarking and planning
- Facility navigation assistance using floor plans, room assignments, and sweep positions

## Limitations

| Limit | Value |
|-------|-------|
| API rate limit | 50 req/min |
| Auth | Token ID + Secret (Basic) |
| API | GraphQL |
| Room segmentation | Requires Matterport AI processing |
| Point cloud | Optional (increases sync time) |
