# Features

## Indexed Entities

### Contents
Full-text search across article titles, body text, excerpts, and tags. Metadata includes content type (article, news, page), publication status, space assignment, author, and language.

### Communities
Search across community names and descriptions. Includes privacy settings and member counts for understanding community scope and reach.

### Posts
Search across community post content with author attribution. Includes reaction counts, comment counts, and attachment references for engagement context.

### Spaces
Space catalog with names, descriptions, and visibility settings. Useful for understanding organizational structure within LumApps.

## Actions

The connector supports write operations for agent workflows:

| Action | Description |
|--------|-------------|
| **Create Content** | Create a new article, news item, or page |
| **Update Content** | Update title, body, tags, or status of existing content |
| **Create Post** | Create a new post in a community |

## Knowledge Graph

The connector feeds the knowledge graph with:
- **Author attribution** from content and post authorship
- **Space relationships** between contents and their parent spaces
- **Community relationships** between posts and their communities
