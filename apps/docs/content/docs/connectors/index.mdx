## How Connectors Work

Every connector follows the same lifecycle:

| Phase | What happens |
|-------|-------------|
| **Authenticate** | OAuth flow or API key configuration with minimal required scopes |
| **Full Sync** | Complete index of all historical content from the source |
| **Index and Embed** | Parse, chunk, generate embeddings, store in Vespa |
| **Incremental Sync** | Scheduled sync fetches only new and modified content |
| **Real-time** | Webhook-driven instant updates (connector-specific) |

### Sync Modes

| Mode | Trigger | Availability |
|------|---------|-------------|
| Full | First connect or manual re-index | All connectors |
| Incremental | Scheduled interval (configurable) | All connectors |
| Real-time | Webhooks, subscriptions, or Pub/Sub | Select connectors |

All sync jobs are orchestrated by Temporal workflows with durable execution, automatic retries, and progress tracking.
