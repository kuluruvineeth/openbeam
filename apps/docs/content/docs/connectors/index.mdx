## How It Works

1. **OAuth** — Secure authentication with minimal scopes
2. **Initial Sync** — Full index of historical content
3. **Real-time** — Webhooks for instant updates
4. **Permissions** — Respects source application access control

## Sync Modes

| Mode | Description |
|------|-------------|
| Full | Complete re-index of all content |
| Incremental | New or modified content only |
| Real-time | Webhook-driven instant updates |
