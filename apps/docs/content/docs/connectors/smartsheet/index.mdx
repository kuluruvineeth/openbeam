# Smartsheet

Index work management data from Smartsheet including sheets with row-level content, workspaces, reports, and dashboards. Supports API key authentication with page-based pagination and modifiedSince incremental sync.

## What Gets Indexed

| Content | Details |
|---------|---------|
| **Sheets** | Name, columns, row count, owner, workspace, version |
| **Rows** | Cell values across all columns, row number, parent hierarchy, lock status |
| **Workspaces** | Name, contained sheets, reports, dashboards, folders |
| **Reports** | Name, source sheets, owner, row count |
| **Dashboards** | Name, widgets, owner |

## Authentication

**Method:** API Key (Bearer Token)

Generate an API access token from **Account > Personal Settings > API Access** in Smartsheet.

## Quick Start

1. Generate an API access token in Smartsheet
2. Add the Smartsheet connector in OpenBeam
3. Enter your API access token
4. Start the initial sync
