# NVIDIA Omniverse

Index industrial digital twin data from OpenUSD scenes stored in Omniverse Nucleus. Search across equipment, zones, sensors, and annotations with spatial metadata and scene hierarchy preservation.

## What Gets Indexed

| Entity | Description |
|--------|-------------|
| Assets (Equipment) | Name, prim type, spatial transform, bounding box, USD properties |
| Zones | Zone name, spatial bounds, contained assets |
| Sensors | Sensor name, position, associated readings |
| Annotations | Note text, 3D position, linked prim path |

## Authentication

Omniverse uses **API token** authentication for Nucleus server access and the USD Search API.

## Sync

| Mode | Supported |
|------|-----------|
| Full sync | Yes |
| Incremental sync | Yes |
| Real-time | No |

Full sync traverses the OpenUSD scene graph from configured stage paths, extracting prims and their properties. Incremental sync uses the Nucleus file system watch to detect modified USD stages. An optional USD Search API integration enables natural language queries against the scene.

## Setup

1. Ensure your **Omniverse Nucleus server** is accessible
2. Generate an API token from the Nucleus admin panel
3. In OpenPlane, add the Omniverse connector
4. Enter the Nucleus server URL, API token, and USD stage paths to index
5. Optionally configure the USD Search API URL for natural language query support
6. Start the initial sync

### Settings

| Setting | Default | Description |
|---------|---------|-------------|
| Nucleus Server URL | — | Omniverse Nucleus server address (required) |
| API Token | — | API token for Nucleus and USD Search API access (required) |
| USD Stage Paths | — | Paths to USD stages to index, one per line (required) |
| USD Search API URL | — | URL of the USD Search API service (optional) |
| Scene Depth Limit | 0 (unlimited) | Maximum depth for scene graph traversal |
