# GitHub

Index repositories, issues, pull requests, and releases from GitHub organizations and personal accounts. The connector uses OAuth 2.0 for authentication and supports webhook-driven real-time updates.

GitHub is one of the most common connectors -- engineering teams use it to make code context searchable alongside Slack messages, Linear issues, and documentation.

## Authentication

**Method:** OAuth 2.0

**Scopes:** `read:user`, `user:email`, `repo`, `read:org`

Create an OAuth App at [github.com/settings/developers](https://github.com/settings/developers) and provide the Client ID and Client Secret in OpenBeam.

## Data Streams

| Stream | Description | Sync Mode | Interval |
|--------|-------------|-----------|----------|
| **Repositories** | Name, description, readme, default branch, topics, visibility | Periodic | 30 min |
| **Issues** | Title, body, state, labels, assignees, comments | Periodic | 15 min |
| **Pull Requests** | Title, body, state, review status, commits, comments | Periodic | 15 min |
| **Releases** | Tag, name, release notes, published date, URL | Periodic | 60 min |

All streams support full backfill.

## Setup

1. Go to **GitHub Settings** > **Developer Settings** > **OAuth Apps** and create a new application
2. Set the authorization callback URL to your OpenBeam instance's redirect path
3. Copy the **Client ID** and **Client Secret**
4. In OpenBeam, add the GitHub connector and enter the credentials
5. Authorize the application to start the initial sync

## Configuration

| Setting | Default | Description |
|---------|---------|-------------|
| Client ID | -- | GitHub OAuth App client ID (required) |
| Client Secret | -- | GitHub OAuth App client secret (required) |
| Include Private Repositories | On | Index private repositories accessible to the OAuth token |
| Include Organization Repositories | On | Include repos from the user's organizations |
| Webhook Secret | -- | Secret for validating GitHub webhook signatures |
| History (days) | Unlimited | How far back to sync issues and pull requests |

## Sync Details

**Full sync** enumerates all accessible repositories and fetches issues, pull requests, and releases for each.

**Incremental sync** uses `updated_at` timestamps per repository to fetch only entities modified since the last sync run.

**Webhooks** can be configured for instant updates when issues, PRs, or releases change. Set a webhook secret in both GitHub and OpenBeam to enable signature verification.
