# GitHub

Index repositories, issues, pull requests, discussions, and releases from GitHub with OAuth 2.0 authentication and webhook-driven updates.

## What Gets Indexed

| Entity | Description |
|--------|-------------|
| Repositories | Name, description, readme, default branch, topics, visibility |
| Issues | Title, body, state, labels, assignees, comments |
| Pull Requests | Title, body, state, review status, commits, comments |
| Discussions | Title, body, category, answer, comments |
| Releases | Tag, name, release notes, publish date |

## Authentication

GitHub uses **OAuth 2.0**. Scopes requested: `read:user`, `user:email`, `repo`, `read:org`.

Create an OAuth App at [github.com/settings/developers](https://github.com/settings/developers) to get a Client ID and Client Secret.

## Sync

| Mode | Supported |
|------|-----------|
| Full sync | Yes |
| Incremental sync | Yes |
| Real-time (webhooks) | Yes |

Incremental sync uses `updated_at` timestamps per repository to fetch only modified issues, pull requests, and discussions since the last sync.

## Setup

1. Go to **GitHub Settings > Developer Settings > OAuth Apps** and create a new OAuth application
2. Set the authorization callback URL to your OpenPlane instance's redirect path
3. Copy the **Client ID** and **Client Secret**
4. In OpenPlane, add the GitHub connector and enter the credentials
5. Authorize the application and start the initial sync

### Optional Settings

| Setting | Default | Description |
|---------|---------|-------------|
| Include Private Repositories | On | Index private repositories accessible to the OAuth token |
| Include Organization Repositories | On | Include repos from the user's organizations |
| Webhook Secret | — | Secret for validating GitHub webhook signatures |
| History (days) | Unlimited | How far back to sync |
