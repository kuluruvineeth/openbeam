# Troubleshooting

## Authentication Errors

**Invalid access token:** Verify your access token is correct and has not expired. Re-generate from Administration > Identity and Access > Access Tokens if needed.

**403 Forbidden:** The access token lacks sufficient permissions. Ensure it has read access to Artifactory repositories, artifacts, builds, and (if syncing violations) Xray.

**Wrong instance URL:** Verify your instance URL matches your JFrog deployment. SaaS instances use `https://company.jfrog.io`, self-hosted instances use your custom domain.

## Rate Limiting

**429 Too Many Requests:** The connector automatically backs off when rate limited. If syncs are consistently slow, consider disabling build or violation syncing to reduce API calls.

## Missing Data

**Artifacts not appearing:** AQL queries filter out folders by default. Only file-type artifacts are indexed. Verify artifacts exist as files in your repositories.

**Builds missing:** Ensure build syncing is enabled in connector settings. Builds require the build info API which may need separate permissions.

**Violations not showing:** Xray must be configured with watches and policies to generate violations. Verify Xray is active and the access token has Xray permissions.

## Sync Failures

**Incremental sync falling back to full:** This happens when the cursor state is stale or the API returns errors. The connector automatically recovers by running a full sync.

**Connection timeout:** JFrog API may be temporarily unavailable. The connector retries with exponential backoff up to 3 times.

**AQL errors:** If artifact syncing fails with AQL errors, verify the access token has AQL execution permissions (typically requires admin or specific role).
