# Changelog

Track notable changes, new features, and fixes across OpenPlane releases.

## March 2026

### Edge Runtime (v0.1.0)
- Edge search with SQLite FTS5 + in-memory vector similarity
- RAG pipeline for offline AI answers
- Merkle tree sync protocol for cloud-to-edge replication
- Hardware tier detection and feature flags
- Task scheduler with cron and dead letter queue

### Documentation Overhaul
- 183 documentation pages across 12 sections
- Full API reference covering all 23 tRPC routers (200+ procedures)
- New sections: API Reference, Edge Runtime, Security, Monitoring
- Glossary with 35+ defined terms
